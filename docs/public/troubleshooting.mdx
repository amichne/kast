Find your symptom below.

## Your agent does not use Kast

1. From your project root, run the [first query](/start#3-run-your-first-query) yourself. If it fails, fix that first with the sections below.
2. Repeat [Connect your agent](/start#2-install-agent-guidance), for example `kast install codex`.
3. Start a new agent session in your Kotlin project, and ask your question again.

Do the same if an upgrade reports `HARNESS_REFRESH_REQUIRED`. It means the Kast guidance in your agent tool, such as Codex, Copilot, or Pi, is older than the new build.

## IDEA runs an old version of Kast

```shell
kast status --json
```

`installedBuild.value.version` is the build on disk. `applicationHost.value.runtimeIdentity.buildIdentity.version` is the build that IDEA has loaded.

1. If `unresolvedTransaction.value.records` is not empty, an update is unfinished. Follow the [recovery procedure](/reference/management#4-resolve-unfinished-recovery) before anything else.
2. If the two versions differ, or `applicationHost` is `UNAVAILABLE`, restart IntelliJ IDEA.
3. If that does not help, see [Load the plugin and inspect state](/reference/installation#2-load-the-plugin-and-inspect-state).

With a workspace container, `kast status` does not show the container's Host. Each container keeps the runtime it was created with. See [Without desktop IDEA](/reference/management#without-desktop-idea).

## You want the latest build

`kast versions` lists the builds you can select. `kast upgrade` moves to the latest one:

```shell
kast versions
kast upgrade --channel main --restart-ide
```

The upgrade removes a pinned version. To select a specific version instead, see [Pin a published build](/reference/installation#pin-a-published-build).

If the result is not `ACTIVATED` or `INSTALLED_NOT_RUNNING`, look it up in [update results](/reference/management#3-read-the-result). For `RECOVERY_REQUIRED`, keep the output before you run another install or upgrade.

## The project is not ready

The query output names a trust, save, Gradle import, or indexing problem.

- **Desktop IDEA:** resolve it in IDEA, in the same project. Then ask your question again.
- **Workspace container or `kast-task`:** there is no IDEA window. `kast container create` or the first `kast-task` run grants trust. For a Gradle import problem, fix the build in your workspace. Then restart the Host with `kast container stop NAME` and `kast container resume NAME`, or with `"$root/bin/kast" stop --json` and another `kast-task` run.
- **Indexing:** wait, then ask again.

See [Compatibility](/reference/compatibility) for the supported IDEA versions.

## A query does not finish

The output gives the cause and a recovery step.

- **Search too broad:** narrow the question to a function, package, or directory.
- **Container `STOPPED`:** see [Manage the container](/reference/installation#3-manage-the-container).
- **Reference expired:** follow the recovery step in the output.
- **More output to read:** the output includes a result reference or continuation. Use it to read the next page. Running the query again repeats the whole search.

An unfinished query with no matches does not show that nothing exists.

## An edit has an unclear result

Before another edit, read the current source and the [change receipt](/reference/change#read-the-receipt).
Review the diff and run your project's tests.
