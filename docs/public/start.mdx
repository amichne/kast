Install Kast, restart IDEA, then [connect your agent](/agent-harnesses).

## Before you install

You need Apple silicon macOS, a Kotlin Gradle repository, and IntelliJ IDEA `262.*` with its bundled Kotlin plugin and Java 25 JBR. A separate JDK does not change IDEA's runtime.

<Accordion title="Check the IDEA build and bundled runtime">
  Adjust the application path if necessary:

  ```shell
  idea="/Applications/IntelliJ IDEA.app/Contents"
  cat "$idea/Resources/build.txt"
  cat "$idea/jbr/Contents/Home/release"
  ```

  Look for `IU-262.…` or `IC-262.…`, `JAVA_VERSION` beginning with `25`, and `OS_ARCH` of `aarch64` or `arm64`.
</Accordion>

## Install

```shell wrap
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/amichne/kast/main/install.sh)"
```

The installer adds the IDEA plugin, Kast services, and native `kast` command. It selects stable Control and Host releases independently, then checks their contracts. Version numbers can differ. Append `-- --verbose` for structured diagnostics.

Restart IDEA to load the plugin. Then run:

```shell
kast status
```

Inspect the version and installation path. Verify loaded tools with the [first query](/agent-harnesses#check-that-the-tools-work).

<AccordionGroup>
  <Accordion title="Install the latest developer build">
    The default command selects stable releases. To select the latest tested developer build:

    ```shell wrap
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/amichne/kast/main/install.sh)" -- --developer-latest
    ```

    Keep the `--` separator before installer options. Terminal downloads show progress. Wait for the installation result; Ctrl-C stops installation.

    Developer builds are prereleases. Selection reads the published GitHub channel, independently of the local checkout or installed version. The installer prints the selected version and source revision. `kast upgrade` keeps the developer channel.

    To preserve an existing Codex MCP configuration, append `--skip-codex-mcp`. Restart IDEA and your agent after installation.
  </Accordion>

  <Accordion title="If your shell cannot find kast">
    The executable is `$XDG_CONFIG_HOME/kast` when `XDG_CONFIG_HOME` is nonempty. Otherwise, it is `$HOME/.local/bin/kast`.

    Use the printed absolute path or add its directory to `PATH`. The installer warns but does not edit shell profiles.
  </Accordion>

  <Accordion title="Select another IDEA installation">
    ```shell wrap
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/amichne/kast/main/install.sh)" -- --idea-home "/Applications/IntelliJ IDEA.app"
    ```
  </Accordion>

  <Accordion title="Install a specific release pair">
    The checked pair is [Control 0.3.1 and Host 0.4.0](/reference/compatibility#current-release-pair):

    ```shell wrap
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/amichne/kast/main/install.sh)" -- --version 0.3.1 --host-version 0.4.0
    ```

    `--version` selects Control. `--host-version` selects Host. Restart IDEA and your agent.
  </Accordion>
</AccordionGroup>
