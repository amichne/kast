MCP places the canonical `query_symbols` document in `result.structuredContent`. Its semantic status is `complete`, `qualified`, or `rejected`.

The document preserves exact references, coverage, qualifications, and retained evidence. An invocation failure can omit this document.

`check_diagnostics` uses the separate `check_diagnosticsSemanticResult` schema. The [MCP wrapper](/reference/models/mcp-tool-call-result) defines invocation failure.

[Results](/reference/responses) defines query fields. [Read retained evidence](/how-to/read-retained-evidence) gives the presentation procedure.
