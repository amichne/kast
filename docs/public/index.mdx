<span id="what-kast-adds" />

Kast gives your coding agent source relationships from IntelliJ IDEA's compiler analysis.
Use the native `kast` command with Codex, Copilot, or Pi to investigate your Kotlin code.

## Ask about your code

Give your agent the function's file and name.

<Prompt description="Before you change a function" actions={["copy"]}>
Use the Kast CLI to find the callers of this function. Show the source locations and explain how they use it.
</Prompt>

Try [another question](/search), or use the [CLI reference](/reference/cli) for terminal commands.
