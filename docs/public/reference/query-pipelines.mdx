## Complete static answers

Every public run needs complete execution within `COMPILER_RESOLVED_STATIC_V1`. Composition preserves input identity and qualifications.

A finished output page cannot strengthen incomplete producer proof. Rejection evidence stays `POLICY_REJECTED_EVIDENCE` during later presentation.

The examples use the [historical recording](/reference/schemas#recorded-walkthrough) at `56df091`. Its counts describe that recording alone.

## 1. Keep a second query result

The recording's input A contains ten implementations of `QueryStepSyntax`. Input B contains two class-like declarations named `Concat`.

Only `QueryStepSyntax.Concat` implements that interface. `ExactQueryStage.Concat` has a separate identity despite the equal name.

```json
{
  "request": {
    "type": "RUN",
    "executionBudget": {"maxElapsedMs": 15000},
    "source": {
      "type": "SEARCH_DECLARATIONS",
      "declarationName": "Concat",
      "declarationKinds": ["CLASS"],
      "scope": {
        "type": "DIRECTORY",
        "relativeDirectoryPath": "query/contract",
        "sourceSetNames": ["main"]
      }
    },
    "output": {"type": "SYMBOLS", "fields": ["NAME", "LOCATION", "SIGNATURE"]},
    "retention": "RETAIN"
  }
}
```

<a id="combine-both-inputs-then-filter-the-combined-stream" />

## 2. Combine the inputs

Use `UNION` to combine symbol identities. Apply a later `WHERE` to the combined stream.

```json
{
  "request": {
    "type": "RUN",
    "executionBudget": {"maxElapsedMs": 15000},
    "source": {"type": "RESULT", "result": "<result A>"},
    "steps": [
      {"type": "UNION", "right": {"type": "RESULT", "result": "<result B>"}},
      {
        "type": "WHERE",
        "predicate": {
          "type": "PRIMITIVE",
          "field": "NAME",
          "operator": "EQUALS",
          "value": "Concat"
        }
      }
    ],
    "output": {"type": "SYMBOLS", "fields": ["NAME", "LOCATION", "SIGNATURE"]}
  }
}
```

Recorded call `04-union-filter` returned both declarations with exhaustive coverage. The filter acted after the union.

`CONCAT` uses `input` and preserves order and duplicates. It does not use union's identity reduction.

## 3. Select the composition rule

Use `INTERSECT` to keep identities present in both inputs.

```json
{
  "request": {
    "type": "RUN",
    "executionBudget": {"maxElapsedMs": 15000},
    "source": {"type": "RESULT", "result": "<result A>"},
    "steps": [
      {"type": "INTERSECT", "right": {"type": "RESULT", "result": "<result B>"}}
    ]
  }
}
```

Recorded call `05-intersection` returned `QueryStepSyntax.Concat`. The shared identity kept evidence from both producers.

## 4. Project a joined cell before another symbol step

Use an `INNER` join to preserve two named cells. Select one cell before a later symbol step.

```json
{
  "request": {
    "type": "RUN",
    "executionBudget": {"maxElapsedMs": 15000},
    "source": {"type": "RESULT", "result": "<result A>"},
    "steps": [
      {
        "type": "JOIN",
        "mode": {"type": "INNER", "leftName": "step", "rightName": "candidate"},
        "right": {"type": "RESULT", "result": "<result B>"}
      }
    ],
    "output": {"type": "BINDING_ROWS"},
    "retention": "RETAIN"
  }
}
```

Recorded call `06-join-c` kept one pair as C. Both cells identified `QueryStepSyntax.Concat` through their own evidence.

```json
{
  "request": {
    "type": "RUN",
    "executionBudget": {"maxElapsedMs": 15000},
    "source": {"type": "RESULT", "result": "<result C>"},
    "steps": [
      {"type": "PROJECT_BINDING", "name": "step"},
      {"type": "EXPAND_RELATION", "relation": "REFERENCES"}
    ],
    "output": {"type": "OCCURRENCES"}
  }
}
```

Recorded call `07-project-references` found this compiler-confirmed occurrence.

```kotlin
is QueryStepSyntax.Concat -> ExactQueryStage.Concat(step.input, stage)
```

Arbitrary-field joins and a general-purpose `MAP` have no supported contract. [Composition contracts](/reference/composition) defines legal row forms.

## Choose the relationship search domain

`EXPAND_RELATION` defaults to workspace expansion. An unbounded `WALK` also defaults to workspace expansion.

An explicit walk depth defaults to the retained seed's scope. An explicit `expansionScope` overrides either default before enumeration.

```json
{
  "type": "EXPAND_RELATION",
  "relation": "REFERENCES",
  "expansionScope": {
    "type": "SOURCE_DOMAIN",
    "sourceSets": ["main"],
    "directory": "query/contract",
    "includeSubdirectories": true,
    "sourcePolicy": "PRODUCTION_ONLY",
    "generatedSources": "EXCLUDE"
  }
}
```

This current source-domain example does not change the recorded counts. A later `WHERE` cannot reduce native enumeration work.

## Read produced output or retained rows

Use `RESUME` for an issued output continuation. Use `READ_RESULT` for rows from an identified retained result.

```json
{"request":{"type":"RESUME","continuation":"<issued output continuation>"}}
```

```json
{"request":{"type":"READ_RESULT","result":"<issued symbol-result reference>"}}
```

```json
{"request":{"type":"READ_RESULT","result":"<result C>","output":{"type":"BINDING_ROWS"}}}
```

Recorded calls `08-read-a` and `09-read-c` returned ten symbols and one pair. Both kept their original identities.

### Reject an unproven absence claim

`DIFFERENCE` and `ANTI` need complete right coverage without unfinished producer progress. A missing match in a prefix cannot establish absence.

Recorded call `10-incomplete-right` supplied incomplete right coverage. Both absence operations returned this historical rejection.

```json
{
  "status": "rejected",
  "rejection": {
    "type": "execution-rejected",
    "reason": "right-input-incomplete"
  },
  "next_action": "correct_request"
}
```

Current complete-only execution can reject before it produces a reusable incomplete answer. Resource exhaustion still cannot establish absence.

If the epoch changes, start fresh producing queries. [Staleness](/reference/staleness) defines reuse, and [Results](/reference/responses) defines independent row and evidence positions.
