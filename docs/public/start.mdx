You need macOS on Apple silicon, a Kotlin Gradle repository, and IntelliJ IDEA
`262.*` with its bundled Kotlin plugin and Java 25 JBR.

<Steps>
  <Step title="Install the matched release">
    ```shell
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/amichne/kast/main/install.sh)"
    ```

    The installer checks the IDEA release line and installs its matching
    plugin and Kast service. In an interactive terminal, it offers to register
    a user-level Kast MCP server with Codex.
  </Step>
  <Step title="Restart IDEA and open your agent">
    Restart IDEA to load the plugin. Start the agent from the repository or
    worktree:

    ```shell
    cd /path/to/kotlin-repository
    codex
    ```

    Kast binds the request to that Gradle root and prepares its IDEA project.
    A semantic call waits for the required import and indexing state.
  </Step>
  <Step title="Ask a project-independent question">
    > Use Kast to query declarations in this workspace. Show one exact
    > compiler-backed symbol with its signature, location, `ref`, and coverage.
    > If no symbol is proven, report the reason.

    See [query examples](/search) for the tool input and follow-up prompts.
  </Step>
</Steps>

## Other clients and install options

The [MCP contract](/reference/mcp-catalog) and
[tool RPC contract](/reference/rpc-catalog) show how other clients discover
tools. The installer does not add a `kast` command to `PATH`. If another
integration provides the Codex MCP declaration, pass `-- --skip-codex-mcp`
to the installer.

For a second IDEA installation, pass
`-- --idea-home "/Applications/IntelliJ IDEA.app"`.
If setup reports a blocker, use the [troubleshooting guide](/troubleshooting).
