Composition operates on admitted exact references or retained rows. Display names and token strings do not establish equality.

## Set operations

| Step | Input field | Output rule | Evidence rule |
| --- | --- | --- | --- |
| `CONCAT` | `input` | Appends rows in order with duplicates. | Keeps evidence from each input. |
| `UNION` | `right` | Combines symbols by canonical identity. | Keeps input qualifications. |
| `INTERSECT` | `right` | Keeps symbols present in both inputs. | Combines evidence for the shared identity. |
| `DIFFERENCE` | `right` | Keeps left symbols absent from the right input. | Needs complete right coverage without failures or producer progress. |
| `DISTINCT_SYMBOLS` | None | Keeps the first row per canonical identity. | Applies at its exact pipeline position. |

Steps after composition apply to the combined stream. A filter before composition applies only to its upstream input.

## Joins and row kinds

| Mode | Output | Necessary proof |
| --- | --- | --- |
| `INNER` | Binding rows with named left and right cells. | Canonical identity equality. |
| `SEMI` | Matching left symbol rows. | A matching right identity. |
| `ANTI` | Left symbol rows without a match. | Complete right coverage for absence. |

`PROJECT_BINDING` selects one named symbol cell before later symbol steps. `BINDING_ROWS` is the output form for an inner join.

Arbitrary-field joins and a general-purpose `MAP` are unsupported. Row IDs belong to one retained result and do not migrate between results.

## Absence and rejection

An incomplete right input cannot establish absence. `DIFFERENCE` and `ANTI` reject that input rather than emit a success-shaped empty answer.

A completed presentation page does not repair incomplete producer coverage. Composition preserves that original qualification.

These semantics use the fixed `COMPILER_RESOLVED_STATIC_V1` model. They do not establish runtime activation or path feasibility.
