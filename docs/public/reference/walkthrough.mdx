## Start from remembered text

`SEARCH_TEXT` returns the declaration that contains a matching word. Each result includes one matching line, a one-based line number, and a UTF-16 range. Use the declaration's `ref` for source reads or relations.

<Accordion title="Request: find declarations containing a word">
  ```json
  {
    "request": {
      "type": "RUN",
      "source": {
        "type": "SEARCH_TEXT",
        "word": "launchd",
        "declarationKinds": ["FUNCTION"],
        "scope": {
          "type": "DIRECTORY",
          "relativeDirectoryPath": "app-server",
          "sourceSetNames": ["main"]
        }
      },
      "output": {"type": "SYMBOLS", "fields": ["NAME", "LOCATION"]},
      "executionBudget": {"maxResults": 10}
    }
  }
  ```

  Use one case-sensitive ASCII identifier word. Kast rejects phrases, substrings, qualified literals, and regular expressions. To find uses of `AppServerAction.Disable`, search `Disable`. Then examine the match context.

  Unsupported containers leave coverage incomplete. A stopped index scan is terminal. The internal runner can resume other saved work within its grant.
</Accordion>

The [captured source](https://github.com/amichne/kast/blob/56df0912e46b182bb4ad8beabd1512823100fd72/query/contract/src/main/kotlin/io/github/amichne/kast/query/contract/QuerySteps.kt) declares `sealed interface QueryStepSyntax`.

## 3. Trace callers to a chosen depth

Find `QueryPlanCompiler.exactStage` under `query/contract` in `main`. Use its exact reference in this caller query:

<Accordion title="Request: walk callers to a bounded depth">
  ```json
  {
    "request": {
      "type": "RUN",
      "executionBudget": {"maxElapsedMs": 15000},
      "source": {
        "type": "SYMBOL_REFS",
        "symbolRefs": ["<exact function ref>"]
      },
      "steps": [
        {"type": "WALK", "relation": "CALLERS", "maximumDepth": 2}
      ],
      "output": {"type": "TRAVERSAL_RECORDS"}
    }
  }
  ```
</Accordion>

Recorded call `15-caller-walk` found `QueryPlanCompiler.admit` at depth 1. The response included compiler-confirmed evidence and exhaustive coverage. It issued no continuation.

Depth limits the requested graph. Coverage reports unfinished work within that graph. Empty qualified output does not establish absence. Use [Callback evidence](/reference/callbacks) for ownership limits. Use [Results](/reference/responses#follow-progress-not-row-count) for progress and recovery.
