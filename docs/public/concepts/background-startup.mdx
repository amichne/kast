Workspace preparation is automatic for ordinary semantic calls. It binds one
request to the exact repository or worktree, an IDEA application, and the
project opened there. You do not need a separate workspace command before
searching.

## From client connection to project

1. The client starts an MCP session or an RPC tool call from a Kotlin Gradle
   repository. Kast discovers its exact Gradle root.
2. Kast asks the installed service for that root. The service reuses the
   selected IDEA when its plugin is available. If IDEA is absent, it starts the
   selected application in the background.
3. IDEA opens or reuses the exact project. On first attach, after changed
   Gradle inputs, or without a cached model, Kast requests a linked Gradle
   model reload. A clean prepared project can reuse its existing model.
4. The native host saves changed buffers under the selected root, refreshes
   changed files, and waits for indexing before evaluating semantic requests.
5. The result carries its scope, status, and any qualification or finite
   failure back to the client.

MCP begins preparation on its first valid protocol request; a semantic call joins
that work. RPC performs preparation when `call` arrives. A `catalog` request
only describes available tools; it does not establish IDEA readiness.

## What background means

Kast does not deliberately activate the IDEA window when launching or opening
the project. IDEA can still display its own prompts or errors. Project trust,
an unavailable plugin, a failed save, import failure, or indexing delay can
prevent a semantic answer. These conditions return a blocker or incomplete
outcome; they do not become an empty successful search.

Use `health_check` to observe the bound workspace and readiness, then retry
the original request after resolving a blocker. `validate_workspace` runs
specific read only probes when you need to check semantic behavior. See
[Troubleshooting](/troubleshooting) for actions tied to reported failures and
[Read a response](/reference/responses) for result status.
