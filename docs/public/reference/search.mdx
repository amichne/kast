## 1. Find a declaration and inspect its source

Ask for candidates with their signatures, locations, and coverage.

```text wrap
Use Kast to find submitOrder under checkout in main. Show matching signatures, locations, and coverage. Stop so I can choose the exact function.
```

Select the intended overload and owner. Ask the agent to read its source and keep its issued exact reference.

| Evidence | Why it matters |
| --- | --- |
| Signature | Tells overloads apart. |
| Location | Identifies the repository and declaration. |
| Coverage | Reports whether the requested search finished. |
| Exact reference | Carries the selected identity into the next request. |

For an interface, use the request family `CLASS`. Returned class-like declarations use `kind: "classlike"`.

`INTERFACE` and `CLASSLIKE` reject as request kind values. This example selects supported class-like declarations within one package.

```json
{
  "request": {
    "type": "RUN",
    "source": {
      "type": "SEARCH_DECLARATIONS",
      "declarationName": "CacheManager",
      "declarationKinds": ["CLASS"],
      "scope": {
        "type": "PACKAGE",
        "packageName": "example.cache",
        "includeSubpackages": false,
        "sourceSetNames": ["main"]
      }
    },
    "output": {"type": "SYMBOLS", "fields": ["NAME", "LOCATION", "SIGNATURE"]}
  }
}
```

An exact name can match several owners. To find a method, search its name with `FUNCTION`. Then check each signature.

Before discovery, set the directory, package, source set, and kind that you know. To prove completeness, the scan can visit files that the name index did not return.

`AT_LOCATION` selects the nearest containing named declaration. It does not resolve a call token to its target.

Use `REFERENCES` or `CALLERS` from the selected target to prove that relationship. Source offsets use UTF-16 code units.

## 2. Trace the selected declaration

Pass the exact reference unchanged. Choose the relationship domain before the native scan.

```text wrap
Use the exact Kast reference we selected to TRACE affected uses across the workspace. Show signatures, locations, occurrence evidence, and completion. Keep the result for follow-up reads.
```

This current input example uses a placeholder for the issued reference.

```json
{
  "request": {
    "type": "RUN",
    "source": {"type": "SYMBOL_REFS", "symbolRefs": ["<issued ref>"]},
    "steps": [{"type": "TRACE", "expansionScope": {"type": "WORKSPACE"}}],
    "output": {"type": "SYMBOLS", "fields": ["NAME", "LOCATION", "SIGNATURE"]},
    "retention": "RETAIN",
    "executionBudget": {"maxElapsedMs": 30000}
  }
}
```

`TRACE` includes references, implementations or overrides, and direct callers. It adds one further caller layer. For a type seed, it also includes direct callable members.

The topology is fixed. Put `TRACE` last and use `SYMBOLS` output. Its grouped symbols keep the original relation and occurrence evidence.

`WORKSPACE` can reach clients outside the discovery directory. Use explicit `SOURCE_DOMAIN` when the question excludes those destinations.

The host grant can lower the requested 30 seconds. All trace branches share the admitted elapsed allowance.

For one hop, use `EXPAND_RELATION`. For a graph, use `WALK` and state the intended depth or expansion scope.

If walk depth is omitted or null, the request covers the reachable graph with workspace expansion. A later row filter cannot reduce that native work.

## 3. Read completion and choose recovery

Check completion, searched domain, and occurrence evidence before a conclusion. A qualified result with no rows does not prove absence.

Every public run uses `COMPLETE_ONLY`. If execution or callback proof is incomplete, the result returns `COMPLETION_UNPROVEN`. It keeps available evidence.

Use its issued `nextQuery` to inspect retained rejection evidence. That read does not resume the unfinished semantic work.

Use public `RESUME` only with an issued output continuation. The internal runner owns semantic page continuation.

For callback code, check supply, formal binding, and actual call ownership. [Program tracing](/reference/program-tracing) explains each path's meaning.

## Start from remembered text

Use one case-sensitive ASCII identifier word to discover containing declarations.

```text wrap
Use Kast to find functions containing the word retry under checkout in main. Show a matching line for each function, then let me choose one to inspect or trace.
```

Kast rejects phrases, substrings, qualified literals, and regular expressions. A word match explains why discovery found the body. It does not prove a caller relationship.

## Keep reads current

If retained state is not available, start a fresh query. After edits, get new source offsets and handles.

An exact reference can gain fresh compiler authority after its identity checks pass. Read `reference_acquisitions` if the response supplies it.

For reuse rules, read [Staleness](/reference/staleness). [Results](/reference/responses) defines progress and recovery fields.
