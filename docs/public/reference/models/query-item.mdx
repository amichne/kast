The selected output determines the row variant: a symbol, occurrence, traversal record, binding row, or impact evidence.

Each row preserves its exact identities and supporting evidence. A shared display name does not establish identity equality.

Qualifications remain attached to the producing result. [Query forms](/reference/api#choose-the-result-you-need) defines outputs. [Composition contracts](/reference/composition) defines legal row combinations.
