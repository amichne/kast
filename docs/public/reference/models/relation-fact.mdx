A relation fact records a compiler-established source relationship within the admitted domain. Its producing query separately reports occurrence inventory and coverage.

Reference, caller, implementation, and type-use facts describe different relationships. Their counts do not share one invocation meaning.

Anonymous ownership stays separate from lexical containment. A static callback route does not prove runtime execution.

[Program tracing](/reference/program-tracing) explains path evidence. [Callback observations](/reference/callback-observations) defines named-edge qualifications.
