Kast connects your coding agent to IntelliJ IDEA for Kotlin queries, diagnostics, and targeted source changes.

Your agent chooses the question. Kast uses compiler evidence to identify declarations and relationships. Each answer reports its search scope, source state, and limits.

## What you can do

| Question | Kast evidence |
| --- | --- |
| Which `submitOrder` do I need? | Signatures, locations, source, and exact references for matching declarations. |
| What calls or implements it? | Compiler-confirmed relationships and call sites within the requested traversal. |
| Which queries share declarations? | [Query results combined by declaration identity](/query-pipelines). |
| Can I change this declaration? | [One declaration addition or supported body replacement](/change), with a receipt for the edit and recovery. |

A caller result identifies a source relationship. Read coverage before you claim that it includes every caller or proves absence. See [What an answer proves](/concepts/evidence-boundaries).

## Supported environment

Use Kast with a Kotlin Gradle project on Apple silicon macOS and IntelliJ IDEA `262.*`. Supported agents include Codex, Copilot, and Pi. Queries prepare the selected IDEA project and report setup blockers.

Before installation, examine [compatibility](/reference/compatibility). After a source change, run your project's build and tests. Kast's edit verification covers the scope in its receipt.
