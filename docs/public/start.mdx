Install Kast once, then [connect Codex, Copilot, or Pi](/agent-harnesses).

## Before you install

You need **macOS on Apple silicon**, a **Kotlin Gradle repository**, and **IntelliJ IDEA `262.*`** with its bundled Kotlin plugin and Java 25 JBR.

## Install

Run this in a terminal:

```shell
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/amichne/kast/main/install.sh)"
```

The installer installs the matched IDEA plugin, Kast-owned services, and the native `kast` management command. It may offer to connect Codex during interactive setup; you can choose or change your agent afterward.

Installer output shows progress and readable failure reasons. To include structured diagnostic reports, append `-- --verbose` to the command above.

Restart IntelliJ IDEA to load the plugin, then check the installation:

```shell
kast status
```

Look for the installed version and installation path. A recorded connection is not proof that an agent has loaded its tools; you will check that in the next step.

<Accordion title="If your shell cannot find kast">
  With a nonempty `XDG_CONFIG_HOME`, the executable is `$XDG_CONFIG_HOME/kast`. Otherwise it is `$HOME/.local/bin/kast`.

  Use the absolute command path printed by the installer, or add its containing directory to `PATH`. The installer warns when the directory is missing from `PATH`; it does not edit shell profiles.
</Accordion>

<Accordion title="Select another IDEA installation">
  Pass the IDEA application path to the bootstrap installer:

  ```shell
  /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/amichne/kast/main/install.sh)" -- --idea-home "/Applications/IntelliJ IDEA.app"
  ```
</Accordion>

## Next: connect your agent

[Connect Codex, Copilot, or Pi](/agent-harnesses), start it from your repository, and ask one question to verify the connection.

If installation stops at a blocker, start with [Troubleshooting](/troubleshooting). For upgrades and removal, see [Manage Kast](/workspaces).
