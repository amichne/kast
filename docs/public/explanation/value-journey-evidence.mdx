The [interactive example](/explanation/value-journey) traces one `Pet`.
A `PetListing` can hold it in `pet`. A list can then hold that listing as an element.
The listing and the list each have their own identity.

The compiler identifies the function and callback. A reviewed rule for `map` connects a callback result to a possible list element.
Select **Evidence** in the example to inspect that distinction and each source location.

The illustration uses [fixed Kotlin fixtures](https://github.com/amichne/kast/tree/main/relation/intellij/testData/r1-value-flow) and authored expected routes.
The displayed code uses pet-store names. The original fixtures stay unchanged.
The illustration does not query Kast or record execution. Its final step does not prove a complete investigation.

[What an answer proves](/reference/evidence-boundaries) explains the limits of a real Kast result.
