Honest beta boundary

What this release does not pretend to be.

Kotlin semantics only

Compiler guarantees do not extend to arbitrary languages.

No labels or embeddings

Natural language is deterministic lexical and structural ranking, not an LLM layer.

Some bounds do not page

Resolve, architecture, and context bounds require a narrower rerun; traversal evidence continues.

TOON v3-compatible

The Rust codec is toon-format 0.5.0; no v4.1 encoder-conformance claim.

Human view is an overview

Use default TOON with --explain for full actionable evidence.

Prerelease compatibility

Public analysis API packages moved; the beta does not claim 0.16.1 binary compatibility.
