## Start from remembered text

`SEARCH_TEXT` returns containing declarations with one matching line, a one-based line number, and a UTF-16 range. Reuse the declaration's `ref` for source or relations.

<Accordion title="Request: find declarations containing a word">
  ```json
  {
    "request": {
      "type": "RUN",
      "source": {
        "type": "SEARCH_TEXT",
        "word": "launchd",
        "declarationKinds": ["FUNCTION"],
        "scope": {
          "type": "DIRECTORY",
          "relativeDirectoryPath": "app-server",
          "sourceSetNames": ["main"]
        }
      },
      "output": {"type": "SYMBOLS", "fields": ["NAME", "LOCATION"]},
      "executionBudget": {"maxResults": 10}
    }
  }
  ```

  Use one case-sensitive ASCII identifier word. Phrases, substrings, qualified literals, and regular expressions are rejected. Search `Disable` rather than `AppServerAction.Disable`, then inspect context.

  Unsupported containers leave coverage incomplete. A stopped index scan is terminal; other retained work can be resumable.
</Accordion>

## 3. Trace callers to a chosen depth

Find `QueryPlanCompiler.exactStage` under `query/contract` in `main`, then reuse its reference:

<Accordion title="Request: walk callers to a bounded depth">
  ```json
  {
    "request": {
      "type": "RUN",
      "executionBudget": {"maxElapsedMs": 15000},
      "source": {
        "type": "SYMBOL_REFS",
        "symbolRefs": ["<exact function ref>"]
      },
      "steps": [
        {"type": "WALK", "relation": "CALLERS", "maximumDepth": 2}
      ],
      "output": {"type": "TRAVERSAL_RECORDS"}
    }
  }
  ```
</Accordion>

Recorded `15-caller-walk` returned `QueryPlanCompiler.admit` at depth 1, with compiler-confirmed evidence, exhaustive coverage, and no continuation.

Depth bounds the requested graph; coverage reports unfinished work within it. Empty qualified output does not establish absence. See [Callback evidence](/reference/callbacks) and [Results](/reference/responses#follow-progress-not-row-count).
