Read the canonical `query_symbols` document from `result.structuredContent`. Its status is `complete`, `qualified`, or `rejected`. Keep the evidence and qualifications with the result.

Decode `check_diagnostics` with its separate `check_diagnosticsSemanticResult` schema. An invocation failure can omit the structured document. Examine the [MCP wrapper](/reference/models/mcp-tool-call-result) first. Use [Results](/reference/responses) to interpret query coverage and progress.
