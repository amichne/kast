## Client contracts

The default agent guidance uses the native CLI.
MCP is an explicit option. MCP and Tool RPC carry the underlying tool documents.

| Client | Contract authority |
| --- | --- |
| [Native CLI](/reference/cli) | `kast describe` and the installed command examples. |
| [Direct MCP](/reference/mcp-catalog) | Installed `tools/list` entries and input and output schemas. |
| [Tool RPC](/reference/rpc-catalog) | Installed `catalog`, process commands, and reply variants. |
| [Agent guidance](/reference/integrations) | The selected installed skill and optional MCP composition. |

The shared tools are `query_symbols`, `check_diagnostics`, `add_declaration`, and `replace_body`.

Direct MCP and Tool RPC expose `health_check`. The hosted App Server has a distinct `workspace_lifecycle` contract. Its model pages describe that contract. [Compatibility](/reference/compatibility) describes the supported platform and Codex setup.

## Related architecture

| Mechanism | What it describes |
| --- | --- |
| [Program tracing](/reference/program-tracing) | Calls, callback paths, and supported value transfers within and across source callables. Each supported hop keeps its evidence. |
| [Staleness](/reference/staleness) | The state a read needs. Exact references can gain fresh authority. Old retained evidence can be rejected. |
| [Lifecycles](/reference/lifecycles) | Who owns a request, connection, project setup, or daemon start and stop. |

The compiler-static model does not prove that code ran or that a path can run. If proof is missing, Kast rejects the claim. It reports the cause and available evidence.

For step-by-step procedures, start at [Find and trace code](/reference/search). To compare results with known source, use the [source-evidence check](/tutorials/first-query).
