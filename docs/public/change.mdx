---
title: "Add a declaration"
description: "Use Kast's one-call, exact-target source change."
icon: "file-pen-line"
---

`change` adds one declaration to an existing Kotlin file. It uses an exact
symbol `ref` returned by Kast to identify the target. The
generated **Change** entry in the API / RPC tab defines the admitted intent.

```json
{
  "intent": {
    "kind": "add-declaration",
    "exactTarget": "<returned ref>",
    "declaration": "fun retryLimit(): Int = 3"
  }
}
```

Replace the placeholder with a returned exact `ref`. Kast plans the edit,
applies it, verifies the result, and returns a receipt or a finite failure
with recovery evidence. A rejected or lost response does not prove that no
write occurred; retain its plan identity and recovery evidence.

Use [query](/search) to obtain the target. The tool does not support new
files, replacements, multi-file renames, or arbitrary text edits.
