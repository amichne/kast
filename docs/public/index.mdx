Kast gives coding agents compiler-grounded Kotlin declarations, relationships, diagnostics, and targeted source changes through IntelliJ IDEA.

**Kast is the deterministic structure around a probabilistic system.** The agent chooses what to investigate. Kast establishes declaration identity and reports the scope, source state, and limits of the evidence.

## What you can do

| Question | Kast evidence |
| --- | --- |
| Which `submitOrder` do I need? | Matching signatures, locations, source, and exact references. |
| What calls or implements it? | Compiler-confirmed relationships, call sites, and bounded traversal. |
| Which queries share declarations? | [Retained results combined by identity](/query-pipelines). |
| Can I change this target precisely? | [One declaration addition or supported body replacement](/change), with verification and recovery evidence. |

A confirmed caller does not establish every caller. An empty qualified result does not prove absence. [What an answer proves](/concepts/evidence-boundaries) explains coverage and reuse.

## Supported environment

Kast supports Kotlin Gradle projects on Apple silicon macOS with IntelliJ IDEA `262.*`. Connect Codex, Copilot, or Pi. Queries prepare the selected IDEA project and report setup blockers.

Check [compatibility](/reference/compatibility) before installing. After a change, run your project's build and tests. Kast verifies the reported edit scope.
