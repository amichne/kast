Kast's public query contract expresses intent rather than candidate-refinement stages.
Use the same request with `kast.query` or `kast query run < request.json`.

## Search with defaults

```json
{"type":"QUERY","from":{"type":"SEARCH","query":"OrderService"}}
```

The default is exact declaration-name matching, not a unique overload selection.
All matching overloads remain separate exact symbols. Omitted controls use supported
kinds, main and test sources, no pipeline stages, and name/location projection.
Enumerated controls use CAPS_CASE; source-set names preserve Gradle spelling.
Explicit `null` is rejected; omit a control to use its declaring default.
`select: []` deliberately requests no optional display fields. Empty kinds, empty
source sets, blank queries, unknown fields and old INSPECT steps are rejected.

## Compose ordered operations

```json
{
  "type": "QUERY",
  "from": {
    "type": "SEARCH",
    "query": "submitOrder",
    "scope": {
      "type": "DIRECTORY",
      "value": "services/orders",
      "sourceSets": [
        "main"
      ]
    }
  },
  "steps": [
    {
      "type": "EXPAND",
      "relation": "CALLERS"
    },
    {
      "type": "FILTER",
      "visibility": [
        "PUBLIC"
      ]
    },
    {
      "type": "DISTINCT"
    }
  ],
  "select": [
    "NAME",
    "LOCATION",
    "SIGNATURE"
  ]
}
```

Scope restrictions intersect during discovery. `sourceSets` accepts exact Gradle
source-set names, including custom names such as `integrationTest` and multiplatform
names such as `commonMain`. Omitted source-set selection uses `main` and `test`; an unmatched
name contributes no declarations. Names are matched against imported ownership,
independently of production/test classification and physical directory names.
Scope selects exactly one `DIRECTORY` or `PACKAGE` target through `type` and `value`.
Directory values are relative to the workspace root; `"."` names the root. Package
values use dotted Kotlin names. Omitted scope means the workspace root.
Containment defaults to `RECURSIVE`, including the target and nested directories or
subpackages; `DIRECT` searches only the target. Scope does not
silently constrain later expansion destinations. Step order matters: this query
filters callers, not the declarations that were initially matched.

## Reuse exact references

```json
{"type":"QUERY","from":{"type":"REFS","refs":["exact:v3:EXAMPLE_NOT_ISSUED"]}}
```

The example token demonstrates shape only. Copy real `items[].ref.token` values
verbatim. Prefix syntax is not proof of workspace compatibility, current generation,
or compiler identity. Kast still admits those facts at execution.

Use `ALL` instead of `SEARCH` to enumerate; it has no query or match field. `REFS`
also has neither discovery scope nor name-matching controls. All public sources
request exact-symbol results; callers never insert candidate-refinement operations.

## Let Kast coordinate the work

Kast starts or joins the exact-root runtime and establishes required workspace and
derived evidence. Do not invoke lifecycle, synchronization or topology preparation
as query prerequisites. Existing bounded exhaustive intent remains qualified when
work or result coverage is incomplete. A qualified empty result is not proof of
zero matches. Preserve failure and limitation evidence.

Installed server projection 9 retains the declaration query syntax introduced in
projection 8 and adds explicit live read evidence.
Unchanged canonical wire/evaluator models are internal, not a second public CLI mode.
See `app-server/docs/public-query-contract.md` for ownership, enforcement and the
requirement-to-proof map. The installed `--schema` remains the executable's public
contract authority.
