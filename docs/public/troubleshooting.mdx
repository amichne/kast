Start with the symptom. Use the reported outcome to select the next action.

<span id="1-identify-the-failed-stage" />

## Your agent does not use Kast

Follow [step 2 in Set up](/start#2-install-agent-guidance) to install CLI guidance for your agent.
Start a fresh session in the intended Kotlin repository or worktree.

If an upgrade reports `HARNESS_REFRESH_REQUIRED`, repeat `kast install` with your agent's name before the fresh session.
MCP registration is necessary only for the optional MCP composition.
Then repeat your question in the fresh session.

<span id="inspect-installation-and-activation" />

## Installed build or Host does not match

<span id="2-inspect-the-installation-before-recovery" />

```shell
kast status --json
```

Compare `installedBuild` with `applicationHost`, which identifies the loaded Host.
Read `updatePolicy` and `unresolvedTransaction`.
If a transaction remains unresolved, follow the [recovery procedure](/reference/management#4-resolve-unfinished-recovery).
If the Host is missing or still uses the prior build, see [Load the plugin and inspect state](/reference/installation#2-load-the-plugin-and-inspect-state).
Run a query in the project to establish workspace readiness.

<span id="select-the-development-head" />

## The selected build is not the development head

If you want to track the latest development build, run:

```shell
kast versions
kast upgrade --channel main
```

This upgrade replaces a pin with the development channel. See [Pin a published build](/reference/installation#pin-a-published-build) to select a specific version or revision.
If activation needs an IDEA restart, repeat the upgrade with `--restart-ide`.

If the result reports `RECOVERY_REQUIRED`, keep its recovery evidence.
Use [installation outcomes](/reference/management#lifecycle-result-contract) before another lifecycle action.

## IntelliJ needs your attention

In IDEA, resolve the reported trust, project import, or indexing problem.
Then repeat your question in the same worktree.

[Platform requirements](/reference/compatibility) describe the supported IDEA and runtime.

## Kast cannot finish a query

Read the reported cause and recovery action.
If a workspace container reports `STOPPED`, see [Manage the container](/reference/installation#3-manage-the-container).
If the cause concerns search scope, narrow the question to a known function, package, or directory.
An unfinished query with no matches does not prove absence.

If a source reference expires, use the reported recovery action.
For a later output page, use the issued result reference or continuation.
Do not repeat a query only to recover that page.

## An edit has an uncertain outcome

Inspect the source and [change receipt](/reference/change#read-the-receipt) before another write.
Review the diff and run your project's tests.
