Kast gives your agent guidance for the installed `kast` command.
These steps assume that Kast already exists on your machine.

<span id="choose-your-agent" />
<span id="1-connect-your-agent" />

## Select your agent

<Tabs sync={false}>
  <Tab title="Codex">
    Install the CLI guidance:

    ```shell
    kast install codex
    ```

    Start a fresh Codex session in your Kotlin repository or worktree.
  </Tab>
  <Tab title="Copilot">
    Install the CLI guidance:

    ```shell
    kast install copilot
    ```

    Start a fresh Copilot session in your Kotlin repository or worktree.
  </Tab>
  <Tab title="Pi">
    Install the CLI guidance:

    ```shell
    kast install pi
    ```

    Start a fresh Pi session in your Kotlin repository or worktree.
  </Tab>
</Tabs>

The default composition uses the CLI. It installs no MCP registration or Python hook.
For optional MCP, add `--mcp` to your agent's command.
The [integration reference](/reference/integrations#optional-mcp) gives its runtime needs.

## Refresh guidance

Core replacement does not refresh copied skills or cached provider resources.
If Kast reports `HARNESS_REFRESH_REQUIRED`, repeat your agent's installation command before a fresh session.
Keep `--mcp` if you select the optional MCP composition.

To export the canonical skill, use `kast install skill`.
The default parent is `./.agents/skills`. Existing different or incomplete skills stay unchanged.
See [skill exports](/reference/integrations#3-export-the-canonical-skill) for the output option and rejection outcomes.
