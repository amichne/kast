For a first result, follow [Install Kast](/start) and [the controlled exercise](/tutorials/first-query).

A complete call meets the proof rules of the fixed compiler-static model. Those rules apply to its source scope.

A retained result keeps the original answer. Reading more pages cannot make an incomplete answer complete.

[Reference](/reference) defines fields and result kinds. [Guides](/how-to) shows how to use this evidence.
