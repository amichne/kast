The output form selects the kind of row. A row can hold a symbol, source occurrence, traversal record, binding, value path, or impact witness.

Each row keeps its proved identities and evidence. Two symbols with the same display name need not be the same declaration.

An occurrence row keeps facts about a source site. A traversal row keeps facts about a hop. A binding row keeps named cells. A value path keeps the origin of each transfer.

The result that produced the rows owns their coverage and stated limits. A selected row cannot prove coverage of rows left out.

[Query outputs](/reference/api#choose-the-result-you-need) defines valid forms. [Composition](/reference/composition) defines row changes and identity checks.
