Kast gives coding agents compiler-grounded search, diagnostics, and approved
source changes for the Kotlin project open in IntelliJ IDEA.

## Start with one search

1. [Install Kast and connect your agent](/start).
2. Ask: **“Use Kast to find the class OrderService.”** Use a class from your project.
3. Check the returned status and matches, then reuse the result for follow-up work.

<Note>
  Kast reads saved, indexed project state. Keep the repository open in IDEA,
  finish Gradle import and indexing, and save edits before requesting evidence.
</Note>

## Know what an answer proves

| Status | How to use it |
| --- | --- |
| **complete** | Rely on the answer within its declared scope and limits. |
| **qualified** | Read the attached limitations before drawing conclusions. |
| **rejected** | Resolve the reported problem before using the answer. |

Keep returned `ref` values unchanged for follow-up tools.
[Read a response](/reference/responses) explains the result fields.
