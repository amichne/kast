Callback observations preserve the occurrence, named lexical container, anonymous body, and named-edge policy. Their static facts do not establish runtime activation.

## Named-edge policy

| Policy | Named-edge meaning |
| --- | --- |
| `EXCLUDED` | Invocation is absent from named callers, with its reason. |
| `ADMITTED_DIRECT` | A compiler-confirmed immediate invocation admits a named edge while preserving its anonymous body. |
| `ADMITTED_INLINE` | Inline policy admits a named edge while preserving the anonymous owner. |
| `UNAVAILABLE` | Ownership remains incomplete. |

An admitted named edge keeps its anonymous owner evidence. An excluded edge keeps the reason and exact excluded occurrence.

## Binding forms

| Binding | Meaning |
| --- | --- |
| `BOUND` | An explicit argument supplies the value. |
| `DEFAULT` | A declared default supplies the value. |
| `DIRECT` | A literal or anonymous function is invoked directly. |
| `DEPENDENCY_CONTRACT` | Compiler contract and dependency binary identity establish a supported calls-in-place effect. |
| `DEFERRED_DEPENDENCY` | Reviewed dependency binaries establish initializer supply without an invocation claim. |
| `UNAVAILABLE` | The mapping is unavailable. |

`BOUND` records compiler argument-to-parameter mapping. `DEFAULT` preserves the defining formal and default expression rather than an invented argument.

`DIRECT` keeps the actual invocation owner without a receiving formal. `DEFERRED_DEPENDENCY` establishes initializer supply without an invocation site or count.

## Invocation scan

| Scan | Meaning |
| --- | --- |
| `EXHAUSTIVE` | The admitted scan finished. Empty invocations establish no supported invocation sites in that scanned flow. |
| `INCOMPLETE` | A limit or unsupported flow prevents an absence claim. |
| `NOT_APPLICABLE` | A directly invoked body has no receiving formal to scan. |

The scan states the extent of formal-invocation enumeration. An exhaustive scan can still need proof that a nested invocation owner executes.

Each parameter invocation keeps `forwardings`, including an empty array. Each hop identifies the source formal, supplied expression, and destination binding.

`owner_bindings` preserves a nested anonymous owner's supply and mapping. `callable_observations` records symbolic formal invocations and source-less compiler targets.

## Declared dependency effects

Calls-in-place evidence keeps `EXACTLY_ONCE`, `AT_MOST_ONCE`, `AT_LEAST_ONCE`, or explicitly declared `UNKNOWN`.

The effect must belong to the compiler-selected formal and reviewed binary identity. Missing, duplicate, or unsupported effects return `DEPENDENCY_CONTRACT_EFFECT_UNPROVEN`.

These kinds describe the declared contract. They do not count runtime invocations or invent dependency body sites.

## Unresolved obligations

| Evidence | Limit |
| --- | --- |
| Nested callable owner | `NESTED_CALLBACK_EXECUTION` |
| Library mapping | `EXTERNAL_CALLABLE` and `OUTSIDE_DOMAIN` |
| Local initializer | `STORED_CALLBACK` |
| Returned literal | `RETURNED_CALLBACK` |
| Unsupported supply | `UNSUPPORTED_CALLBACK_SUPPLY` |
| Recursive forwarding | `CALLBACK_CYCLE` |

The list groups ownership and transfer failures. Work, time, result, and byte limits keep their separate causes.

`FINALLY_UNSUPPORTED` and `ABRUPT_COMPLETION` preserve unsupported control-flow effects. An empty invocation list cannot erase an incomplete scan or unresolved obligation.

## Candidate source action

The anonymous body's issued `candidateSelector` supplies this action's `candidateRef`.

```json
{"request":{"type":"READ_SOURCE","candidateRef":"<issued candidateSelector>"}}
```

The selector needs its admitted source state. It does not select the enclosing named function.
