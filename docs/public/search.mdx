Resolve one declaration, keep its exact reference, then trace its affected uses.
Your [connected agent](/agent-harnesses) writes the query.

## 1. Find a declaration and inspect its source

Substitute your name and directory:

```text wrap
Use Kast to find submitOrder under checkout in main. Show matching signatures, locations, and coverage. Stop so I can choose the exact function.
```

Select by signature and file. Ask the agent to read its source and keep its exact reference for follow-up queries.

For a Kotlin interface, use `declarationKinds: ["CLASS"]`. The request's `CLASS`
family includes supported class-like declarations, including interfaces and
objects; returned symbols report `kind: "classlike"`. `INTERFACE` and
`CLASSLIKE` are not accepted request kind values.

```json
{
  "request": {
    "type": "RUN",
    "source": {
      "type": "SEARCH_DECLARATIONS",
      "declarationName": "CacheManager",
      "declarationKinds": ["CLASS"],
      "scope": {
        "type": "PACKAGE",
        "packageName": "example.cache",
        "includeSubpackages": false,
        "sourceSetNames": ["main"]
      }
    },
    "output": {"type": "SYMBOLS", "fields": ["NAME", "LOCATION", "SIGNATURE"]}
  }
}
```

Find an interface method with `declarationName: "execute"` and
`declarationKinds: ["FUNCTION"]` in the same package. Inspect the signature's
qualified identity to select `example.cache.CacheManager.execute` from its
overrides. Exact name matching returns all eligible overloads and owners.

Exact-name discovery uses name indexes and a supplemental declaration scan to
prove completeness within the admitted scope. Apply known directory, package,
source-set, and declaration-kind constraints before searching. An exact name
alone does not bound the number of source files the completeness scan visits.

`AT_LOCATION` selects the nearest containing named declaration. An offset inside
the method's generic parameter list selects that method; an offset on
`manager.execute(...)` selects its enclosing declaration. It does not resolve
the `execute` use-site token to the interface method. To establish that link,
select the exact method and request `REFERENCES` or `CALLERS` in the intended
relationship domain. Use occurrence evidence to identify the exact use site.
Offsets and returned ranges use UTF-16 code units, not byte offsets or line
numbers. Recompute them from the current file after edits.

| Check | Why it matters |
| --- | --- |
| Signature | Distinguishes overloads. |
| Location | Confirms the intended repository and declaration. |
| Coverage | Reports whether the requested search finished. |
| Exact reference | Carries the selected identity into the next request. |

## 2. Trace the selected declaration

For a function, interface method, or type:

```text wrap
Use the exact Kast reference we selected to TRACE affected uses across the workspace. Show signatures, locations, occurrence evidence, and completion. Keep the result for follow-up reads.
```

The agent passes the issued reference unchanged. Replace this placeholder with
the `ref` from the preceding response:

```json
{
  "request": {
    "type": "RUN",
    "source": {"type": "SYMBOL_REFS", "symbolRefs": ["<issued ref>"]},
    "steps": [{"type": "TRACE", "expansionScope": {"type": "WORKSPACE"}}],
    "output": {"type": "SYMBOLS", "fields": ["NAME", "LOCATION", "SIGNATURE"]},
    "retention": "RETAIN",
    "executionBudget": {"maxElapsedMs": 30000}
  }
}
```

TRACE covers references, implementations or overrides, direct callers, and one
further caller layer. A type trace also covers its direct functions and
properties. Kast groups declarations while retaining occurrence evidence.
The topology is fixed; TRACE must be the final step and requires `SYMBOLS` output.

This example requests 30 seconds for the trace. The host can admit less;
read the returned execution budget. The elapsed grant is shared by all branches.

Discovery scope selects the seed. `WORKSPACE` lets the trace reach clients in
other modules. Choose `SOURCE_DOMAIN` only when the question excludes those
destinations. `RETAINED_SEED` restricts expansion to the selected capability's
scope. A later filter cannot reduce native search work. See [Query forms](/reference/api#apply-only-the-steps-you-need).

## 3. Read completion and follow recovery

The fixed `COMPLETE_ONLY` policy requires a complete compiler-static answer.
If proof is incomplete, Kast returns `COMPLETION_UNPROVEN` with its finite cause
and recovery evidence when available. A retained preview contains established
facts; it does not prove completion. Use the retained result reference with
`READ_RESULT` to inspect proof or page a completed answer. `RESUME` accepts only
issued output continuations. Semantic page continuation belongs to the internal
runner. A historical checkpoint and a result cursor cannot authorize execution.

TRACE gathers incoming paths before its final grouping. Budget exhaustion still
returns a completion rejection with any retained proof. A larger requested
timeout does not remove host ceilings.

For a question about only direct callers or implementations, use one
`EXPAND_RELATION`. For a graph with a requested depth, use `WALK` and inspect its
hop evidence. These forms are available in [Query forms](/reference/api).

If `WALK.maximumDepth` and `WALK.expansionScope` are omitted or null, `WALK` traverses
the reachable graph across the workspace to exhaustion. A narrow discovery
scope does not narrow those destinations. Set the requested depth or destination
scope explicitly when the question requires that bound. Keep `COMPLETE_ONLY`:
resource exhaustion leaves proof incomplete, and later output filters do not
reduce native enumeration work.

Invocations inside lambdas preserve separate ownership. Static callback paths do not prove runtime execution. See [Callback evidence](/reference/callbacks).

## Start from remembered text

```text wrap
Use Kast to find functions containing the word retry under checkout in main. Show a matching line for each function, then let me choose one to inspect or trace.
```

Use one case-sensitive ASCII word beginning with a letter or underscore. Phrases, substrings, qualified literals, and regular expressions are rejected. A word match explains discovery. A relation query establishes callers. Unsupported containers or a stopped scan leave coverage incomplete.

## Keep the investigation current

Pass issued references unchanged. After a stale-reference or unavailable-state failure, search again. Edits, IDEA restarts, and retention expiry can invalidate saved work.

A new opaque reference for the same signature and location does not by itself
prove a source change. Read `reference_acquisitions` when Kast reacquires an
exact handle, and retain each response's semantic basis. Signature and location
help select a declaration; they do not replace handle authority. Continuations
and source snapshots require their original basis. See [read-limit diagnostics](https://github.com/amichne/kast/blob/main/docs/hosted-read-configuration.md#read-the-evidence)
for the bounded epoch-movement signals.

Use [What an answer proves](/concepts/evidence-boundaries) for conclusions, [Results](/reference/responses) for progress, or [Combine query results](/query-pipelines) for retained composition.
