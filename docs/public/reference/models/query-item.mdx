The output form selects the row kind. A row can describe a symbol, occurrence, traversal record, binding, value path, or impact witness.

Each row keeps its established identities and evidence. Equal display names do not establish declaration equality.

Occurrence and traversal rows keep source-site or hop facts. A binding row keeps named cells, while a value path keeps transfer provenance.

The producing result owns coverage and qualifications. Row selection cannot prove coverage of excluded rows.

[Query outputs](/reference/api#choose-the-result-you-need) defines legal forms. [Composition](/reference/composition) defines row transitions and identity comparison.
