## Before you install

Agent integrations need uv 0.12.9 or later and Python 3.12 or 3.13.
The locked task script can download Python and pinned dependencies on its first run.

Use an Apple silicon Mac with a Kotlin Gradle repository. Select IDEA build `262.*` with bundled Kotlin and Java 25 JBR.

If IDEA uses another path, change the path in this command.

```shell
idea="/Applications/IntelliJ IDEA.app/Contents"
cat "$idea/Resources/build.txt"
cat "$idea/jbr/Contents/Home/release"
```

Make sure that the build starts with `IU-262.` or `IC-262.`. Make sure that the runtime reports Java 25 and `aarch64` or `arm64`.

## 1. Install the selected release

Run the public installer from a terminal.

```shell wrap
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/amichne/kast/main/install.sh)"
```

By default, the installer selects Control and Host from the same stable release.
It uses GitHub's public release redirect, without an anonymous API request.
The version URL must come from `amichne/kast`. Before installation, Kast examines artifact checksums and contracts.

If release selection fails, the error keeps the HTTP cause. It names `--version <major.minor.patch>` for recovery.
The installer replaces the selected Host directory. A changed receipt or file inventory does not block replacement.
If replacement fails, Kast restores the prior Host and receipt.
If restoration fails, Kast keeps evidence for recovery.

The installer offers the Codex plugin. Accept the default. Restart IDEA and Codex to use it.

To install without a prompt, append `-- --install-codex-plugin`. To skip the Codex plugin, append `-- --skip-codex-plugin`.

For structured error details, append `-- --verbose`. Keep the `--` separator before installer options.

<Accordion title="Latest developer build">
  Developer builds use the published prerelease channel.

  ```shell wrap
  /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/amichne/kast/main/install.sh)" -- --developer-latest
  ```

  The installer prints the selected version and source revision. Your checkout and installed version do not select the published candidate.

  Terminal downloads show progress. Ctrl-C stops installation. `kast upgrade` keeps the developer channel.

  The developer installer resets stale Kast state first. With the stable installer, `--force` requests the same cleanup.

  Reset removes old Kast settings, launcher backups, and the default Pi and Copilot extensions.
  Reset also removes duplicate Kast plugins that it recognizes.
  Stable locks stay in place. Unrelated extensions and plugins stay in place.

  Use `--dry-run` to preview the plan. It leaves files and registrations intact. To skip the Codex plugin, use `--skip-codex-plugin`.
</Accordion>

<Accordion title="Another IDEA installation">
  Set the path to the IDEA app.

  ```shell wrap
  /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/amichne/kast/main/install.sh)" -- --idea-home "/Applications/IntelliJ IDEA.app"
  ```
</Accordion>

## 2. Load the plugin and inspect state

Restart IDEA to load Host. Examine the installed version, command path, and saved connections.

```shell
kast status
```

Status reports receipts and passive runtime evidence.
An empty list of registrations does not describe Codex's plugin catalog.
`EPOCH_UNAVAILABLE` does not prove that an installed MCP session failed.
Use the semantic exercise in step 3 to examine that session.

If `XDG_CONFIG_HOME` is nonempty, the command path is `$XDG_CONFIG_HOME/kast`. Otherwise, it is `$HOME/.local/bin/kast`.

If the shell cannot find the command, use the absolute path from the installer. Add its directory to `PATH` when needed.

The installer reports a missing `PATH` entry. It does not change shell profiles.

### Coordinator endpoint

Installations use a private endpoint. If a saved `codex-control` selection is admitted, replacement changes it to `private`.

The installer rejects an explicit `codex-control` selection. It does not start a broker or publish desktop discovery. The plugin's MCP session prepares IntelliJ. Codex owns its App Server and control socket.

Use [integration options](/reference/integrations) for custom connections.

## 3. Prove a semantic connection

[Connect your agent](/reference/integrations). Complete [the first-query exercise](/tutorials/first-query) in the intended worktree.

Installation success does not prove which Host IDEA loaded. It does not prove that the workspace is ready. [Lifecycles](/reference/lifecycles) separates those facts.

For recovery or removal, use [Manage Kast](/reference/management). Before another installation try, keep the failed stage and recovery path.
