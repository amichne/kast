After [installing Kast](/start), connect your agent to Kast with CLI guidance. The agent handles the tool calls while you describe the work.

<span id="choose-your-agent" />
<span id="1-connect-your-agent" />

## Select your agent

<Tabs sync={false}>
  <Tab title="Codex">
    ```shell
    kast install codex
    ```
  </Tab>
  <Tab title="Copilot">
    ```shell
    kast install copilot
    ```
  </Tab>
  <Tab title="Pi">
    ```shell
    kast install pi
    ```
  </Tab>
</Tabs>

Start a fresh agent session in your Kotlin repository or worktree.

For optional MCP, add `--mcp` to your agent's command. See the [MCP runtime requirements](/reference/integrations#optional-mcp).

## Refresh guidance

A Kast update does not refresh copied skills or cached provider resources.
If Kast reports `HARNESS_REFRESH_REQUIRED`, repeat your agent's installation command before a fresh session.
Keep `--mcp` if you select the optional MCP composition.

To export the canonical skill, use `kast install skill`.
The default parent is `./.agents/skills`. Existing different or incomplete skills stay unchanged.
See [skill exports](/reference/integrations#3-export-the-canonical-skill) for the output option and rejection outcomes.
