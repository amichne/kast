<Warning>
  The installed endpoint does not publish a direct `diagnostic.check` route.
  Hosted AddDeclaration planning and verification invoke the same canonical
  diagnostic service internally within their typed proof obligations.
</Warning>

## Canonical contract

The diagnostic operation remains in the typed operation registry, command
graph, and `kast --schema`. Its presence defines a stable command and wire
identity; it does not grant callers a separate diagnostic capability.

Use the [CLI reference](/reference/cli) as the availability boundary.
