---
title: "Workspace control"
description: "Understand when the hosted workspace_lifecycle tool is needed."
icon: "folder-open"
---

Ordinary Kast queries prepare the exact Gradle repository or worktree from
the agent's session. They wait for IDEA readiness; no separate open or sync
call is required.

`workspace_lifecycle` is an App Server tool for explicit project control,
such as inspecting, presenting, releasing, or closing a selected project.
It is absent from direct MCP and tool RPC catalogs. Its generated
**Workspace lifecycle** entry in the API / RPC tab lists the admitted
actions and approval boundary.

See [how Kast works](/concepts/architecture) for the normal request flow.
