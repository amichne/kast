# Request-response fixture

This directory contains a standalone Gradle project with Kotlin `2.4.21`, JDK `25`, and compiler warnings as errors.
It is separate from the Kast module graph.

`src/main` and `src/test` own the semantic fixture inputs.
The separate `fixtureRuntime` source set owns `runtime/kotlin` and `oracle`.
Keep those assertion sources outside the imported semantic roots.

`oracle/RequestResponseOracle.kt` owns the corrected positive rows, forbidden witnesses, predicates, and milestone membership.
`OracleEvaluation.kt` evaluates those expectations separately from query completion.
Keep the original constructor and nested-lambda seeds when a later transfer fails.

`initial-freeze.sha256` identifies the original sources and corrected oracle.
`derived-sources.sha256` identifies supplemental variants and controls.
`segment4-controls.sha256` identifies the renamed carrier, constant callback, and user-defined `invoke` controls.
`segment4-return-controls.sha256` identifies the normal, discarded, abrupt, and finally cases for anonymous returns.

`segment6-library-controls.sha256` identifies the source-defined `firstOrNull` control.
`segment5-branch-controls.sha256` identifies normal, bottom-type, Unit, and discarded branch controls.
`segment5-entry-controls.sha256` identifies immutable and reassigned mutable destructuring controls.
`segment5-source-function-controls.sha256` identifies immutable and reassigned mutable function suppliers.

The runtime procedure examines all eight source manifests.

`runner-inputs.sha256` identifies the independent runtime procedure.
Examine a changed hash against its owning source before a deliberate manifest update.

From the repository root, run:

```sh
mise exec -- ./gradlew --no-daemon --max-workers=1 -p experiments/representation-impact/request-response-fixture assertFixture --console=plain
```

This command asserts fixture behavior, hashes, and pure oracle decisions.
It does not establish K2 transfers or milestone completion.
Native compiler assertions reside in `:relation:intellij:nativeFixtureTest`.
Full query and retention assertions reside in `:runtime:hosted:nativeFixtureTest`.
Use focused `NativePacket*` selectors.
Keep each exact procedure and source identity in `evidence`.

Keep reports in `results` and compiler receipts in `evidence`.
Keep `.gradle`, `.kotlin`, and `build` caches under this project and outside Git.
Library reviews must identify the native library bytes separately from this fixture's runtime library.
The supplemental `firstOrNull` captures include library declarations.
The original S2 request keeps `SymbolLibraryPolicy.EXCLUDE`.
