Kast supports Apple silicon macOS and an on-disk Kotlin Gradle repository. IDEA must use build `262.*`, its bundled Kotlin plugin, and Java 25 JBR. Other IDEA release lines reject admission.

Use your installed client's catalog as the contract authority:

| Client | Installed contract authority |
| --- | --- |
| MCP | `tools/list` |
| Tool RPC | `catalog` |
| Codex App Server | Conversation's provider catalog |

After an upgrade, rediscover tools. If a workspace reference is stale, search again.

## Recorded release pair

This recorded release pair dates from October 5, 2026. The installer can select newer stable releases.

| Component | Release | Source | Installed part |
| --- | --- | --- | --- |
| Control | [0.3.1](https://github.com/amichne/kast/releases/tag/control-v0.3.1) | [`c2582dbf0`](https://github.com/amichne/kast/commit/c2582dbf0c3bbee83acc7db4f426d5836ece0710) | Command and adapters |
| Host | [0.4.0](https://github.com/amichne/kast/releases/tag/host-v0.4.0) | [`d1305fe51`](https://github.com/amichne/kast/commit/d1305fe51e35855e65a1024ce88d094a90e8a341) | IDEA plugin for `262` |

Compatibility depends on the runtime protocol, operation registry, wire schema, capabilities, and IDEA/Kotlin admission. Equal version numbers do not establish those contracts.

The [installer](/start) selects stable components independently. To pin this pair with a downloaded public installer, use:

```shell
bash install.sh --version 0.3.1 --host-version 0.4.0
```

`--version` selects Control. `--host-version` selects Host. The earlier Host 0.3.0 and Control 0.2.0 pair uses a different wire contract. Both components need upgrades. After installation, restart IDEA and affected agents.

Control-only installation reuses a live Host with a matching contract. To install only Host and keep Control in place, use:

```shell
bash install.sh --host-only --version 0.4.0
```

In Host-only mode, `--version` selects Host. Restart IDEA to load the plugin. Control must still match the Host contract.
