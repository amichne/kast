A diagnostic records IDEA's severity, message, and source location. Its producing response states the requested scope and coverage.

Complete empty coverage can establish no reported diagnostics within that admitted scope. Incomplete empty coverage cannot establish that conclusion.

IDEA diagnostics do not establish project build success. A change receipt describes a separate source effect and its examination scope.

[Inspect diagnostics](/how-to/inspect-diagnostics) supplies the procedure. [Evidence limits](/reference/evidence-boundaries) defines the supported conclusion.
