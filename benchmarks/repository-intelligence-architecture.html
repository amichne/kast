Project scope

Compiler-bound label retrieval

A versioned sidecar may improve natural-language recall, never semantic authority.

Fail-closed certainty guard. Natural-language and regex discovery with missing required compiler semantic tables returns REPOSITORY_INDEX_INVALID. Positive evidence from incomplete compiler coverage returns REPOSITORY_COVERAGE_INCOMPLETE. Neither state can collapse to EMPTY or ANSWERED.

Flow scope

One question, one frozen generation.

This trace shows the normal natural-language resolve path with the optional version-1 label sidecar. Other intents split only after validation and snapshot admission.

Request / decision

Design principles made executable

Parse at the boundary

Unsafe strings become validated scope, path, syntax, and limit types before execution.

Carry the proof

Generation, coverage, identity, evidence class, and bounds survive into the response.

Route closed intents

Each question family has one explicit algorithm and relation vocabulary.

Fail closed on snapshot drift

Generation movement and stale label content stop the query instead of silently changing its evidence.

Keep retrieval subordinate

Approximate discovery can suggest; only compiler facts can authorize.

Project, do not recompute

TOON, JSON, and human views render the same canonical result value.
