## 1. Match the cause to its owner

| Failure | Recovery |
| --- | --- |
| Missing tools | Examine registration and restart the affected client. |
| Host or schema mismatch | Compare selected executable, installed contract, and loaded IDEA plugin. |
| Trust, save, import, or indexing blocker | Resolve the named state in the exact IDEA project. |
| Completion unproven | Inspect retained evidence and the finite proof cause. |
| Stale or unavailable retained state | Establish current authority or start a new query. |
| Uncertain source effect | Examine source and recovery evidence before another write. |

`health_check` reports readiness when the catalog exposes it. It does not establish declaration or relationship evidence.

If the client selects the wrong root, restart it from the intended Gradle worktree.

For contract mismatch, install compatible components. Restart IDEA and the client, then rediscover the installed catalog.

A hosted thread also needs admitted ownership, generated namespace, and workspace binding. Reconnection does not repair those facts automatically.

For retained-state failure, preserve expiry, eviction, owner, dependency, and stale-basis causes. A larger budget cannot recover missing state.

Revocation receipts also have finite retention. After reclamation, an unavailable token does not establish its historical cause.

## 2. Establish an uncertain source effect

If a response is lost after dispatch, keep plan identity and phase evidence. Read current source before another write.

Use [change recovery](/reference/change#read-the-receipt) to establish the effect. Known pre-write rejection and uncertain post-dispatch settlement need different actions.

The hosted App Server can fence the workspace after an uncertain mutation. [Lifecycles](/reference/lifecycles#hosted-workspace-settlement) describes reconciliation.

## 3. Establish recovery

After the cause changes, repeat the original read in the same worktree. Compare its identity, declared scope, and completion evidence.

If original retained authority is unavailable, start a fresh query. Do not reconstruct token strings or transfer earlier cursors to a new result.

[Staleness](/reference/staleness) defines those rules. [Retained evidence procedures](/how-to/read-retained-evidence) apply when original state remains valid.
