Support callables have separate availability: direct MCP exposes `health_check`; hosted App Server exposes `workspace_lifecycle`. The [generated OpenAPI document](https://raw.githubusercontent.com/amichne/kast/main/docs/public/reference/callables.openapi.json) defines their inputs and outputs.

The [authored schema](https://github.com/amichne/kast/blob/main/app-server/src/main/resources/io/github/amichne/kast/appserver/query/tools.schema.json) owns shared definitions and metadata. Use per-tool `parameters.json` for input checks. Preserve closed variants and `$ref` links.

## Read a schema without reading every definition

Start with required root properties, then select the action variant. For `RUN`, choose a source, necessary steps, and output. [Query forms](/reference/api) explains supported combinations.

Defaults come from admission. Schema validity does not establish current identity, complete coverage, or permission to mutate.

## Samples and observed responses

Generated samples include valid and deliberately invalid contract cases. Their opaque references are illustrative; they are not reusable tokens or native response recordings.

To reproduce, use the linked source checkout. Send each `request` to `kast-tool-rpc-complete call query_symbols` in order, substituting newly issued references. Pause builds and edits during composition. Establish your run's own counts and coverage.

Captured requests and responses pass generated shape checks. Those checks do not replay IDEA.

OpenAPI `/callables/…` labels are documentation identifiers, not HTTP endpoints. Use [MCP](/reference/mcp-catalog) or [Tool RPC](/reference/rpc-catalog) for transport wrappers.
