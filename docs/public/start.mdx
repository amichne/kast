Use Kast through its native CLI with the agent you already use.
These steps assume that `kast` is installed and available in your terminal.

## Before you start

<span id="before-you-install" />

Use an Apple silicon Mac and a Kotlin Gradle project.
Use IntelliJ IDEA `262.*` with its bundled Kotlin plugin and Java 25 JBR.
Install your chosen agent CLI.

1. Select the development build.
2. Install your agent's CLI guidance.
3. Ask about your code.

## 1. Select the development build

<span id="1-install-kast" />

Use the latest qualified build from main:

```shell
kast upgrade --channel main
```

The `main` channel tracks qualified development builds.
The installer reports the selected build and its activation outcome.
If it reports a restart requirement, repeat the command with `--restart-ide` to permit a normal IDEA restart.

[Installation and activation](/reference/installation) explains build selection, pins, and recovery outcomes.

## 2. Install agent guidance

<span id="choose-your-agent" />
<span id="1-connect-your-agent" />
<span id="2-restart-intellij-idea" />
<span id="2-restart-your-tools" />
<span id="3-connect-your-agent" />

<Tabs sync={false}>
  <Tab title="Codex">
    ```shell
    kast install codex
    ```
  </Tab>
  <Tab title="Copilot">
    ```shell
    kast install copilot
    ```
  </Tab>
  <Tab title="Pi">
    ```shell
    kast install pi
    ```
  </Tab>
</Tabs>

These commands install guidance for the native CLI.
MCP is optional. The default guidance needs no MCP registration or session hook.

Start a fresh agent session in the same Kotlin repository or worktree.
If an upgrade reports `HARNESS_REFRESH_REQUIRED`, repeat your agent's installation command before the fresh session.

## 3. Ask about your code

<span id="3-ask-your-agent" />
<span id="4-establish-readiness" />
<span id="what-your-first-result-establishes" />

Give your agent the function's file and name.

<Prompt description="Find the callers of your function" actions={["copy"]}>
Use the Kast CLI to find the callers of this function. Show the source locations and explain how they use it.
</Prompt>

The persistent Host in IDEA supplies compiler analysis for CLI calls.
Kast prepares the project as needed. The first query can wait for Gradle import and indexing.
Use the returned locations to continue your task.

To inspect the CLI yourself, use:

```shell
kast describe query --section input
kast describe query --section examples
```

Those commands read the installed contract. They do not establish a semantic connection.

Try [example questions](/search), read the [CLI reference](/reference/cli), or use [Help](/troubleshooting).
