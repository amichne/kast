The managed product targets macOS ARM64 and Linux x86-64.
Kast supplies the admitted IntelliJ, Kotlin plugin, and Java runtime bytes. Your project's JDK does not replace that runtime.
There is no user-selected desktop IDEA or container setup path.

The product record binds the immutable vendor base and exact component identities.
Control admits the actual IDEA and Kotlin builds against the selected runtime contract.
The runtime protocol, operation registry, wire schema, and capabilities must match exactly.
Native acceptance and publication of this managed-only product are not yet complete; see [installation](/reference/installation).

## Tool contracts

Use the installed Kast skill and the schema from your current session.
MCP clients get the tool contract from `tools/list`. Tool RPC clients use `catalog`.
Copy issued references unchanged.

Before semantic work, Kast examines the runtime protocol, operation registry, and wire schema.
It also examines supported features and IDEA/Kotlin support.
Equal component versions alone do not establish compatibility.

## Select a development build

Use the [setup guide](/start) for an initial installation. To update an installed CLI to the latest published development build, use:

```shell
kast versions
kast upgrade --channel preview
```

Control supplies the command and agent resources. Host supplies the IDEA plugin and semantic runtime.
Build selection resolves one complete product, not independently chosen components.
An exact version or commit selector records a pin. See [build selection](/reference/installation#pin-a-published-build).

## Loaded Host identity

```shell
kast status --json
```

Installed build identity describes disk contents. Workspace Host observations describe admitted running processes.
Inspect `workspaces`, not the old installation-wide `applicationHost` field, for a managed product.
Status remains passive. The next explicit semantic request prepares the selected workspace generation.

A loaded Host does not prove readiness in a particular project or worktree.
A successful query keeps its own scope and completion evidence.
