An exact reference carries a declaration identity proved by the compiler into the next request. The query that issued it also states its scope and coverage.

## Public fields

| Field | Meaning |
| --- | --- |
| `ref` | An opaque handle. Kast checks its identity on the next request. |
| `location` | Where the proved declaration is found. |
| `signature` | The identity and facts about a callable or property, proved by the compiler. |
| `source` | A bounded slice of committed source, if requested. |

Use the signature and location to tell candidates apart. Pass the issued `ref` so Kast can check the selected identity.

`SOURCE` adds a bounded slice of committed source. To read an anonymous body or exact occurrence, use the distinct anchored `READ_SOURCE` action.

Source positions use UTF-16 code units. A byte offset or line number does not replace the encoded range.

## Local declarations

A local property uses a `LOCAL_PROPERTY` signature. It states the type and whether it is `VAL` or `VAR`. A local named function uses a `LOCAL_FUNCTION` signature.

Each identity keeps the file and compiler identity. It also keeps the declaration range, the range of its containing declaration, and bounded lexical owner ranges.

The same name can refer to different declarations in different scopes. A local property identity does not prove how values are assigned to it.

To reacquire a local reference, the owning file must stay unchanged. After a local edit or move, run discovery again. Do so even if the displayed signature stays the same.

## Evidence limits

A local function identity does not prove that its deferred body runs. An anonymous body's lexical container does not become its named caller by default.

For callback and value-flow proof, read [Program tracing](/reference/program-tracing). [Staleness](/reference/staleness) defines reuse.

## Output selection example

This output adds fields to the required identity and kind.

```json
{"type":"SYMBOLS","fields":["NAME","LOCATION","SIGNATURE","SOURCE"]}
```

[The query item schema](/reference/models/query-item) defines encoded rows. [The recorded lookup](/reference/walkthrough#1-find-a-declaration-and-inspect-its-source) illustrates source output.
