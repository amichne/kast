All connections bind requests to the exact Gradle repository or worktree.
The installed catalog is the authority for a release's tool inputs.

| Connection | Discover tools | Result contract |
| --- | --- | --- |
| Direct MCP | `tools/list` | [MCP](/reference/mcp-catalog) |
| Tool RPC | `kast-tool-rpc-complete catalog` | [Tool RPC](/reference/rpc-catalog) |
| Codex App Server | Provider catalog for the conversation | Hosted callable schemas in this pane |

The direct transports expose `query_symbols`, `source_read`,
`check_diagnostics`, candidate tools, `health_check`,
`validate_workspace`, and one-call `change`.
The App Server additionally exposes `workspace_lifecycle` for explicit
project control. Ordinary semantic calls prepare the workspace themselves.

Read the outer result and its canonical semantic document. Keep exact
`ref` values and qualifications unchanged. After upgrading Kast, discover
the catalog again.

For installation, use [Install Kast](/start). The repository's
[tool RPC guide](https://github.com/amichne/kast/blob/main/docs/tool-rpc.md)
contains the included Copilot CLI and Pi adapter setup.
