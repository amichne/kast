Setup takes three steps: install Kast, connect your agent, and run one query.

## Before you start

<span id="before-you-install" />

You need:

- An Apple silicon Mac.
- A Kotlin Gradle project.
- IntelliJ IDEA 2026.2 or 2026.3 (build `262.*` or `263.*`), with its bundled Kotlin plugin and Java 25 JetBrains Runtime (JBR).
- The Codex, Copilot, or Pi CLI.
- Python 3.12 or 3.13, available as `python3` on your `PATH`.
- For `kast upgrade` and the optional MCP setup: the uv Python package manager, version 0.12.9 or later.

<Tip>
  On Linux x86-64, or to run Kast without desktop IDEA, see [Run Kast without desktop IDEA](/reference/installation#manage-isolated-workspaces).
</Tip>

<Steps titleSize="h2">
  <Step title="Install Kast" id="1-install-or-update-kast">
    <span id="1-install-kast" />
    <span id="1-select-the-development-build" />

    Run this command from any directory. You do not need a checkout of the Kast repository.

    ```shell
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/amichne/kast/main/install.sh)" -- --developer-latest --skip-codex-plugin
    ```

    `--developer-latest` selects the latest development build. `--skip-codex-plugin` skips the installer's Codex prompt; step 2 connects every agent, including Codex.

    Then restart IntelliJ IDEA so that it loads Kast.

    If your shell cannot find `kast`, add the directory that the installer prints to your `PATH`, then open a new terminal.

    <Accordion title="Already installed? Update instead">
      Installing or updating can end running Kast sessions. Save your work in your agent first.

      ```shell
      kast upgrade --channel main --restart-ide
      ```

      `--restart-ide` lets Kast restart IDEA when the update needs it.
      See [Install and update Kast](/reference/installation) to pin a version or recover a failed update.
    </Accordion>
  </Step>

  <Step title="Connect your agent" id="2-install-agent-guidance">
    <span id="choose-your-agent" />
    <span id="1-connect-your-agent" />
    <span id="2-restart-intellij-idea" />
    <span id="2-restart-your-tools" />
    <span id="3-connect-your-agent" />

    Install guidance that teaches your agent when and how to run `kast`:

    <Tabs sync={false}>
      <Tab title="Codex">

        ```shell
        kast install codex
        ```

      </Tab>
      <Tab title="Copilot">

        ```shell
        kast install copilot
        ```

      </Tab>
      <Tab title="Pi">

        ```shell
        kast install pi
        ```

      </Tab>
    </Tabs>

    Open your project in IntelliJ IDEA, and keep IDEA open while you work. Then start a new agent session in the same project.

    You do not need MCP to ask about your code. Edits through Kast need the [optional MCP setup](/reference/integrations#optional-mcp).
  </Step>

  <Step title="Run your first query" id="3-run-your-first-query">
    <span id="3-continue-your-work" />
    <span id="3-ask-about-your-code" />
    <span id="3-ask-your-agent" />
    <span id="4-establish-readiness" />
    <span id="what-your-first-result-establishes" />
    <span id="inspect-your-first-answer" />

    Choose the name of a class or function in your project.
    From the project root, run this command with that name in place of `DECLARATION_NAME`:

    ```shell
    kast query --name DECLARATION_NAME --fields name,location --json
    ```

    The command exits with status `0` when the search finished. In the output, look for `"type": "complete"` and the file where that declaration is.

    The first query can take several minutes while IDEA imports the Gradle project and builds its index. Let it run.
    If `type` has another value or the command prints an error, the output gives the cause. See [Help](/troubleshooting).
  </Step>
</Steps>

## Next

Ask your agent about your code as usual, for example:

```text wrap
Which functions call submitOrder, and where are they?
```

The agent's transcript shows the `kast` commands it runs to answer. If it searches the text instead, see [Your agent does not use Kast](/troubleshooting#your-agent-does-not-use-kast).
For more examples, see [What you can ask](/search).
