## Before you install

Use an Apple silicon Mac with a Kotlin Gradle repository. Select IDEA build `262.*` with bundled Kotlin and Java 25 JBR.

If IDEA uses another path, change the path in this command.

```shell
idea="/Applications/IntelliJ IDEA.app/Contents"
cat "$idea/Resources/build.txt"
cat "$idea/jbr/Contents/Home/release"
```

Make sure that the build starts with `IU-262.` or `IC-262.`. Make sure that the runtime reports Java 25 and `aarch64` or `arm64`.

## 1. Install the selected release

Run the public installer from a terminal.

```shell wrap
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/amichne/kast/main/install.sh)"
```

The default selects stable Control and Host independently. The installer examines component contracts before it reports installation success.

The installer offers a user-level Codex MCP connection. Accept the default to use Codex after you restart IDEA and Codex.

For registration without a prompt, append `-- --register-codex-mcp`. To preserve existing Codex MCP configuration, append `-- --skip-codex-mcp`.

For structured diagnostics, append `-- --verbose`. Preserve the `--` separator before installer options.

<Accordion title="Latest developer build">
Developer builds use the published prerelease channel.

```shell wrap
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/amichne/kast/main/install.sh)" -- --developer-latest
```

The installer prints the selected version and source revision. Local checkout state and the installed version do not select that published candidate.

Terminal downloads show progress. Ctrl-C stops installation. `kast upgrade` keeps the developer channel.

Developer installation resets stale Kast state before replacement. Stable installation requests the same cleanup with `--force`.

If you need a preview without file or registration changes, use `--dry-run`. To preserve existing Codex MCP registration, use `--skip-codex-mcp`.
</Accordion>

<Accordion title="Another IDEA installation">
Select the application path explicitly.

```shell wrap
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/amichne/kast/main/install.sh)" -- --idea-home "/Applications/IntelliJ IDEA.app"
```
</Accordion>

<Accordion title="Recorded component pair">
This command selects the [historical pair](/reference/compatibility#recorded-release-pair), rather than the latest channel release.

```shell wrap
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/amichne/kast/main/install.sh)" -- --version 0.3.1 --host-version 0.4.0
```

`--version` selects Control. `--host-version` selects Host.
</Accordion>

## 2. Load the plugin and inspect state

Restart IDEA to load Host. Inspect the installed version, command location, and recorded connections.

```shell
kast status
```

If `XDG_CONFIG_HOME` is nonempty, the public executable is `$XDG_CONFIG_HOME/kast`. Otherwise, it is `$HOME/.local/bin/kast`.

If the shell cannot find the command, use the installer-reported absolute path. Add its directory to `PATH` when needed.

The installer reports a missing `PATH` entry. It does not change shell profiles.

### Coordinator endpoint

Fresh installations use a private endpoint. Routine installation preserves admitted saved settings unless you select another endpoint.

Select `codex-control` explicitly to expose the standard Codex control socket. An occupied or unreadable socket does not establish ownership.

Read [App Server compatibility](https://github.com/amichne/kast/blob/main/app-server/docs/compatibility.md) for endpoint admission and migration details.

## 3. Establish a semantic connection

[Connect your agent](/reference/integrations). Complete [the first-query exercise](/tutorials/first-query) in the intended worktree.

Installation success does not establish loaded Host identity or workspace readiness. [Lifecycles](/reference/lifecycles) separates those facts.

For recovery or removal, use [Manage Kast](/reference/management). Preserve failure stage and recovery location before another installation try.
