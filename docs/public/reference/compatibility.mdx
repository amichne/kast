Kast admits Apple silicon macOS, an on-disk Kotlin Gradle repository, IDEA `262.*`, its bundled Kotlin plugin, and Java 25 JBR. Unsupported IDEA release lines are rejected.

| Client | Installed contract authority |

Compatibility requires matching runtime protocol, operation registry, wire schema, capabilities, and IDEA/Kotlin admission. Version equality establishes none of these.

The [installer](/start) selects stable components independently. With a downloaded public installer, pin the pair:

```shell
bash install.sh --version 0.3.1 --host-version 0.4.0
```

`--version` selects Control; `--host-version` selects Host. The previous Host 0.3.0 / Control 0.2.0 pair requires both upgrades because its wire contract differs. Restart IDEA and affected agents.

Control-only installation reuses a running Host with a matching contract. Host-only installation leaves Control in place:

```shell
bash install.sh --host-only --version 0.4.0
```

In Host-only mode, `--version` selects Host. Restart IDEA; Control must still match its contract.
