Callback observations keep the source occurrence, named lexical container, anonymous body, and named-edge policy. These are static facts. They do not prove that code ran.

## Named-edge policy

| Policy | Named-edge meaning |
| --- | --- |
| `EXCLUDED` | Call is absent from named callers, with its reason. |
| `ADMITTED_DIRECT` | The compiler proves a direct call. It admits a named edge and keeps the anonymous body. |
| `ADMITTED_INLINE` | Inline policy admits a named edge. It keeps the anonymous owner. |
| `UNAVAILABLE` | Ownership remains incomplete. |

An admitted named edge keeps its anonymous owner evidence. An excluded edge keeps the reason and exact excluded occurrence.

## Binding forms

| Binding | Meaning |
| --- | --- |
| `BOUND` | An explicit argument supplies the value. |
| `DEFAULT` | A declared default supplies the value. |
| `DIRECT` | A literal or anonymous function is invoked directly. |
| `DEPENDENCY_CONTRACT` | The compiler contract proves a supported calls-in-place effect. The dependency binary identity is checked. |
| `DEFERRED_DEPENDENCY` | Reviewed dependency binaries prove initializer supply without a call claim. |
| `UNAVAILABLE` | The mapping is not available. |

`BOUND` records how the compiler maps an argument to a parameter. `DEFAULT` keeps the defining formal and default expression. It does not invent an argument.

`DIRECT` keeps the actual call owner without a receiving formal. `DEFERRED_DEPENDENCY` proves initializer supply without a call site or count.

## Call scan

| Scan | Meaning |
| --- | --- |
| `EXHAUSTIVE` | The admitted scan finished. Empty calls prove no supported call sites in that scanned flow. |
| `INCOMPLETE` | A limit or unsupported flow prevents an absence claim. |
| `NOT_APPLICABLE` | A directly invoked body has no receiving formal to scan. |

The scan states how far it searched the formal for call sites. A full scan can still need proof that a nested call owner executes.

Each parameter call keeps `forwardings`, even if the array is empty. Each hop names the source formal, supplied expression, and destination binding.

`owner_bindings` keeps the supply and mapping of a nested anonymous owner. Its `execution` field carries a recursive flow proof or an explicit unproved state. A complete owner route can discharge `NESTED_CALLBACK_EXECUTION`. Unknown effects, escapes, and exhausted grants remain explicit.

`callable_observations` records symbolic formal calls. It also records compiler targets without source.

## Declared dependency effects

Calls-in-place evidence keeps `EXACTLY_ONCE`, `AT_MOST_ONCE`, `AT_LEAST_ONCE`, or explicitly declared `UNKNOWN`.

The effect belongs to the formal selected by the compiler and the reviewed binary identity. If effects are missing, repeated, or not supported, the result returns `DEPENDENCY_CONTRACT_EFFECT_UNPROVEN`.

These kinds describe the declared contract. They do not count calls at runtime. They do not invent sites within dependency bodies.

## Unresolved obligations

| Evidence | Limit |
| --- | --- |
| Unproved route for a nested callable owner | `NESTED_CALLBACK_EXECUTION` |
| Library mapping | `EXTERNAL_CALLABLE` and `OUTSIDE_DOMAIN` |
| Local initializer | `STORED_CALLBACK` |
| Returned literal | `RETURNED_CALLBACK` |
| Unsupported supply | `UNSUPPORTED_CALLBACK_SUPPLY` |
| Recursive forwarding | `CALLBACK_CYCLE` |

The list groups ownership and transfer failures. Work, time, result, and byte limits keep their separate causes.

`FINALLY_UNSUPPORTED` and `ABRUPT_COMPLETION` keep control-flow effects that are not supported. An empty call list does not erase an incomplete scan. It does not erase proof still needed.

## Candidate source action

The anonymous body's issued `candidateSelector` supplies this action's `candidateRef`.

```json
{"request":{"type":"READ_SOURCE","candidateRef":"<issued candidateSelector>"}}
```

The selector needs its admitted source state. It does not select the enclosing named function.
