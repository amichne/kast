Use this map to trace the CLI-first interface to its source owners.
The reviewed implementation is [PR #1144](https://github.com/amichne/kast/pull/1144) at `647fffc46f6247fac5b0fc632ae019d157bf9020`.
Use `kast describe` for the contract in your installed build.

## Native CLI

[`KastManagementMain`](https://github.com/amichne/kast/blob/647fffc46f6247fac5b0fc632ae019d157bf9020/distribution/cli/src/main/kotlin/io/github/amichne/kast/distribution/cli/KastManagementMain.kt) owns management command admission.
[`PublicQueryDispatch`](https://github.com/amichne/kast/blob/647fffc46f6247fac5b0fc632ae019d157bf9020/distribution/cli/src/main/kotlin/io/github/amichne/kast/distribution/cli/PublicQueryDispatch.kt) delegates semantic commands to the query executable.
The [CLI reference](/reference/cli) describes common command forms.

## Installation and transport

[`ManagementBuilds`](https://github.com/amichne/kast/blob/647fffc46f6247fac5b0fc632ae019d157bf9020/distribution/cli/src/main/kotlin/io/github/amichne/kast/distribution/cli/ManagementBuilds.kt) resolves build selections.
[`ManagedUpgrade`](https://github.com/amichne/kast/blob/647fffc46f6247fac5b0fc632ae019d157bf9020/distribution/cli/src/main/kotlin/io/github/amichne/kast/distribution/cli/ManagedUpgrade.kt) invokes the selected managed installer.
[`GuidanceInstallation`](https://github.com/amichne/kast/blob/647fffc46f6247fac5b0fc632ae019d157bf9020/distribution/cli/src/main/kotlin/io/github/amichne/kast/distribution/cli/GuidanceInstallation.kt) owns CLI guidance and optional MCP setup.

The [installation reference](/reference/installation) describes build policies and activation.
The [integration reference](/reference/integrations) describes agent guidance and skill export.

## Host activation and recovery

[`ManagedHostBridge`](https://github.com/amichne/kast/blob/647fffc46f6247fac5b0fc632ae019d157bf9020/cli/src/main/kotlin/io/github/amichne/kast/cli/installation/ManagedHostBridge.kt) coordinates private Host operations.
[`HostedApplicationSettlement`](https://github.com/amichne/kast/blob/647fffc46f6247fac5b0fc632ae019d157bf9020/runtime/hosted/src/main/kotlin/io/github/amichne/kast/runtime/hosted/lifecycle/HostedApplicationSettlement.kt) owns application settlement.
[Manage Kast](/reference/management) distinguishes installed files, loaded Host identity, and terminal recovery outcomes.

## Public requests

[`tools.schema.json`](https://github.com/amichne/kast/blob/647fffc46f6247fac5b0fc632ae019d157bf9020/app-server/src/main/resources/io/github/amichne/kast/appserver/query/tools.schema.json) owns the public query inputs.
The CLI, MCP, and Tool RPC preserve the underlying request and outcome contracts.
[Query forms](/reference/api) describes those inputs.

## Query execution and retention

[`CanonicalQueryProtocol`](https://github.com/amichne/kast/blob/647fffc46f6247fac5b0fc632ae019d157bf9020/query/protocol/src/main/kotlin/io/github/amichne/kast/query/protocol/CanonicalQueryProtocol.kt) owns semantic query execution and retained reads.
[Result contracts](/reference/responses) describe output pages, qualifications, and recovery.

## Documentation owners

`docs/public/docs.json` owns navigation. `docs/okf-public.json` selects authored pages and generated knowledge views.
The callable generator owns `reference/callables.openapi.json`.
