## Before you install

You need:

- An Apple silicon Mac.
- A Kotlin Gradle project.
- IntelliJ IDEA `262.*` with its bundled Kotlin plugin and Java 25 JBR.

## 1. Install Kast

Run this command in a terminal:

```shell wrap
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/amichne/kast/main/install.sh)"
```

The installer adds Kast and its IntelliJ plugin. Accept the default Codex connection when the installer asks.

## 2. Restart IntelliJ IDEA

Restart IDEA to load the plugin. Then examine the installation:

```shell
kast status
```

If your terminal cannot find `kast`, use the command path that the installer prints.

## 3. Ask your agent

Restart Codex. Select your Kotlin repository or worktree. Ask:

> Use Kast to find a Kotlin declaration in this workspace. Show its signature and source location.

The first query prepares the IDEA project. Kast reports trust, import, or indexing blockers if preparation cannot finish.

<Card title="Choose your agent" icon="plug" href="/agent-harnesses">
  Use Copilot or Pi, or change an existing Codex connection.
</Card>

## 4. Establish readiness

Complete [the first-query exercise](/tutorials/first-query) in the selected project. Compare the returned declaration and caller with the exercise source.

`kast status` reports installation state. A fresh semantic query establishes that the selected project admits the requested read.

If setup stops, use [Troubleshoot Kast](/troubleshooting).
