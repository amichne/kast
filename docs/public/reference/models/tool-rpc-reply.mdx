---
title: "Tool RPC reply"
description: "Select the catalog, operation document, or process failure from a Tool RPC reply."
openapi-schema: "reference/callables.openapi.json ToolRpcReply"
mode: "wide"
---

The reply's `type` selects a catalog, tool document, or process failure. The inner tool document keeps its own semantic status.

`complete`, `qualified`, and `rejected_document` carry `document`. `rejected` carries `failure`. `catalog` carries the installed schemas and supported features.

An unknown reply kind means the contracts do not match. Keep a process failure distinct from a rejected semantic answer.

[Tool RPC](/reference/rpc-catalog#decode) defines commands and session states. [Lifecycles](/reference/lifecycles) names each call's owners.
