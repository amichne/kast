The MCP wrapper separates display text in `content[]` from the operation document in `structuredContent`. For semantic tools, that document is the canonical result.

Before you use a result, examine `isError` and the document's semantic status. Decode the document with its tool-specific schema. `health_check` uses a separate readiness shape. See [MCP contract](/reference/mcp-catalog) for discovery and calls.
