Kast gives your coding agent compiler-grounded evidence during ordinary Kotlin work.
Describe the feature, bug, or change you want. The agent uses its installed guidance to select the supported operations.

## Resolve the code you mean

Your agent can find declarations, inspect their signatures and owners, and select an exact declaration before following its relationships.
Identical names can refer to different declarations. Kast's issued references preserve the selected identity.
[Declarations and relationships](/reference/search) explains discovery, callers, references, and implementations.

<span id="what-depends-on-this-function" />

## Understand a change's source relationships

Caller and reference locations show where code uses the selected declaration.
Your agent can read that source as it plans a change.
The relationships describe the queried source state and scope; they do not establish runtime execution.

<span id="where-does-this-value-go" />

## Follow a value through supported transfers

Value paths connect supported returns, arguments, and field reads.
The result keeps the evidence for each connection and identifies unsupported transfers.
[Program tracing](/reference/program-tracing) defines the relationships and their limits.
The optional [value illustration](/explanation/value-journey) makes those distinctions visible.

<span id="what-problems-does-idea-report" />

## Inspect problems and make supported edits

Kast also exposes IDEA diagnostics and controlled source changes through its [optional MCP composition](/reference/integrations#optional-mcp) and Tool RPC interfaces.
The default native CLI guidance supports declaration and relationship queries and source reads.

- [IDEA diagnostics](/how-to/inspect-diagnostics) carry source locations and reported coverage.
- [Source changes](/reference/change) support adding a declaration to an existing file or replacing a supported function body, with a change receipt.

These operations support your project's build and tests. A change receipt records a scoped source effect; it does not establish application behavior.
