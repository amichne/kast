Connect Kast to Codex, then find a function in your own Kotlin project.
Success means that a completed query identifies the function and its source location in the selected worktree.

## Before you install

You need:

- An Apple silicon Mac.
- A Kotlin Gradle project.
- IntelliJ IDEA `262.*` with its bundled Kotlin plugin and Java 25 JBR.
- Codex CLI and uv 0.12.9 or later on `PATH`.
- Python 3.12 or 3.13 for the task service.

Run `codex --version` and `python3 --version` to see their installed versions.
The IDEA runtime is separate from your project's JDK.
Use the [platform inspection commands](/reference/installation#before-you-install) if you do not know your IDEA build or runtime.
For Copilot or Pi, use the [agent guide](/agent-harnesses) after installation.

<Steps>
  <Step title="Install Kast">
    <span id="1-install-kast" />

    Run this command:

    ```shell wrap
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/amichne/kast/main/install.sh)"
    ```

    Accept the default Codex plugin installation.
    Keep the command path that the installer prints. The installer does not change your shell profile.
  </Step>
  <Step title="Restart IDEA and Codex">
    <span id="2-restart-intellij-idea" />
    <span id="3-connect-your-agent" />

    Restart IDEA to load its Kast plugin. Restart Codex and select your Kotlin repository or worktree.
    Review and trust the Kast session context hook in Codex.
  </Step>
  <Step title="Ask your first question">
    <span id="3-ask-your-agent" />
    <span id="4-establish-readiness" />

    Choose a function name from your source, then replace `yourFunction` in this prompt:

    > Use Kast to find the function yourFunction in this workspace. Show its signature, source location, and completion status. If several declarations match, show each one.

    Kast prepares the project in IDEA. If trust or import needs your attention, the result tells you what went wrong.
    Open the returned source location and compare the function with the answer.
    If several declarations match, select the intended signature and owner before another query.
  </Step>
</Steps>

## What your first result establishes

A matching declaration with a completed query shows that Kast reached semantic analysis for this source question in this worktree.
Installation status alone does not establish that fact.
This result does not prove that your project builds or that a function ran.

Use [the first-query exercise](/tutorials/first-query) for a known caller, an unrelated function, and an absent name.
If setup stops, use [Troubleshoot Kast](/troubleshooting).
