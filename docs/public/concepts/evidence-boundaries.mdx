Use a Kast answer only for the question its evidence supports.

Start with [Read a response](/reference/responses) for field-level decoding.

## Keep the scope in the claim

“Nothing matched” needs the repository, source sets, directory or package,
matching mode, and transformations that defined the search.

<Note>
  A complete search of `main` and `test` does not establish absence from every
  imported source set.
</Note>

| Evidence | Supported claim |
| --- | --- |
| Complete result, no relevant item failures | The operation met its admitted completeness contract. |
| Empty complete search | No match was found within the admitted scope. |
| Qualified result | These results were established, with the attached coverage limitations. |
| Empty qualified search | No match was returned; absence is unproven. |
| Rejection | No successful semantic answer was established. |

Keep per-item failures beside successful items.

## Distinguish identity from presentation

| Representation | What it proves |
| --- | --- |
| Candidate | Discovery evidence only |
| Exact symbol | Admitted compiler identity |
| Name, location, or signature | Human-readable presentation |

Copy exact references unchanged and let the runtime re-admit them.

[Symbol results](/reference/symbols) shows both variants.

## Bind evidence to the observed source

Live evidence retains:

- canonical repository root
- original host incarnation
- content and model epoch
- saved committed content view

Published evidence retains its published workspace coordinates.

Neither evidence family can become the other.

Search again after a saved edit, model change, owner replacement, or stale-token rejection.

## Separate verification from coverage

- Scoped diagnostics do not prove a whole-project build.
- A verified receipt proves only the obligations discharged for that change.
- A larger budget permits more work but does not guarantee completeness.
- Timeouts and incomplete observations must remain visible in the outcome.
- An uncertain mutation requires the [recovery workflow](/change).
