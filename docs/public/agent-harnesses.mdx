[Install Kast](/start), then select your agent.

<span id="1-connect-your-agent" />

<Tabs sync={false}>
  <Tab title="Codex">
    If you accepted the installer's Codex option, restart Codex and select your Kotlin repository or worktree.
    Review and trust the Kast session context hook.

    If you skipped that option, run this command before the restart:

    ```shell
    kast plugin codex
    ```
  </Tab>
  <Tab title="Copilot">
    This command connects the Tool RPC extension. The [integration reference](/reference/integrations#1-choose-the-client-and-transport) also describes the Copilot plugin.

    Run this command:

    ```shell
    kast connect copilot
    ```

    Restart Copilot from your Kotlin repository or worktree.
  </Tab>
  <Tab title="Pi">
    Run this command:

    ```shell
    kast connect pi
    ```

    Restart Pi from your Kotlin repository or worktree.
  </Tab>
</Tabs>

## Ask a question

Use the same project in IDEA and your agent.

> Use Kast to find a Kotlin function in this repository. Show its name and source location.

<span id="3-compare-the-evidence" />

Open the returned location and compare the source with the answer.
If Kast reports a trust, import, or indexing problem, resolve it in IDEA before another query.
