Read each fact with its workspace, source state, scope, and coverage. Exact identity and exhaustive coverage establish different properties.

## Exact facts are not the same as exhaustive coverage

| Result | Supported conclusion |
| --- | --- |
| Exact symbol, complete coverage | Confirmed declaration. Requested search scope covered. |
| Exact symbol, qualified coverage | Confirmed declaration. Additional matches or checks can remain. |
| Empty, complete coverage | No match in the declared, supported scope. |
| Empty, qualified coverage | Absence remains unproven. |
| Rejected or unavailable | No successful semantic result from this request. |

Kotlin-source coverage does not establish facts about excluded sources, libraries, other languages, or runtime execution. Read restrictions, omissions, and item failures.

## Decide whether to continue

Public RESUME uses an issued output token to present already-produced facts. It does not continue semantic execution. Terminal progress supplies a stopping reason; `retention_unavailable` means a remaining output suffix was lost. A missing continuation does not establish completeness.

An empty retained page can still advance evidence. Reading all saved rows preserves the original coverage limits. See [Results](/reference/responses#follow-progress-not-row-count).

## Can I reuse this result later?

Pass issued handles unchanged. Report stale references or unavailable saved state as a blocker. A fresh query requires a new decision; it cannot recover the original delivery.

An exact symbol can undergo fresh compiler revalidation. Retained results and continuations require their original read state and lifetime. See [Saved state and identity](/reference/responses#saved-state-and-identity).

## Check relationship and verification claims

A confirmed call site establishes a source relationship. Lexical containment alone does not establish a named caller. [Callback evidence](/reference/callbacks) preserves anonymous ownership and activation limits.

A verified edit covers the reported change scope. For uncertain outcomes, preserve the receipt and follow [change recovery](/change#read-the-receipt) before retrying. Run your project's build and tests.
