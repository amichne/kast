The Kast installation includes one plugin for Claude Code, Codex, GitHub Copilot, and Pi. It holds the Kast skill, a session hook, and the Kast MCP server.
`kast agent` runs your agent's own plugin commands. Kast writes no agent configuration.

## Before you start

[Install Kast](/start). Your agent must find the `kast` command on its `PATH` or in `~/.local/bin`.

<span id="1-export-the-kast-skill" />
<span id="2-declare-kast-in-agents-toml" />

## 1. Install the plugin

```shell
kast agent install
```

The command lists the supported agents on your `PATH`. Enter their numbers, press Enter for all of them, or enter `0` for none.
Without a terminal, it selects all of them. The installer asks the same question after it installs Kast.

Name an agent to skip the question: `claude`, `codex`, `copilot`, or `pi`. You can name more than one.

<Tabs>
  <Tab title="Claude Code">
    ```shell
    kast agent install claude
    ```

    The skill appears as `kast:kast`.
  </Tab>
  <Tab title="Codex">
    ```shell
    kast agent install codex
    ```

    Codex skips a new hook until you trust it. Run `/hooks` in a session, then review the Kast session hook.
  </Tab>
  <Tab title="GitHub Copilot">
    ```shell
    kast agent install copilot
    ```

    Copilot runs the session hook only in a folder that you trust.
  </Tab>
  <Tab title="Pi">
    ```shell
    kast agent install pi
    ```

    Pi loads the skill and a small extension from one package. Kast adds the MCP server with `pi mcp add`.
  </Tab>
</Tabs>

The plugin applies to all your projects. Outside a Gradle project, the session hook adds nothing to the session.

Add `--without-mcp` to install only the skill and hook. Run the command again without it to add the MCP server.

The command replaces a marketplace, plugin, or MCP server with the name `kast`, from any source.
It then reads the agent's own plugin list. If the list shows another version or directory, the command stops with `VERSION_STALE`.

<span id="3-apply-the-configuration" />

## 2. Start a new session

Start a new agent session in your project to load the plugin.

## Work with your agent

Describe your task as usual. The skill tells your agent when a Kast query gives a better answer than a text search.
The agent can read the installed CLI contract with `kast describe`.

The first explicit semantic request grants trust to the exact workspace root and prepares its Host. This applies to the CLI and to MCP.
Use Kast only in a workspace whose build code you trust. Plugin installation, the session hook, and `tools/list` do not grant trust or start a Host.
Each result applies to its stated worktree, source state, and scope.

The [MCP contract](/reference/mcp-catalog) describes the server's tools and replies. The [CLI reference](/reference/cli) describes the command forms.

<span id="refresh-the-skill-after-an-upgrade" />

## Refresh after an upgrade

`kast upgrade` updates the plugin in each agent that already has it, and adds it to no other agent.
Start a new agent session to load the update. A changed hook needs a new review in Codex.

If the upgrade reports that an agent keeps an older plugin, run the update yourself:

```shell
kast agent refresh
```

## Install from the published marketplace

Each stable release also publishes the plugin to the [`amichne/kast-plugins`](https://github.com/amichne/kast-plugins) repository. It holds only the marketplace, so a clone stays small.
Add it with your agent's own commands when you want the agent to fetch the plugin from GitHub:

<Tabs>
  <Tab title="Claude Code">
    ```shell
    claude plugin marketplace add amichne/kast-plugins
    claude plugin install kast@kast
    ```

    To update, run `claude plugin marketplace update kast`, then `claude plugin update kast@kast`.
  </Tab>
  <Tab title="Codex">
    ```shell
    codex plugin marketplace add amichne/kast-plugins
    codex plugin add kast@kast
    ```

    To update, run `codex plugin marketplace upgrade`, then `codex plugin add kast@kast`.
  </Tab>
  <Tab title="GitHub Copilot">
    ```shell
    copilot plugin marketplace add amichne/kast-plugins
    copilot plugin install kast@kast
    ```

    To update, run `copilot plugin marketplace update`, then `copilot plugin update kast@kast`.
  </Tab>
</Tabs>

The repository has a tag for each release, such as `v0.55.0`. To pin one, add `--ref v0.55.0` for Codex, `#v0.55.0` after the repository for Claude Code, or `https://github.com/amichne/kast-plugins.git#v0.55.0` for Copilot.
`kast-release.json` in the repository names the Kast release and the build that produced it.

The plugin runs your installed `kast` command. Keep the plugin and Kast at the same release.
`kast agent install`, `kast agent refresh`, and `kast upgrade` replace this marketplace with the copy in your Kast installation.

## Remove the plugin

```shell
kast agent remove
```

Without a name, the command removes the plugin from every agent on your `PATH`. Name an agent to select it.
A marketplace named `kast` from another source stops the removal with `MARKETPLACE_FOREIGN`.

`kast uninstall` does not change agent configuration. Remove the plugin first.

## Connect another agent

For an agent without a Kast plugin, export the skill and register the MCP server.

From your repository root, export the skill:

```shell
kast install skill
```

Kast writes the skill to `.agents/skills/kast`. Many agents read that directory. Keep it in Git to share it with your team.
Use `--output` to select another parent directory, and `--json` to print one structured result.

Register this stdio MCP server as your agent's documentation describes:

```shell
kast --internal-entrypoint=mcp
```

If your agent cannot find `kast`, use the absolute path that the installer printed.

`kast install skill` never overwrites an existing skill:

- An identical skill returns `ALREADY_INSTALLED` and writes nothing.
- A different or incomplete skill returns `SKILL_EXISTS` and leaves the directory unchanged.

To refresh an exported skill after an upgrade, remove it with `rm -rf .agents/skills/kast` and export it again.
Do not combine an exported skill with the plugin. Your agent would list the Kast skill twice.

Recovery: [Help](/troubleshooting).
