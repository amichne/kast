Kast gives agents compiler-grounded tools for the Kotlin project open in IntelliJ.

## What do you need to do?

| Task | Start here | You get |
| --- | --- | --- |
| Connect a Kotlin repository | [Install and connect](/start) | A working agent tool catalog |
| Find a class, function, or property | [Search declarations](/search) | Separate matches, compiler signatures, and reusable references |
| Follow callers or implementations | [Compose a query](/query-pipelines) | Related declarations from an ordered query |
| Decide what an answer proves | [Read a response](/reference/responses) | Status, coverage, item failures, and the next action |
| Add a declaration | [Plan and apply a change](/change) | A file preview, exact-plan approval, and verification evidence |
| Integrate your own agent host | [Harness contract](/agent-harnesses) | Installed schemas and executable bindings |

## Make one useful request

After [setup](/start), ask your agent to find a declaration by its simple name.

```json
{"class_name":"OrderService","name_match":null,"scope":null}
```

Use these request rules:

- Replace `OrderService` with a declaration from your project.
- Keep all three fields because `null` selects a documented default.
- Expect exact, case-sensitive matching in the imported `main` and `test` source sets.

Read the semantic status before the matches:

| Status | What it means |
| --- | --- |
| **complete** | The search can establish absence within its scope. |
| **qualified** | The answer remains limited by its attached qualifications. |
| **rejected** | Resolve the reported problem before using the answer. |

## Keep the compiler evidence

A result's `ref` is its reusable identity.

- Copy `ref` unchanged into later tools.
- Use the name, location, and signature for display only.
- See [Symbol results](/reference/symbols) for field and reuse rules.

<Note>
  Semantic reads use saved, indexed project state.

  Open the repository in IDEA, finish import and indexing, and save edits before asking again.

  Search returns a blocker instead of opening or importing an unavailable project.
</Note>
