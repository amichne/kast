Live read evidence names the workspace and source state used for a call. Its identity and lifetime belong to that read.

A read epoch records state signals that Kast has checked. Its value alone does not prove that saved content or compiler identity is current.

An exact reference can gain fresh authority after Kast checks its identity under the reference's policy. Retained results and their next output pages still need the read state that produced them.

[Staleness](/reference/staleness) defines these rules. [Lifecycles](/reference/lifecycles) names the Host and request owners.
