A Kast fact is useful only within its admitted workspace, source state, and
request scope. Its status says how far the read got.

| Result | Claim you can make |
| --- | --- |
| Exact symbol, complete coverage | The compiler established that declaration within the reported scope. |
| Exact symbol, partial coverage | The returned declaration is useful; other matches may be missing. |
| Empty, complete coverage | No match was established in the requested scope. |
| Empty, partial coverage | Absence remains unproven. |
| Rejected | Resolve the reported failure before using the result. |

Keep qualifications, item failures, and omissions with positive facts. Copy
opaque `ref` values unchanged and search again when the source or project
authority changes. [Read a result](/reference/responses) explains the
transport layers.
