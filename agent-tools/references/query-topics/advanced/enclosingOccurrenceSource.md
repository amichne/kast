# `enclosingOccurrenceSource`

Read the smallest callable body around an issued occurrence with a bounded line window. This example token grants no authority.

```json
{"request":{"type":"READ_SOURCE","candidateRef":"candidate:v5:AAAAAAAAAAAAAAAAAAAAAA","region":"ENCLOSING_CALLABLE_BODY","text":{"type":"WINDOW","beforeLines":2,"afterLines":3}}}
```
