The MCP wrapper puts display text in `content[]`. It puts a checked tool document in `structuredContent`. `isError` reports a failed tool call.

The inner document has its own status and evidence. `health_check` uses a distinct document for readiness.

A reply that crosses the transport intact does not prove that the semantic work is complete. A failed tool call can lack structured semantic evidence.

[MCP](/reference/mcp-catalog) defines how to find and call tools. [Results](/reference/responses) defines the proof and output within each document.
