Kast lets your agent ask the Kotlin compiler about the repository open in
IntelliJ IDEA. Start with one query that needs no project-specific name.

## Try Kast

1. [Install and connect](/start).
2. Start your agent from a Kotlin Gradle repository.
3. Ask:

> Use Kast to query declarations in this workspace. Show one compiler-backed
> symbol with its signature, source location, exact `ref`, and coverage. If
> the query is incomplete or empty, explain what that result proves.

A returned `ref` is Kast's exact symbol handle. Reuse it unchanged for a
source read or a relation query. The result also says whether the requested
scope was fully covered.
