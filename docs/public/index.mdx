Kast connects your coding agent to IntelliJ IDEA. Your agent gets the Kotlin knowledge your IDE already uses.

Ask which function a call refers to, where an interface has implementations, or what uses the code you want to change.

## What Kast adds

Text search finds matching words. Kast identifies Kotlin declarations and their connections through the compiler.

That gives your agent more context before it explains code or changes it:

- **The exact function.** Distinguish functions that share a name and find their source.
- **The connected code.** Find callers, references, implementations, and overrides across your project.
- **The limits of the answer.** See when Kast cannot finish a search or establish a result.
- **Targeted edits.** Add a declaration or replace a supported function body, with a record of the outcome.

## Use the agent you already use

Connect Codex, Copilot, or Pi. After setup, ask questions in your usual conversation.

Kast prepares the selected IntelliJ project when a question needs it. If setup needs your attention, Kast reports the next action.

## Is Kast for you?

Use Kast with a Kotlin Gradle project on an Apple silicon Mac and IntelliJ IDEA `262.*`.

Kast helps your agent understand source code. Your project's build and tests still establish whether a change works.
