<Accordion title="Invocation contract">

Choose the operation before execution. `QUERY` is the pipeline envelope, not a separate analysis algorithm. `SELECT`: use `SEARCH_DECLARATIONS`, `ALL_DECLARATIONS`, `AT_LOCATION` or issued `SYMBOL_REFS` to return declarations; no relationship expansion is implicit. `RELATION`/`TRAVERSAL`: `EXPAND_RELATION` follows one compiler-confirmed relationship hop; `WALK` repeats one selected relation to an explicit `maximumDepth` and returns depth-bearing `TRAVERSAL_RECORDS`. `CALLERS` follows incoming calls; `CALLEES` follows outgoing calls, including constructors. `TRACE`: a fixed affected-use recipe over exact declarations: references, implementations or overrides, direct callers, and one further caller layer. It returns grouped `SYMBOLS` with proven connections and occurrences; it has no arbitrary depth control and does not follow runtime values. `IMPACT`: a forward Kotlin value investigation from an exact producer invocation, requiring enclosing and callable refs plus the whole invocation range. It returns `VALUE_PATHS` or `IMPACT_WITNESS`; model-assisted transfers and unresolved boundaries retain their qualifications. It is not a general declaration dependency walk. Expansion scope restricts destinations independently of discovery scope. None of these proves runtime behavior or unrestricted transitive reachability. `READ_RESULT` and `RESUME` only deliver produced evidence; `READ_SOURCE` reads source under an issued selector. Use simple exact-name flags for discovery; use one `JSON` `RUN` request for `WALK` or `IMPACT`. Inspect only the needed syntax after choosing the operation. Every `RUN` uses `COMPLETE_ONLY` under `COMPILER_RESOLVED_STATIC_V1`. Preserve incomplete verdicts and recovery evidence. Presentation limits do not reduce the semantic question. Copy issued references unchanged; inspect overload signatures before exact selection.

</Accordion>
