Start your agent from a Kotlin Gradle repository. Kast uses its saved, indexed
IDEA project; the agent does not need to know a class name in advance.

## 1. Find a compiler-backed symbol

> Use Kast `query_symbols` to enumerate declarations in this workspace.
> Show one returned exact symbol's kind, signature, source location, and
> unchanged `ref`. Include query coverage and any limitation. If there is no
> symbol, state whether Kast proved the scope empty.

The direct tool input is:

```json
{
  "request": {
    "action": "run",
    "source": {"type": "all_declarations"},
    "steps": null,
    "output": {"type": "symbols", "fields": ["name", "location", "signature"]},
    "execution_budget": {"max_results": 5}
  }
}
```

This is a bounded sample. Reaching the result limit can make the answer
partial. With no explicit scope, Kast searches the workspace's `main` and
`test` source sets recursively. The returned `ref` names a compiler-backed
declaration; keep it unchanged for the next call.

## 2. Show an exact relationship

> For that Kast `ref`, use `query_symbols` to find references. Show the
> individual occurrence facts and their locations. Report omissions or
> incomplete coverage, even if no occurrences were returned.

```json
{
  "request": {
    "action": "run",
    "source": {"type": "symbol_refs", "symbol_refs": ["<returned ref>"]},
    "steps": [{"type": "expand_relation", "relation": "references"}],
    "output": {"type": "occurrences"}
  }
}
```

Replace the placeholder with an exact `ref` from step 1. A reference fact
connects the compiler's subject and source location. An empty result proves
absence only when Kast reports complete coverage for the requested scope.

## Read the answer

| Direct MCP status | Meaning |
| --- | --- |
| `complete` | The requested scope was covered. |
| `partial` | Keep the returned facts and the stop reason; absence is unproven. |
| `rejected` or `unavailable` | Follow the typed error before making a semantic claim. |

Tool RPC uses `type: "qualified"` for a partial document. The
[MCP](/reference/mcp-catalog) and [RPC](/reference/rpc-catalog) pages show
their exact wrappers. See the generated **Query symbols** entry in the API / RPC tab
for every supported source, step, and output.
