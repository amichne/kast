The complete `health_check` variant contains readiness observations in `data`. A rejection contains its finite error.

Readiness describes workspace binding at the time of that call. It does not establish a later query's declaration identity or coverage.

[MCP contract](/reference/mcp-catalog) defines discovery and result wrappers. [The first-query tutorial](/tutorials/first-query) supplies a semantic exercise.
