Direct MCP places the canonical `query_symbols` document in `result.structuredContent`. Its status is `complete`, `qualified`, or `rejected`.

The document keeps exact identities, coverage, proof limits, producer progress, and retained evidence. Output presentation has separate row and byte limits.

An invocation failure can omit this document. `check_diagnostics` uses its own `check_diagnosticsSemanticResult` schema.

[Results](/reference/responses) defines semantic fields. [The MCP wrapper](/reference/models/mcp-tool-call-result) defines transport failure.
