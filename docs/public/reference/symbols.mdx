---
title: "Read a symbol"
description: "Use exact compiler references, locations, and signatures without guessing identity."
icon: "braces"
---

`query_symbols` returns exact Kotlin symbols. A result can carry a kind,
name, source location, signature, and an opaque `ref`. The
[query item schema](/reference/models/query-item) defines the full shape.

| Field | Use |
| --- | --- |
| `ref` | Pass unchanged to Kast for a later read. |
| `location` | Show where the declaration was proven. |
| `signature` | Display the compiler's declaration details. |
| `source` | Show a bounded committed source window when requested. |

`symbol_lookup` can return candidates without exact compiler identity.
Use `symbol_inspect` to refine a candidate. Do not treat a matching name,
file path, or reconstructed token as an exact `ref`.

The [symbol query example](/search) works without knowing a project-specific
name. Keep the result's coverage with any symbol you report.
