Choose a guide by the result you need. Each guide states its prerequisites, next action, and completion evidence.

| Your task | Guide | Completion evidence |
| --- | --- | --- |
| Find a declaration and its uses | [Find and trace code](/reference/search) | Selected identity, occurrence evidence, scope, and completion. |
| Inspect IDEA problems | [Inspect diagnostics](/how-to/inspect-diagnostics) | Reported diagnostics and coverage for the requested path. |
| Read a result beyond its preview | [Read retained evidence](/how-to/read-retained-evidence) | Rows and evidence at their separate final positions. |
| Combine two result sets | [Combine query results](/reference/query-pipelines) | Canonical identity comparison and kept input qualifications. |
| Add a declaration or replace a body | [Make a targeted change](/reference/change) | The receipt, source diff, and project-specific tests. |
| Install or choose a release channel | [Install Kast](/reference/installation) | Installation result and a fresh semantic query. |
| Connect a client | [Connect your agent](/reference/integrations) | Installed catalog and a query in the intended worktree. |
| Repair a failed setup or read | [Troubleshoot Kast](/reference/troubleshooting) | The original operation succeeds after the reported cause changes. |
| Upgrade, stop, or remove Kast | [Manage Kast](/reference/management) | The finite lifecycle result and reported installation state. |

For a first exercise, use [the first-result exercise](/tutorials/first-query). For field definitions, use [Reference](/reference).
