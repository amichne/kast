# Value impact and independent peer proof

## Acquire native inputs once

An impact source selects producer seeds, declarations, requested native sites, reviewed models, and an expansion domain.
`QueryImpactSourceAdmission` first admits counts and model syntax.
It then acquires native source inputs under the original authority and shared grant.
Resumed internal plans keep that acquired proof rather than reacquiring a new semantic basis for each page.

The producer invocation and the domain of later expansion remain separate facts.
A reviewed model can connect admitted native positions only after fresh endpoint revalidation.
Model syntax or an author's explanation does not establish that the compiler bound the selected sites.
Source acquisition, model admission, and retained storage each preserve their finite failure causes.

## Conserve branches and obligations

`QueryImpactTasks` schedules bounded value-flow work inside the existing query interpreter.
`QueryImpactLedger` keeps the branch accounting and obligations needed to close the original investigation.
Native transfers, model applications, scope exits, and unresolved relationships remain distinguishable.
An omitted branch cannot disappear because the presentation selects only compact findings.

Original path identity and ordinals connect findings to the retained value-path evidence.
`QueryInvestigationCompletion` establishes original impact completion only from the complete original value-path result.
A final presentation slice cannot create that proof after the fact.

## Admit an independently completed peer

A peer target has its own exact workspace authority, selected site, native read, grant, and completion evidence.
The hosted adapter grants the child only the parent's remaining work, time, and retention allowance.
It debits actual child work and elapsed time before the parent continues.
Unavailable or rejected peer evidence stays explicit.

`QueryImpactPeerBoundary` admits one reviewed final model connection to the exact completed peer site.
It rejects a mismatched source basis, same-root peer, wrong target basis, or wrong site identity.
That connection does not permit arbitrary native expansion inside the peer workspace.
The parent and peer authorities remain separate in the result.

## Present the original proof

Retained witness sections expose original producers, models, native sites, findings, and unresolved obligations.
`READ_RESULT` slices that retained evidence without another native acquisition.
A compact finding proves only the evidence to which its original path refers.
Peer and impact tests establish accounting and rejection with controlled source evidence.
They do not establish unmeasured cross-workspace runtime behavior.
