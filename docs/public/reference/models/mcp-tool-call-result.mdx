The MCP wrapper separates display text in `content[]` from the operation document in `structuredContent`. `isError` reports tool-call failure.

For semantic tools, `structuredContent` contains the canonical document with its own semantic status. `health_check` uses a separate readiness shape.

A transport-level success alone does not establish semantic completion. [MCP contract](/reference/mcp-catalog) defines catalog discovery and calls.
