Kast admits an on-disk Kotlin Gradle repository on Apple silicon macOS. The selected IDEA must use build `262.*`, bundled Kotlin, and Java 25 JBR.

Other IDEA release lines reject admission. A separate project JDK does not replace the selected IDEA runtime.

## Installed contract authority

| Client | Installed contract authority |
| --- | --- |
| MCP | `tools/list` |
| Tool RPC | `catalog` |
| Codex plugin | MCP `tools/list` |

Component admission compares runtime protocol, operation registry, wire schema, capabilities, and IDEA/Kotlin support. Equal component version numbers cannot establish compatibility.

Registration, live service readiness, loaded Host identity, and exact workspace admission supply separate facts. [Lifecycles](/reference/lifecycles) describes those owners.

| Host | [0.4.0](https://github.com/amichne/kast/releases/tag/host-v0.4.0) | [`d1305fe51`](https://github.com/amichne/kast/commit/d1305fe51e35855e65a1024ce88d094a90e8a341) | IDEA plugin for `262` |

The installer selects stable Control and Host components independently. A downloaded installer can select this historical pair with explicit options.

```shell
bash install.sh --version 0.3.1 --host-version 0.4.0
```

`--version` selects Control, and `--host-version` selects Host. Older pairs can use different wire contracts and need coordinated component changes.

Host-only mode interprets `--version` as the Host version.

```shell
bash install.sh --host-only --version 0.4.0
```

Control-only mode needs a compatible live Host. Host-only mode keeps Control, whose contract must still match the loaded Host.

## Recorded examples and client limits

Historical offsets, counts, and handles belong to their captured revision. Current input examples need your installed catalog and newly issued references.

After an upgrade, IDEA and clients must load the new components. Retained output cannot cross retired live authority.

The [App Server compatibility record](https://github.com/amichne/kast/blob/main/app-server/docs/compatibility.md) describes its tested protocol and earlier desktop limits. Current Codex setup uses the bundled plugin over MCP.

`kast connect codex app-server` rejects before registration effects. Codex owns its App Server and control socket. Use [integration options](/reference/integrations) for the current setup contract.
