<span id="what-kast-adds" />

Kast connects your coding agent to IntelliJ IDEA. Your agent can trace a value through functions, fields, and callbacks to the code that uses it.

## Can my agent already do that?

Your agent can search names and read files. Now ask a harder question:

**If I change this value, where does it go?**

In this example, a helper creates a `Pet`. A `PetListing` holds that pet. A callback puts the listing into a list.
Press **Follow the value** to see each connection. Then choose **Return a different value**. The code still mentions the same types, but the route changes.

This illustration uses authored routes. It does not run Kotlin or query Kast.

Kast gives your agent source locations and evidence for these connections. A matching name or type cannot establish them.

<span id="use-the-agent-you-already-use" />

## Ask a better question before the edit

> Use Kast to trace this function's result. Show where it goes and where the evidence stops.

> Use Kast to find the callers of this function before we change it.

> Use Kast to inspect the diagnostics in the code we changed.

When Kast cannot finish, it says so. Your agent can see what still needs attention.

<span id="is-kast-for-you" />

## Try it on your project

Use an Apple silicon Mac, a Kotlin Gradle project, and IntelliJ IDEA `262.*` with its bundled Kotlin plugin and Java 25 JBR.
