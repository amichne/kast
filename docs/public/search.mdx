Use these prompts with your [connected agent](/agent-harnesses). Each prompt identifies a task and the evidence that the answer must keep.

## Find the exact code

Find a function, class, or property and read its source. If several declarations share a name, Kast gives their signatures and locations.

> Use Kast to find submitOrder in this repository. Show the matches and their source locations.

## Understand what connects to it

Find callers, references, implementations, or overrides. Use those connections to investigate a feature or review the code around a proposed change.

> Use Kast to find the callers of the submitOrder function I selected. Show where each call occurs.

> Use Kast to find implementations of CacheManager in this project.

## Find reported problems

Ask for the problems that IntelliJ reports in the selected code.

> Use Kast to inspect the IDEA diagnostics for the function I selected.

## Make a targeted change

Kast can add a declaration to an existing Kotlin file or replace a supported function body. It reports the edit outcome.

> Use Kast to replace the selected retryLimit function's body with `{ return 3 }`. Keep its signature unchanged.

These edits cover specific targets. Kast does not rename symbols, create files, or do multi-file refactors through its change tools.

After an edit, review the diff. Run your project's build and tests.

The [change guide](/reference/change) describes supported targets and the receipt needed before another write.

## Know when an answer needs more work

Kast reports when it cannot finish a search or prove a relationship. A limited answer does not prove that no matches exist.

Your agent can use the reported reason to narrow the question or resolve a setup problem.

Use [Find and trace code](/reference/search) for scoped discovery. Use [Inspect diagnostics](/how-to/inspect-diagnostics) for reported problems.

Use [Read retained evidence](/how-to/read-retained-evidence) when the response supplies more evidence than one preview.
