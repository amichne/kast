After [installing Kast](/start), add CLI guidance for your agent. Add `--mcp` only if you need the optional MCP service.

## 1. Install guidance for your agent

<Tabs>
  <Tab title="Codex">
    The bundled plugin supplies the Kast skill and CLI guidance.

    ```shell
    kast install codex
    ```
  </Tab>
  <Tab title="Copilot">
    ```shell
    kast install copilot
    ```
  </Tab>
  <Tab title="Pi">
    ```shell
    kast install pi
    ```
  </Tab>
</Tabs>

Start a fresh agent session in your Kotlin repository or worktree to load the guidance.

Codex and Copilot own their plugin resources and configuration. Pi stores the Kast skill in its native skill directory.

<span id="task-tools" />
<span id="task-service-builds" />

### Optional MCP

Add `--mcp` to select the optional MCP composition:

```shell
kast install codex --mcp
kast install copilot --mcp
kast install pi --mcp
```

The MCP service needs uv 0.12.9 or later and Python 3.12 or 3.13. It can download Python and pinned dependencies on its first run. The persistent IntelliJ IDEA Host supplies compiler analysis for both the CLI and MCP.

To return to CLI guidance, repeat your agent's command without `--mcp`. Kast removes the MCP resources it owns. It keeps other registrations.

## 2. Continue your work

The installed guidance tells your agent how to use Kast during supported Kotlin work.
Describe your task naturally. The agent can inspect the installed contract with `kast describe`.
See [agent capabilities](/search) for the available evidence and the [CLI reference](/reference/cli) for command forms.

Each result applies to its stated worktree, source state, and scope.

<a id="choose-a-connection-destination" />
<span id="3-set-a-custom-destination-when-needed" />

## 3. Export the canonical skill

To export the skill into the current repository, run:

```shell
kast install skill
```

The default parent is `./.agents/skills`. Kast writes the skill under `./.agents/skills/kast`.

To select another parent directory, use `--output`:

```shell
kast install skill --output ./guidance
```

This command selects `./guidance/kast` as the skill directory.
`--output` belongs to `install skill`. `--mcp` belongs to agent installation.

An identical skill returns `ALREADY_INSTALLED` without writes. A different or incomplete skill returns `SKILL_EXISTS` and leaves the destination unchanged. Select another output directory or explicitly remove the old skill before another export.

## Refresh guidance after a core change

Kast refreshes the skill for each harness that it identifies as a Kast installation.
The skill front matter records the installed Control version.
If Kast reports `HARNESS_REFRESH_REQUIRED`, repeat your agent's installation command:

```shell
kast install codex
```

Use `copilot` or `pi` for those agents. Keep `--mcp` if you select the optional MCP composition.
Then start a fresh agent session.

Standalone skill exports keep the same no-overwrite rule after a core change.
