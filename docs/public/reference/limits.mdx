Execution allowances constrain resource use. They do not change the requested source scope, traversal extent, or output shape.

## Execution budget

`executionBudget` accepts these optional dimensions. Omission or `null` selects configured defaults. Positive requests remain subject to operator and transport ceilings.

| Field | Unit | Meaning |
| --- | --- | --- |
| `maxElapsedMs` | Milliseconds | Elapsed allowance for the admitted operation. |
| `maxWorkUnits` | Work units | Allowance for accounted semantic work. |
| `maxResults` | Rows | Result allowance. A row limit alone does not prove completed semantic work. |
| `maxReturnedBytes` | Bytes | Allowance for returned data. Callback-proof storage uses separate accounting. |

The response reports the admitted grant. A requested value does not establish that Kast admitted the full value.

An internal continuation shares the original operation's grant. Public output continuations and retained result cursors grant presentation only.

## Completion failures

| Code | Failed fact | Preserved evidence |
| --- | --- | --- |
| `COMPLETION_UNSUPPORTED` | The output or question has no supported completion proof. | The finite cause. |
| `COMPLETION_UNPROVEN` | Execution or callback proof does not establish the requested complete answer. | Original coverage and available retained evidence. |
| `INVESTIGATION_UNPROVEN` | An impact investigation lacks original evidence, complete path selection, or discharged obligations. | The investigation's original accounting. |
| `RETENTION_UNAVAILABLE` | Necessary evidence storage failed. | Original enumeration coverage and the storage cause. |
| `RESULT_FIELD_UNAVAILABLE` | The retained result lacks the requested field or finalized witness section. | The result's original qualifications. |

This table groups common failures. The generated result schemas define the complete closed variants and case-specific details.

## Identity and state failures

Exact references need current compiler identity admission. Retained results and output continuations need their original workspace, owner, read state, and lifetime.

Expiry, eviction, owner retirement, incompatible identity, or stale state can prevent reuse. A larger resource grant cannot restore missing state.

`READ_SOURCE` accepts an issued `candidateSelector` as `candidateRef`. An exact symbol reference does not belong to that action's token family.

## Write failures

A missing response, timeout, or cancellation does not establish that no source effect occurred. A change result keeps its plan and phase evidence.

The [change procedure](/reference/change#read-the-receipt) establishes the effect before another write. The project's tests establish behavior beyond the receipt's scope.
