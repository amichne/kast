Kast connects your coding agent to IntelliJ IDEA’s Kotlin analysis. Ask it to find a declaration, trace its callers, inspect source, or make a targeted change. Each result identifies what Kast found and whether the query covered the scope you requested.

## From search to source changes

**Find a declaration.** Start with a name or a word you remember from the source, and narrow the search to a module or directory. Check the returned signature and location, then reuse its exact reference in your next query. See [Find and trace code](/search).

**Trace relationships.** Find callers, implementations, or references, and follow them to a chosen depth. Kast reports any work left unfinished. You can also [combine retained results](/query-pipelines) to compare declarations found by separate queries.

**Make a targeted change.** Add a declaration to an existing Kotlin file or replace a supported function body. Kast uses an exact reference to identify the target and returns a receipt with the verification outcome. See [the change guide](/change) for supported targets and recovery.

## Why the evidence matters

Finding one confirmed caller does not mean every caller was found. An empty, incomplete result does not prove that a declaration is absent. Kast reports these limits so your agent can distinguish a useful finding from a finished search.

References also depend on the workspace and source state that produced them. Kast checks whether they can still be used. Read [What an answer proves](/concepts/evidence-boundaries) for coverage and reuse, or [How Kast works](/concepts/architecture) for the request flow.

## Supported environment

Kast supports Kotlin Gradle projects on Apple silicon macOS with IntelliJ IDEA `262.*`. Connect Codex, Copilot, or Pi. Kast prepares the selected IDEA project when a query needs it and reports any setup blocker.

Check [compatibility](/reference/compatibility) before installing. After a source change, run the build and tests your project requires; Kast’s edit verification and IDEA diagnostics cover their reported scope.
