The selected query output determines the row shape. Use the generated variant for symbols, occurrences, traversal records, bindings, or impact evidence.

Keep exact references, relation evidence, and qualifications with the row. A matching display name does not establish shared identity. See [Query forms](/reference/api#choose-the-result-you-need) for output selection.
