Use this guide to install Kast and ask your first question in Codex. The installer offers the Codex plugin by default.

## Before you install

You need:

- An Apple silicon Mac.
- A Kotlin Gradle project.
- IntelliJ IDEA `262.*` with its bundled Kotlin plugin and Java 25 JBR.

<span id="1-install-kast" />

<Steps>
  <Step title="Install Kast">
    Run this command in a terminal:

    ```shell wrap
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/amichne/kast/main/install.sh)"
    ```

    The installer adds Kast and its IntelliJ plugin. Accept the default Codex plugin installation when the installer asks.
  </Step>
  <Step title="Load the IDEA plugin">
    <span id="2-restart-intellij-idea" />

    Restart IDEA to load the plugin. Then examine the installation:

    ```shell
    kast status
    ```

    If your terminal cannot find `kast`, use the command path that the installer prints.

    <span id="3-connect-your-agent" />
  </Step>
  <Step title="Connect your agent">
    <span id="3-ask-your-agent" />

    The installer offers the Codex plugin by default. Continue with [Connect your agent](/agent-harnesses) to load it and select the exact worktree.

    Use the same page for Copilot or Pi. [Installation reference](/reference/installation) covers release channels and installer options.
  </Step>
</Steps>

## 4. Establish readiness

Complete [the first-query exercise](/tutorials/first-query) in the selected project. Compare the returned declaration and caller with the exercise source.

<Warning>
  `kast status` reports installation state. A tool catalog proves availability. A fresh semantic query establishes that the selected project admits the requested read.
</Warning>

If setup stops, use [Troubleshoot Kast](/troubleshooting).
