Direct MCP places the canonical `add_declaration` document in `result.structuredContent`. It keeps plan identity, source-effect phase, and recovery evidence.

`replace_body` has its own `replace_bodySemanticResult` schema. Its result must keep the same distinction between known rejection and uncertain source effect.

A lost reply does not prove absence of a write. [Change recovery](/reference/change#read-the-receipt) establishes the effect before another write.

[Schemas](/reference/schemas) defines tool-specific documents. [Lifecycles](/reference/lifecycles#hosted-workspace-settlement) describes uncertain mutation settlement.
