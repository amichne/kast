---
title: "Tool RPC reply"
description: "Select the catalog, operation document, or process failure from a Tool RPC reply."
openapi-schema: "reference/callables.openapi.json ToolRpcReply"
mode: "wide"
---

The reply's `type` selects the catalog, canonical document, or finite process failure. Each tool document keeps its own semantic status.

`complete`, `qualified`, and `rejected_document` carry `document`. `rejected` carries `failure`. `catalog` carries installed tool schemas.

Unknown variants represent an incompatible contract. [Tool RPC contract](/reference/rpc-catalog#decode) defines the union and process invocation.
