After [setup](/start), give your agent the function, file, or directory you want to investigate. Use these questions to bring Kast into the task.

## What depends on this function?

<Prompt description="Find callers before an edit" actions={["copy"]}>
Use the Kast CLI to find the callers of this function. Show the source locations and explain how they use it.
</Prompt>

## Where does this value go?

<Prompt description="Follow a function's result" actions={["copy"]}>
Use the Kast CLI to trace this function's result. Show where it goes and where the evidence stops.
</Prompt>

## What problems does IDEA report?

The optional [MCP composition](/reference/integrations#optional-mcp) exposes a diagnostics task.

<Prompt description="Inspect the code you changed" actions={["copy"]}>
Use Kast to inspect IDEA diagnostics in the code we changed.
</Prompt>
