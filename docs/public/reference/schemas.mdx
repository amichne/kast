## Read a schema without reading every definition

Read the necessary root properties first. Select the action variant, then read its necessary properties. For `RUN`, choose a source, the necessary steps, and an output. [Query forms](/reference/api) explains supported combinations.

Admission supplies defaults. A valid schema establishes the input shape. Current identity, complete coverage, and permission to change source need separate evidence.

## Samples and observed responses

Generated samples include valid cases and deliberate rejection cases. Their opaque references are placeholders. Get current handles from your workspace before use. These samples do not record native responses.

The recording replaces only the absolute checkout prefix with `/workspace/kast`. References, offsets, identity, and qualifications stay intact. The capture predates compact output.

To reproduce the example, use the linked source checkout. Send each `request` to `kast-tool-rpc-complete call query_symbols` in order. Substitute newly issued references. During composition, pause builds and source edits. Read the counts and coverage from your own run.

Generated shape checks cover the captured requests and responses. They do not replay the IDEA interaction.

OpenAPI `/callables/…` labels identify documentation sections. Use [MCP](/reference/mcp-catalog) or [Tool RPC](/reference/rpc-catalog) for the transport interface.
