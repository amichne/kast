## Try three changes

- **Return a different value:** the list contains a separate value. The original route does not reach it.
- **Use the value twice:** choose either use of the same producer.
- **Stop at a missing connection:** the route stops where the example lacks evidence.

A search for `Pet` finds text in all these examples. The connections explain why the answers differ.
