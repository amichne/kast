<span id="what-kast-adds" />

Kast helps your coding agent answer questions about your Kotlin code with IntelliJ IDEA's compiler analysis.
Find the callers of a function or trace supported value paths, with source locations you can inspect.

Use the native `kast` command with Codex, Copilot, or Pi.

## Start with one function

Give your agent the function's file and name.

<Prompt description="Before you change a function" actions={["copy"]}>
Use the Kast CLI to find the callers of this function. Show the source locations and explain how they use it.
</Prompt>

Use the returned source locations to inspect each caller before an edit.
A caller result describes source relationships. It does not prove that those calls ran.

For another task, choose [an example question](/search) or use the [CLI reference](/reference/cli) for terminal commands.

<span id="a-name-match-does-not-explain-a-value-path" />

To see how a value path differs from a name match, [follow a value through code](/explanation/value-journey).

If setup or a query stops, use [Help](/troubleshooting) to choose the next action.
