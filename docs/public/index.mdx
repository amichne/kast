Your agent gets the same facts that IDEA shows you: which declaration a call resolves to, which code calls it, and which problems IDEA reports.

<span id="a-name-match-does-not-explain-a-value-path" />
<span id="start-with-one-function" />

## What changes for your agent

| Question | Text search | Kast |
| --- | --- | --- |
| Which `send` does this call use? | Every function named `send`. | The one declaration that IDEA resolves. |
| Who calls `submitOrder`? | Lines that contain the name. | Resolved callers, with file locations. |
| Are there no callers? | An empty search proves nothing. | The answer says if the search finished, and in what scope. A finished search can return zero callers. |

<span id="use-the-evidence-for-your-next-decision" />

## How it works

1. You install Kast. The installer adds a plugin to IntelliJ IDEA and a `kast` command. You restart IDEA.
2. You install guidance for your agent: Codex, Copilot, or Pi.
3. You open your project in IDEA and work with your agent as usual. When the agent needs facts about your code, it runs `kast`, and IDEA answers.
