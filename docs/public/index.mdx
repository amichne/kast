## What your agent can do

- Find a declaration by name, source location, or matching word.
- Read source and distinguish declarations with the same name.
- Find references, callers, implementations, and overrides.
- Inspect IDEA diagnostics for a file or directory.
- Add a declaration or replace a supported function body.

[Example questions](/search) show these tasks in an agent conversation. Codex, Copilot, and Pi use distinct adapters to reach the same semantic owners.

## Before your first query

Use an Apple silicon Mac and a Kotlin Gradle repository. Kast needs IntelliJ IDEA `262.*` with its bundled Kotlin plugin and Java 25 JBR.

[Install Kast](/start), then [connect your agent](/agent-harnesses). The plugin's MCP session starts IDEA setup for projects with `settings.gradle.kts`. If trust, import, or indexing blocks a query, Kast reports the cause.

A complete answer applies to its declared source scope and compiler-static model. It does not prove that code ran or that the project builds.

[What an answer proves](/reference/evidence-boundaries) explains these limits. Your project's build and tests prove behavior after a change.
