# VFS-passive static task ownership

This directory owns the graph-named KVP-032 static task adapter. It composes source-symbol,
compiled-bytecode, module-edge, firewall, and physical transitive-classpath evidence into the
generated `VfsPassiveStaticProof` report.

It also owns KVP-033's non-cacheable dynamic report adapter. That adapter admits only exact
failure-free JUnit class evidence from the production single-flight, cancellable-read,
epoch-revalidation, and bounded VFS-storm selectors; its negative task mutates every prohibited
effect, concurrency bound, and stale-result invariant.

- Keep raw files and JSON confined to the Gradle task boundary.
- Preserve the typed `Complete`, `Qualified`, and `Rejected` admission protocol.
- Never replace compiled or physical scanning with source-text inference alone.
- Write only the graph-declared KVP-032 report output.
- Keep KVP-033 timings as observations, never as the correctness inference; typed assertions and
  zero prohibited-effect counts remain the proof authority.
