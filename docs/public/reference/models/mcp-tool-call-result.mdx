The MCP result wrapper carries display text in `content[]` and an admitted operation document in `structuredContent`. `isError` reports tool-call failure.

The semantic document has its own completion status and evidence. `health_check` uses a distinct readiness document.

A successful transport exchange does not establish semantic completion. An invocation failure can return without structured semantic evidence.

[MCP](/reference/mcp-catalog) defines discovery and calls. [Results](/reference/responses) defines proof and presentation inside the document.
