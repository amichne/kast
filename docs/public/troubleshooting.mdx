<span id="1-identify-the-failed-stage" />

## Your agent has no Kast tools

Complete the [connection commands](/agent-harnesses), then restart your agent. Select the Kotlin repository or worktree that you want to use.

## IntelliJ needs your attention

Resolve the trust, project import, or indexing problem that Kast reports in IDEA. Then repeat your question.

If Kast reports a mismatched IDEA installation, compare it with the [installation needs](/start#before-you-install).

## Kast cannot finish a search

Read the reason in the answer. Ask your agent to narrow the question to a function, package, or directory.

If Kast reports stale code references, ask your agent to find the code again.

## An edit has an uncertain outcome

Ask your agent to inspect the source and edit record before it repeats the change. Review the diff and run your project's tests.

<span id="2-inspect-the-installation-before-recovery" />

## Inspect or update Kast

To inspect Kast, run:

```shell
kast status
```

To update Kast, run:

```shell
kast upgrade
```

After an update, restart IDEA and your agent. For the Codex plugin, repeat `kast plugin codex`.

<span id="3-repeat-the-original-operation" />

After recovery, repeat your question in the intended worktree.
For an uncertain edit, inspect the source before another write.

Use the [detailed troubleshooting guide](/reference/troubleshooting) for contract and saved-state failures.
