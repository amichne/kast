See the [MCP contract](/reference/mcp-catalog) or [tool RPC contract](/reference/rpc-catalog). Return to [Schemas and samples](/reference/schemas) for related contracts.

<Accordion title="Invocation contract">

Add one declaration at an exact top-level Kotlin target. A class or object target inserts into its existing body. A function, property, or type alias target inserts after that declaration. Kast plans and applies the change, examines the resulting source, and reports a verified receipt or finite failure with recovery evidence. Preserve the returned result. A cancelled or missing response does not prove that no write occurred.

</Accordion>
