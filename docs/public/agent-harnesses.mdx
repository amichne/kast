Each connection binds requests to the exact Gradle repository or worktree. The installed catalog defines the tools and schemas for that release.

| Connection | How it works | Discover tools |
| --- | --- | --- |
| Direct MCP | The installed process runs over stdio from the client's repository directory. | `tools/list` |
| Tool RPC | A one-shot JSON process interface. Read the catalog, then call one tool with JSON on stdin. The included adapters support Copilot CLI and Pi. | `kast-tool-rpc-complete catalog` |
| Codex App Server | A persistent hosted integration with schemas supplied to the conversation. It also exposes explicit workspace lifecycle control. | Provider catalog for the conversation |

The Codex App Server's compatibility status remains preview. Ordinary semantic calls prepare the workspace themselves; `workspace_lifecycle` is for explicit project control.

## Rediscover after upgrades

Do not cache tool names or hand-build input assumptions across releases. Read the live catalog after installation or upgrade. It identifies supported inputs, effects, and result schemas.

## Read the full result

Each transport adds an outer wrapper around the operation document. Check both. Preserve exact refs, coverage, qualifications, item failures, and continuation tokens from the canonical document. The [MCP](/reference/mcp-catalog) and [Tool RPC](/reference/rpc-catalog) contracts show their exact wrappers.

## Hosted schema labels are documentation paths

OpenAPI `POST /callables/…` entries group hosted callable schemas in the reference. They are not HTTP endpoints. MCP and Tool RPC use their own client protocols.

For installation, use [Install Kast](/start). The [repository integration guide](https://github.com/amichne/kast/blob/main/docs/tool-rpc.md) contains the Copilot CLI and Pi adapter setup. The [App Server compatibility record](https://github.com/amichne/kast/blob/main/app-server/docs/compatibility.md) gives its tested boundary.
