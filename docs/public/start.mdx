Connect Kast to the agent you already use. These steps install the stable release.

## Before you install

Use an Apple silicon Mac, a Kotlin Gradle project, and IntelliJ IDEA `262.*` with its bundled Kotlin plugin and Java 25 JBR. Install your chosen agent CLI and Python 3.9 or later, available as `python3`.

## 1. Install Kast

<span id="choose-your-agent" />

<span id="1-connect-your-agent" />

<Tabs sync={false}>
  <Tab title="Codex">
    Run this command to install Kast and its Codex plugin:

    ```shell wrap
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/amichne/kast/main/install.sh)" -- --install-codex-plugin
    ```
  </Tab>
  <Tab title="Copilot">
    Install Kast:

    ```shell wrap
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/amichne/kast/main/install.sh)" -- --skip-codex-plugin
    ```

    After installation succeeds, add its Copilot plugin:

    ```shell wrap
    copilot plugin install "$HOME/.local/share/kast/installation/share/kast/agent-tools/plugins/kast"
    ```

    If you already use the optional Kast RPC extension, follow the [migration instructions](/agent-harnesses) first.
  </Tab>
  <Tab title="Pi">
    Install Kast:

    ```shell wrap
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/amichne/kast/main/install.sh)" -- --skip-codex-plugin
    ```

    After installation succeeds, connect Pi:

    ```shell wrap
    "${XDG_CONFIG_HOME:-$HOME/.local/bin}/kast" connect pi
    ```

    This path works for a fresh installation. For an existing installation, use the command path the installer prints.
  </Tab>
</Tabs>

## 2. Restart your tools

<span id="2-restart-intellij-idea" />

<span id="3-connect-your-agent" />

Restart IntelliJ IDEA to load Kast. Start a fresh agent session in the same Kotlin repository or worktree. In Codex, review and trust the Kast session context hook.

## 3. Ask about your code

<span id="3-ask-your-agent" />

<span id="4-establish-readiness" />

<span id="what-your-first-result-establishes" />

Give your agent the function's file and name.

<Prompt description="Find the callers of your function" actions={["copy"]}>
Use Kast to find the callers of this function. Show the source locations and explain how they use it.
</Prompt>

Kast prepares the project as needed. The first query can wait for Gradle import and indexing. Your agent can use the returned locations to continue your task.

If setup stops, use [Help](/troubleshooting). For another task, try [example questions](/search).

[Installation options](/reference/installation) include developer builds and another IDEA installation.
