An exact reference carries compiler-established declaration identity into another request. Its producing query separately supplies scope and coverage.

## Public fields

| Field | Meaning |
| --- | --- |
| `ref` | Opaque handle for subsequent identity admission. |
| `location` | Established declaration location. |
| `signature` | Compiler-established identity and callable or property facts. |
| `source` | Bounded committed source, when requested. |

Signature and location distinguish candidates for human selection. The issued `ref` supplies the identity that Kast admits for semantic operations.

`SOURCE` adds bounded committed source context. Anonymous bodies and exact occurrences use the separate anchored `READ_SOURCE` action.

Source positions use UTF-16 code units. Byte offsets and line numbers do not replace the encoded range.

## Local declarations

Local properties use `LOCAL_PROPERTY` signatures with type and `VAL` or `VAR` mutability. Local named functions use `LOCAL_FUNCTION` signatures.

Their identities keep the file, declaration range, compiler identity, containing declaration range, and bounded lexical ownership ranges.

Equal names in separate scopes identify separate declarations. A local property identity does not establish its assignment flow.

Local reacquisition needs unchanged owning-file content. A local edit or move needs fresh discovery, even when the displayed signature stays the same.

## Evidence limits

A local function identity does not establish execution of its deferred body. An anonymous body's lexical container does not automatically become its named caller.

[Program tracing](/reference/program-tracing) connects those identities to callback and value-flow evidence. [Staleness](/reference/staleness) defines reuse.

## Output selection example

This output adds descriptive fields to the necessary identity and kind.

```json
{"type":"SYMBOLS","fields":["NAME","LOCATION","SIGNATURE","SOURCE"]}
```

[The query item schema](/reference/models/query-item) defines encoded rows. [The recorded lookup](/reference/walkthrough#1-find-a-declaration-and-inspect-its-source) illustrates source output.
