<Accordion title="Invocation contract">

Run, resume, and read compiler-grounded Kotlin queries in the bound workspace. For `RUN`, provide a source, zero or more `nonterminal` steps, and exactly one `terminalStep` object tagged `EMIT` or `TRACE`. Put output in `terminalStep`.output. `EMIT` accepts all output choices. `TRACE` accepts only symbols and owns `expansionScope` directly. Never put `TRACE` in steps or output on `RUN`. Apply known name, kind, scope, and source-set constraints before discovery. Start with request ` {"type":"RUN","source":{"type":"SEARCH_DECLARATIONS","declarationName":"Order","declarationKinds":["CLASS"],"scope":{"type":"DIRECTORY","relativeDirectoryPath":"orders","sourceSetNames":["main"]}},"terminalStep":{"type":"EMIT"}} `. Select the exact owner, receiver, signature, and location, never the first overload. Pass its unchanged issued ref in source ` {"type":"SYMBOL_REFS","symbolRefs":["<issued ref>"]} `. Use `EXPAND_RELATION` for direct references or callers. Use `TRACE` for references, implementations or overrides, direct callers, and one further caller layer. Discovery scope selects seeds. Expansion scope selects destinations. `SOURCE_DOMAIN` applies source-set, production/test, and generated-source constraints before enumeration. If the host supports tool composition, chain discovery, exact selection, and expansion inside code. Keep successful intermediate results inside that call. Return task findings with scope, completion, omissions, and recovery facts. Do not omit requested matches or hide failures to reduce tokens. Apply path exclusions before read batches. Remove duplicate paths. Reuse unchanged source reads until a source change or freshness rejection. Inspect unresolved imports, companion qualifiers, and unmatched source sites before a complete source-use answer. Every `RUN` uses `COMPLETE_ONLY` within `COMPILER_RESOLVED_STATIC_V1`. Preserve typed rejection and recovery evidence when completion is unproven. Use `RESUME` only with an issued output continuation, `READ_RESULT` with an issued result reference and cursor, and `READ_SOURCE` with an issued `candidateSelector` as `candidateRef`. Keep these capabilities distinct. Set retention `RETAIN` for later presentation. Budgets share one admitted grant under host ceilings. The schema also defines graph walk with `WALK`, predicates, retained composition, joins, and value `IMPACT`. Use known request shapes directly. Read only the needed schema section or named example for unfamiliar shapes. Stop when evidence answers the task.

</Accordion>
