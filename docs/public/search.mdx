Ask for a declaration, a relationship, and the scope you care about. Your agent translates that request into `query_symbols`; you do not need to write the JSON yourself.

## Follow the examples in Kast's source

These examples use the public [Kast repository at `56df091`](https://github.com/amichne/kast/tree/56df0912e46b182bb4ad8beabd1512823100fd72). Start your connected agent in that checkout to reproduce them. In another repository, replace the declaration name and directory with your own.

<Note>
  The requests below are based on the checked-in public schema. The result excerpts are expectations checked against source, **not recordings of a live Kast run**. They do not establish completeness, ordering, exact reference values, or a successful IDEA session.
</Note>

## 1. Find a declaration and inspect its source

**Ask your agent:**

> Use Kast to find `QueryStepSyntax` in the production sources under `query/contract`. Show its location, signature, and source. Keep its exact reference for the next question.

**Tool:** `query_symbols`

```json
{
  "request": {
    "type": "RUN",
    "source": {
      "type": "SEARCH_DECLARATIONS",
      "declarationName": "QueryStepSyntax",
      "declarationKinds": ["CLASS"],
      "scope": {
        "type": "DIRECTORY",
        "relativeDirectoryPath": "query/contract",
        "sourceSetNames": ["main"]
      }
    },
    "output": {
      "type": "SYMBOLS",
      "fields": ["NAME", "LOCATION", "SIGNATURE", "SOURCE"]
    }
  }
}
```

**What to look for in the answer:** the declaration in `query/contract/src/main/kotlin/io/github/amichne/kast/query/contract/QuerySteps.kt`, with an issued `ref` and coverage. `CLASS` selects the supported class-like family, including this interface; it is not a claim that the declaration is a concrete class.

The [source](https://github.com/amichne/kast/blob/56df0912e46b182bb4ad8beabd1512823100fd72/query/contract/src/main/kotlin/io/github/amichne/kast/query/contract/QuerySteps.kt) includes:

```kotlin
sealed interface QueryStepSyntax {
    data class ProjectBinding(val name: QueryBindingName) : QueryStepSyntax

    data class Where(val predicate: QueryPredicate) : QueryStepSyntax
```

The returned reference identifies the declaration. The name starts the search; it is not a replacement for that reference.

## 2. Follow its implementations

**Ask your agent:**

> Reuse that exact reference to find the implementations of `QueryStepSyntax`. Show each declaration once and retain the result so we can compare it with another query.

Replace the placeholder with the reference from step 1. Do not send the placeholder literally.

```json
{
  "request": {
    "type": "RUN",
    "source": {
      "type": "SYMBOL_REFS",
      "symbolRefs": ["<ref from step 1>"]
    },
    "steps": [
      {"type": "EXPAND_RELATION", "relation": "IMPLEMENTATIONS"},
      {"type": "DISTINCT_SYMBOLS"}
    ],
    "retention": "RETAIN"
  }
}
```

**Source-derived result excerpt:**

```text
QueryStepSyntax.Where
QueryStepSyntax.Concat
QueryStepSyntax.Intersect
QueryStepSyntax.Union
QueryStepSyntax.Join
```

These are examples of declarations present in the source, not the full expected response. Read the returned coverage before calling the list exhaustive. Keep the issued retained-result reference as **A** for [the composition walkthrough](/query-pipelines).

## 3. Trace farther, without asking for everything

**Ask your agent:**

> Select one exact Kotlin function, then trace its callers up to two hops. Show the hop depth and call-site evidence, and report any unvisited work.

Once the agent has selected the function's exact reference:

```json
{
  "request": {
    "type": "RUN",
    "source": {
      "type": "SYMBOL_REFS",
      "symbolRefs": ["<exact function ref>"]
    },
    "steps": [
      {"type": "WALK", "relation": "CALLERS", "maximumDepth": 2}
    ],
    "output": {"type": "TRAVERSAL_RECORDS"}
  }
}
```

The requested answer is a bounded caller trace, not a promise to enumerate the entire call graph. Each traversal record carries its depth and established relation fact. A continuation means there is resumable work; it is not permission to claim that the returned paths are exhaustive.

## Adapt the question to your codebase

Give the agent the declaration name or exact reference, the relevant module or directory, and the relationship you want. Specify whether you need unique declarations, individual use sites, or a bounded trace. Add a depth when asking for a walk.

A discovery scope limits where the starting symbols are found. It does **not** confine later relation destinations to that directory. Ask for a destination filter when that distinction matters.
