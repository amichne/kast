Check host admission, tool-schema compatibility, and evidence lifetime
separately. Passing one does not establish the others.

## Supported host

| Boundary | Current policy |
| --- | --- |
| Platform | macOS on Apple silicon |
| Repository | On-disk Kotlin Gradle repository |
| IDEA and bundled Kotlin plugin | Both in the `262` release line; patch builds may differ |
| JBR | Java 25 bundled with the selected IDEA |
| Native acceptance baseline | IDEA `262.10315.125`, Kotlin `262.10315.125-IJ` |

Other `262` builds are admitted by policy; the baseline remains the recorded
native acceptance evidence. Other release lines, Linux, Intel macOS, and other
languages are outside the current support contract. Full observed build
identities remain in runtime evidence. Protocol, schema, and artifact integrity
checks remain exact.

## Installed agent contract

Load `serverProjection` from the executable's `kast --schema` output. The current
projection is version 10 and its CLI-invocation projection is version 3. Validate
the complete catalog, schemas, policies, and bindings at provider startup.
Several tool names share a canonical operation; bind invocations by tool name.
[Harness integration](/agent-harnesses) gives the sequence.

The Codex App Server integration is a preview while its upstream protocol is
experimental. Full Desktop UI compatibility remains unqualified. Consult the
[source-backed compatibility record](https://github.com/amichne/kast/blob/main/app-server/docs/compatibility.md)
for the exact tested boundary.

## Upgrade a matched installation

Run the [installer](/start) for the selected release, then restart IDEA so the
matched plugin loads. The installer verifies the control, semantic-runtime, and
IDEA plugin payloads before activation. Repository source and unrelated
JetBrains state are preserved.

<Accordion title="Pin an approved release">
  Run the installer from the same explicit tag passed to `--version`:

  ```shell
  release_tag="v0.35.0"
  /bin/bash -c "$(curl -fsSL "https://raw.githubusercontent.com/amichne/kast/${release_tag}/install.sh")" \
    -- --version "$release_tag"
  ```

  Replace the example with your approved, published release. The example is a
  pinning pattern, not a recommendation to downgrade.
</Accordion>

Requalify the agent catalog after an executable upgrade. Do not reuse metadata
from a different installation. If startup or repository admission fails, retain
the reported boundary and use [Troubleshooting](/troubleshooting).

## Refresh evidence after changes

Compatible tool schemas do not keep a reference alive indefinitely. Saved source,
imported-model changes, and owner replacement can invalidate old references.
Search again when a reference rejects. Never reinterpret its token to make it fit
new evidence. [Evidence outcomes](/concepts/evidence-boundaries) explains the
claims retained by complete, qualified, and rejected results.
