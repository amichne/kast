Start with a declaration name and its module or directory. Your [connected agent](/agent-harnesses) writes the query.

## 1. Find a declaration and inspect its source

Substitute your name and directory:

```text wrap
Use Kast to find submitOrder under checkout in main. Show matching signatures, locations, and coverage. Stop so I can choose the exact function.
```

Select by signature and file. Ask the agent to read its source and keep its exact reference for follow-up queries.

For a Kotlin interface, use `declarationKinds: ["CLASS"]`. The request's `CLASS`
family includes supported class-like declarations, including interfaces and
objects; returned symbols report `kind: "classlike"`. `INTERFACE` and
`CLASSLIKE` are not accepted request kind values.

```json
{
  "request": {
    "type": "RUN",
    "source": {
      "type": "SEARCH_DECLARATIONS",
      "declarationName": "CacheManager",
      "declarationKinds": ["CLASS"],
      "scope": {
        "type": "PACKAGE",
        "packageName": "example.cache",
        "includeSubpackages": false,
        "sourceSetNames": ["main"]
      }
    },
    "output": {"type": "SYMBOLS", "fields": ["NAME", "LOCATION", "SIGNATURE"]}
  }
}
```

Find an interface method with `declarationName: "execute"` and
`declarationKinds: ["FUNCTION"]` in the same package. Inspect the signature's
qualified identity to select `example.cache.CacheManager.execute` from its
overrides. Exact name matching returns all eligible overloads and owners.

`AT_LOCATION` selects the nearest containing named declaration. An offset inside
the method's generic parameter list selects that method; an offset on
`manager.execute(...)` selects its enclosing declaration. It does not resolve
the `execute` use-site token to the interface method. To establish that link,
select the exact method and request `REFERENCES` or `CALLERS` in the intended
relationship domain. Use occurrence evidence to identify the exact use site.
Offsets and returned ranges use UTF-16 code units, not byte offsets or line
numbers. Recompute them from the current file after edits.

| Check | Why it matters |
| --- | --- |
| Signature | Distinguishes overloads. |
| Location | Confirms the intended repository and declaration. |
| Coverage | Reports whether the requested search finished. |
| Exact reference | Carries the selected identity into the next request. |

## 2. Find callers or implementations

For a function:

```text wrap
Use the exact reference we just selected to find its callers. Show each caller's location and the call site, and report the search scope and any limitations.
```

For an interface or base type:

```text wrap
Use the selected type's exact reference to find its implementations. Show each declaration once, with its signature and location. Report whether the search finished.
```

Discovery scope does not automatically restrict relationship destinations. Use `expansionScope` to restrict the relationship search domain. Use a later filter to restrict returned rows. See [Query forms](/reference/api#apply-only-the-steps-you-need).

## 3. Trace callers to a chosen depth

```text wrap
From the selected function, trace callers up to two hops. Show the hop depth and call-site evidence. Continue if Kast reports resumable work; otherwise explain any unvisited work or terminal limit.
```

Depth bounds the requested graph. Coverage reports unfinished work within that bound. Follow reported progress even on a zero-row page.

Invocations inside lambdas preserve separate ownership. Static callback paths do not prove runtime execution. See [Callback evidence](/reference/callbacks).

## Start from remembered text

```text wrap
Use Kast to find functions containing the word retry under checkout in main. Show a matching line for each function, then let me choose one to inspect or trace.
```

Use one case-sensitive ASCII word beginning with a letter or underscore. Phrases, substrings, qualified literals, and regular expressions are rejected. A word match explains discovery. A relation query establishes callers. Unsupported containers or a stopped scan leave coverage incomplete.

## Keep the investigation current

Pass issued references unchanged. After a stale-reference or unavailable-state failure, search again. Edits, IDEA restarts, and retention expiry can invalidate saved work.

A new opaque reference for the same signature and location does not by itself
prove a source change. Read `reference_acquisitions` when Kast reacquires an
exact handle, and retain each response's semantic basis. Signature and location
help select a declaration; they do not replace handle authority. Continuations
and source snapshots require their original basis. See [read-limit diagnostics](https://github.com/amichne/kast/blob/main/docs/hosted-read-configuration.md#read-the-evidence)
for the bounded epoch-movement signals.
