Install the IDEA plugin, connect Codex, and find a declaration in your repository.

<Note>The Codex integration is a preview. See the [compatibility record](/reference/compatibility) for tested boundaries.</Note>

## Requirements

| Boundary | Requirement |
| --- | --- |
| Platform | macOS on Apple silicon |
| Repository | An on-disk Kotlin Gradle repository |
| IDE | IntelliJ IDEA in the `262` release line |
| Kotlin | The Kotlin plugin bundled with that IDEA installation |
| Runtime | The Java 25 JBR bundled with IDEA |
| Agent | A compatible Codex client |

<Steps>
  <Step title="Install the matched release">
    Run:

    ```shell
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/amichne/kast/main/install.sh)"
    ```

    The installer reports the detected IntelliJ version, verifies Kast and the
    matching IDEA plugin, and enables the complete app-server suite and its
    per-user macOS login LaunchAgent. The LaunchAgent keeps the Kast
    app server available across logins and restarts it after an unexpected exit.

    It does not install IDEA.

    If the Kast release has no plugin for the installed IDEA release line, the
    installer names the mismatch and installs nothing.

    The installer does not add a Kast command to `PATH`.
  </Step>
  <Step title="Prepare IDEA">
    - Restart IDEA to load the plugin.
    - Save edited files before requesting evidence.

    The agent can open the requested repository and wait for Gradle import and
    indexing through its workspace setup tool. You do not need to run workspace
    lifecycle commands. Resolve project trust or unsaved-document blockers if the
    agent reports them; see [troubleshooting](/troubleshooting).
  </Step>
  <Step title="Register the repository and connect">
    ```console
    cd /path/to/kotlin-repository
    "${XDG_DATA_HOME:-$HOME/.local/share}/kast/current/share/kast/libexec/kast-service" register "$PWD"
    ```

    Then open the repository in your Codex client. Register each worktree you
    want Kast to serve. The persistent broker remains available after a client
    closes.
  </Step>
  <Step title="Ask for a declaration">
    Ask: **“Use Kast to find the class OrderService.”** Replace `OrderService`
    with a class in your project.

    A successful request returns matches with names, locations, and reusable
    `ref` values. Read the semantic status: a qualified result has limits;
    a rejected request needs the reported problem resolved.

    Continue with [Search declarations](/search) or [Read a response](/reference/responses).
  </Step>
</Steps>

## Setup alternatives

<AccordionGroup>
  <Accordion title="Force a clean installation">
    ```shell
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/amichne/kast/main/install.sh)" \
      -- --force
    ```

    Force installation retires the selected services, resets managed sockets and
    state and rebuilds the verified installation and
    IDEA plugin. It preserves source workspaces and rebuilds enrollment. Previous
    payloads and recovery records move aside under `.replaced-*`.
    Add `--dry-run` to preview without changing installation state.
  </Accordion>
  <Accordion title="Choose among multiple IDEA installations">
    ```shell
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/amichne/kast/main/install.sh)" \
      -- --idea-home "/Applications/IntelliJ IDEA.app"
    ```

    The recorded baseline is IDEA `262.10315.125` with Kotlin plugin
    `262.10315.125-IJ`.

    Other `262` builds are admitted by policy but lack the same native acceptance
    evidence. See [Compatibility](/reference/compatibility).
  </Accordion>
  <Accordion title="Old command links">
    An upgrade removes only links previously owned by Kast. An unrelated file
    named `kast` or `kast-codex` is left in place.
  </Accordion>
  <Accordion title="Connect Codex Desktop">
    Register the repository as above, then open that repository in Codex Desktop.
    Desktop uses the persistent broker. Closing Desktop leaves it running.
  </Accordion>
  <Accordion title="Use an explicit Codex executable or another harness">
    Other agent hosts should connect to the daemon through the
    [hosted contract](/agent-harnesses).
  </Accordion>
  <Accordion title="Uninstall Kast">
    ```shell
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/amichne/kast/main/install.sh)" \
      -- uninstall
    ```

    Uninstall removes Kast-owned links, installations, runtime state,
    configuration, and services.

    Repositories and unrelated JetBrains state remain.
  </Accordion>
</AccordionGroup>
