The installed `kast` command runs a stdio MCP server:

```shell
kast --internal-entrypoint=mcp
```

The Kast plugin registers this command, as [Connect your agent](/reference/integrations) shows. The agent starts the server.
The server's working directory selects the Kotlin repository or worktree.

Registration and catalog discovery do not grant trust or start a Host.
The first explicit semantic request grants trust to its exact workspace root and prepares the managed Host that the CLI also uses.
Use a workspace whose build code you trust. Desktop IDEA, user Python, and uv are not required.

## Catalog

`tools/list` supplies each tool's name, description, input schema, output schema, and annotations.
The installed schemas govern the session.

| Tool | Purpose |
| --- | --- |
| `query_symbols` | Run a public query: declaration selection, relations, traversal, trace, retained results, and source reads. |
| `check_diagnostics` | Read compiler diagnostics for a workspace-relative file or directory. |
| `add_declaration` | Add one declaration at an exact top-level Kotlin target. |
| `replace_body` | Replace the block body of one exact Kotlin function. |
| `health_check` | Inspect workspace readiness. |

The default catalog admits the common query grammar. To select the complete grammar, add `--catalog=COMPLETE` after the entry selector.
Custom-depth `WALK` and forward value `IMPACT` require the complete catalog.

Discovery does not prove IDEA readiness or semantic completion.
Use the first useful tool instead of a readiness probe.
Read the Kast skill for exact selection, destination scope, source regions, and recovery rules.
Source changes need the user's request and an issued exact target.

## Call and result

`tools/call` selects a tool and its input object.
The [callable schemas](/reference/schemas) define each input.

The reply puts display text in `content[]` and the checked tool document in `structuredContent`.
The document keeps its status, evidence, and recovery fields.
`isError` reports a failed tool call without removing the document.
A transport rejection returns `type: "MCP_REJECTED"` in `structuredContent`. See [Results](/reference/responses).

Decode both the MCP wrapper and the inner document.
A successful exchange does not prove that the semantic answer is complete.
Cancellation stops the call, but submission or effects can remain uncertain. Never retry automatically.

## Select a producer invocation

The complete catalog also lists `producer_invocations` and `impact`.
Pass an issued exact callable reference as `callable` to `producer_invocations`.
Each eligible Kotlin call has a `producerSeed` with its enclosing declaration, target callable, and full invocation range.
No UTF-16 offset needs to be computed.
Choose the occurrence for the intended call.
Pass its `producerSeed` unchanged to `impact`.

The default response presents retained findings for that workspace.
Set `section` to another impact witness section to select different evidence.
A stale range rejects before the compiler examines the call.
Repeat discovery after a stale selection.
For custom domains, requested sites, or models, pass the same seed to the full `IMPACT` query.

Exact reference: [Schemas and samples](/reference/schemas).
