`query_symbols` selects a semantic operation through `request.type`. Its sources, stages, outputs, and scopes define the question that Kast must answer.

The installed catalog owns the release contract. [Generated schemas](/reference/schemas) define exact fields, discriminators, and legal combinations.

<a id="choose-an-action" />

## Actions

| Action | Necessary input | Behavior |
| --- | --- | --- |
| `RUN` | `source` | Evaluate optional `steps` in order. Select `output` and optional `retention`. |
| `RESUME` | Issued output `continuation` | Present remaining produced output without semantic execution. |
| `READ_RESULT` | Issued `result`. Optional `cursor` | Present retained rows without semantic execution. Output must match the retained row type. |
| `READ_SOURCE` | Issued `candidateRef` | Read an exact anchored occurrence or anonymous body. See [callbacks](/reference/callbacks#read-the-exact-anonymous-source). |

`RUN` establishes a new answer. `RESUME` and `READ_RESULT` present produced evidence without new semantic work.

`READ_SOURCE` selects an anchored occurrence or anonymous body through its issued `candidateRef`. Exact symbol references belong to a different input family.

```json
{
  "request": {
    "type": "RUN",
    "source": {
      "type": "SEARCH_DECLARATIONS",
      "declarationName": "QueryStepSyntax"
    }
  }
}
```

Omitted output selects symbol names and locations. `retention: "RETAIN"` keeps the result for later reads or composition.

Every public `RUN` uses `COMPLETE_ONLY` within `COMPILER_RESOLVED_STATIC_V1`. A supplied completion selector rejects admission.

The runner drains internal semantic pages under one grant. Missing proof returns `COMPLETION_UNPROVEN` with available evidence.

## Sources

| Source | Purpose |
| --- | --- |
| `SEARCH_DECLARATIONS` | Simple declaration name. Exact, case-sensitive matching by default. Fuzzy matching is explicit. |
| `SEARCH_TEXT` | One case-sensitive ASCII identifier word. Exact containing declarations and match context. |
| `ALL_DECLARATIONS` | Supported Kotlin declarations, including nested declarations, ordered by file path and source offset. |
| `AT_LOCATION` | Nearest containing named declaration at a workspace-relative `file` and UTF-16 `offset`. |
| `SYMBOL_REFS` | Exact references from previous results. |
| `RESULT` | Retained rows, optionally selected by their issued row IDs. |
| `IMPACT` | Producer values through supported Kotlin transfers and supplied reviewed models. |

Discovery defaults to recursive workspace scope in `main` and `test`. Directory, package, source-set, and kind constraints restrict seed discovery.

Those seed restrictions do not limit later relationship destinations. `expansionScope` controls that separate domain.

`SEARCH_DECLARATIONS` uses exact case-sensitive names by default. Explicit fuzzy matching changes name selection without proof of unique identity.

`SEARCH_TEXT` accepts one ASCII identifier word that starts with a letter or underscore. Phrases, substrings, qualified literals, and regular expressions reject admission.

`ALL_DECLARATIONS` includes supported nested Kotlin declarations. It excludes direct library enumeration and keeps the admitted declaration-family restrictions.

`AT_LOCATION` selects the nearest containing named declaration. An offset on a call expression selects its container rather than its target.

## Ordered stages

| Step | Meaning |
| --- | --- |
| `WHERE` | Filter compiler-confirmed visibility or literal `NAME`, `KIND`, or `FILE`. Comparisons: `EQUALS`, `NOT_EQUALS`, `STARTS_WITH`, `ENDS_WITH`. |
| `DISTINCT_SYMBOLS` | Keep the first row per canonical identity at this pipeline position. |
| `EXPAND_RELATION` | One hop through `REFERENCES`, `CALLERS`, `CALLEES`, `IMPLEMENTATIONS`, `INHERITORS`, `OVERRIDES`, or `TYPE_USES`. |
| `WALK` | Exhaust the reachable graph with omitted or null `maximumDepth`. An explicit depth limits reach. Breadth-first by default. |
| `TRACE` | Terminal bounded investigation returning the seed, its direct callable members, reference owners, implementations or overrides, direct callers, and one further caller layer. Select `SYMBOLS`. |
| `CONCAT` | Append `input`, preserving order and duplicates. |
| `UNION`, `INTERSECT`, `DIFFERENCE` | Compare saved symbol rows in `right` by canonical identity. Difference needs complete coverage of that input. |
| `JOIN` | `INNER` pairs named cells. `SEMI` keeps matches. `ANTI` needs complete coverage of `right` to establish absence. |
| `PROJECT_BINDING` | Select one named symbol cell before further symbol steps. |

Stages consume the preceding stage's row kind. A stage after composition acts on the combined stream.

`WHERE` cannot retroactively reduce native enumeration. Known discovery constraints and native expansion scope must apply before expensive semantic work.

<a id="trace-an-interface-or-adapter" />

### TRACE topology

`TRACE` is a terminal stage with `SYMBOLS` output. It groups results by canonical identity while it preserves relation and occurrence evidence.

Its fixed topology includes the seed, direct callable members of type seeds, reference owners, implementations or overrides, and direct callers.

One further caller layer includes discovered owners and callers. Imported type uses and ordinary code references keep distinct occurrence evidence.

Member inventory uses source and compiler evidence. It does not invent a class-to-member call edge or a named caller for a type.

`TRACE` supports bounded static investigations of interfaces and adapters. It does not establish an exhaustive runtime graph.

<a id="choose-the-relationship-search-domain" />

### Relationship search domains

| Scope | Meaning |
| --- | --- |
| `WORKSPACE` | Workspace expansion. Default for `EXPAND_RELATION` and for `WALK` with omitted or null `maximumDepth`. |
| `RETAINED_SEED` | Scope carried by each seed. Default for `WALK` with explicit `maximumDepth`. Acquire an `AT_LOCATION` seed for exact-file scope. |
| `SOURCE_DOMAIN` | Exact imported `sourceSets`, source policy, generated-source policy, and optional workspace-relative directory. |

Omission or `null` selects the operation's default. Explicit expansion scope applies before relation enumeration.

`SOURCE_DOMAIN` needs `sourcePolicy` and `generatedSources`. Its `includeSubdirectories` default is `true`.

An omitted or null `WALK.maximumDepth` requests the reachable graph and defaults to workspace expansion. Its evidence records `EXHAUSTIVE` extent.

An explicit depth includes nodes at that depth without expansion from those nodes. Its evidence records `THROUGH_DEPTH` and `maximum_depth`.

Complete traversal needs complete one-hop reads at every necessary node. Resource exhaustion cannot silently reduce the requested extent.

<a id="choose-the-result-you-need" />

## Outputs

| Output | Evidence |
| --- | --- |
| `SYMBOLS` | Identity and kind, plus selected `NAME`, `LOCATION`, `SIGNATURE`, or bounded committed `SOURCE`. |
| `OCCURRENCES` | Relation facts and use sites, including file-scoped imports and aliases. |
| `TRAVERSAL_RECORDS` | Relation facts with hop depth. |
| `BINDING_ROWS` | Named cells from an inner join. |
| `VALUE_PATHS` | Producer sites, transfers, model applications, representation history, terminals, and obligations. |
| `IMPACT_WITNESS` | Retained impact sections from a complete-only `IMPACT` run or `READ_RESULT`. |

Explicit symbol `fields: []` selects identity and kind alone. `SOURCE` adds bounded committed source context.

File-scoped occurrences preserve imports and aliases. They cannot act as declaration endpoints for later graph expansion.

<a id="investigate-value-impact" />

## Value impact inputs and qualifications

`IMPACT` traces exact producer invocations with `KOTLIN_FORWARD_V1`. Its input must state seeds, declarations, domain, flow, and reviewed models.

| Input | Requirement |
| --- | --- |
| `seeds` | Issued `enclosing` and producer `callable` references, plus UTF-16 `start` and `end` covering the whole invocation. |
| `declarations` | Modeled callable references paired with identity claims for fresh revalidation. |
| `flow` | `KOTLIN_FORWARD_V1`. |
| `domain` | Explicit expansion scope. |
| `models` | Reviewed representation rules or rules for modeled interfaces. `[]` supplies none. |
| Optional `requestedSites` | Enclosing identity, range, and role. Argument sites also identify invocation, callable, and formal parameter index. |

Native reads establish invocation and site identity. Supplied models establish representation meaning or modeled callable behavior.

`IMPACT` accepts no transformation steps. `VALUE_PATHS` presents paths, while `IMPACT_WITNESS` presents a section after the original investigation completes.

A final try or catch value can supply its try expression through a compiler-confirmed normal-completion transfer. Catch fallback values keep separate producers.

Non-final expressions do not supply that result. Returns keep return transfers, and throws do not supply normal branch values.

A transfer across `finally` keeps `FINALLY_UNSUPPORTED`. Mutable, cyclic, or unsupported flow also keeps its unresolved proof.

Strict completion needs all original paths and discharged obligations from the original ledger. Selected preview paths cannot replace that accounting.

<a id="read-retained-witnesses" />

### Retained witness sections

`READ_RESULT` supports `PRODUCERS`, `MODELS`, `NATIVE_READS`, `READ_REJECTIONS`, `FINDINGS`, and `SITE_ACCOUNTING`.

`FINDINGS` presents one compact row per original path. Each row keeps producer, destination, representation, model provenance, terminal, and obligations.

`VALUE_PATHS` with cursor `pathOrdinal` and `maxResults: 1` expands that path. Its `pathRowId` stays attached to the original result.

| State | Meaning |
| --- | --- |
| `REACHED` | Links original paths by ordinal and row ID, preserving separate scope exits. |
| `EXCLUDED` | Keeps proven scope-exclusion witnesses. |
| `RELATIONSHIP_UNPROVEN` | Preserves identity and adds `REQUESTED_SITE_RELATIONSHIP`, preventing semantic completion. |

Requested-site identity alone does not establish a producer relationship. `RELATIONSHIP_UNPROVEN` prevents semantic completion.

Before ledger finalization, witness reads return `RESULT_FIELD_UNAVAILABLE`. Rejection evidence uses `EVIDENCE_ONLY` and grants no semantic replay.

## Defaults and limits

Omitted or null budget dimensions use configured defaults and ceilings. Requested values remain subject to the admitted grant.

The root-level boolean `verbose` defaults to `false`. Compact output keeps semantic qualifications, exact references, and recovery evidence.

[Program tracing](/reference/program-tracing) explains path evidence. [Results](/reference/responses) defines presentation. [Limits](/reference/limits) defines resource and state failures.
