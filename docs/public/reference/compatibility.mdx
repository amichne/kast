Use an Apple silicon Mac and a Kotlin Gradle project.
Kast needs IntelliJ IDEA `262.*` with its bundled Kotlin plugin and Java 25 JBR.
Your project's JDK does not replace the IDEA runtime.

## Tool contracts

MCP clients get the tool contract from `tools/list`. Tool RPC clients use `catalog`.
Use the schema from your session and copy issued references unchanged.

Before it admits work, Kast examines the runtime protocol, operation registry, and wire schema. It also examines supported features and IDEA/Kotlin support.

## Install the latest release

The [installer](/start) selects the latest stable release for Control and Host.
Control provides the command and agent adapters. Host provides the IDEA plugin.

After an update, restart IDEA and your agent. Ask a fresh question in your repository or worktree.

Codex uses the bundled Kast plugin over MCP. Codex owns its App Server and control socket.
Use [integration options](/reference/integrations) for custom connections.
