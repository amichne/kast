<span id="is-kast-for-you" />

The desktop setup supports Apple silicon Macs and IntelliJ IDEA `262.*` or `263.*` for Kotlin Gradle projects. See [setup requirements](/start#before-you-start).

For a private Host on macOS or Linux, use [workspace containers](/reference/installation#manage-isolated-workspaces). If the release lacks matching runtime assets, use a qualified candidate.

## Code has meaning beyond its text

Kast gives your agent compiler-resolved declarations, types, and source relationships with locations it can inspect.
See [Capabilities](/search).

<span id="use-the-evidence-for-your-next-decision" />

## Evidence you can act on

Kast reports what its source evidence establishes and where that evidence stops.
Completion applies to the declared scope and semantic model. Incomplete evidence cannot establish that a result is absent.
[How Kast establishes a fact](/explanation) explains the contract and the product standard: never silently wrong.

For installation or agent problems, use [Help](/troubleshooting).
