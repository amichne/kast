<span id="is-kast-for-you" />

The desktop setup supports Apple silicon Macs and IntelliJ IDEA `262.*` or `263.*` for Kotlin Gradle projects. See [setup requirements](/start#before-you-start).

If the release lacks a runtime for your private Host, use a qualified candidate.

## Code has meaning beyond its text

Kast gives your agent compiler-resolved declarations, types, and source relationships with locations it can inspect.

<span id="use-the-evidence-for-your-next-decision" />

## Evidence you can act on

A complete result applies to the declared scope and semantic model. Incomplete evidence cannot establish that a result is absent. See [what a Kast answer proves](/explanation).
