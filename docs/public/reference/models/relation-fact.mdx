A relation fact records a compiler-established relationship within the requested domain. Read it with the query's coverage and occurrence evidence.

Lexical containment alone does not establish a named caller. Static callback evidence does not prove runtime execution. See [Callback evidence](/reference/callbacks) for ownership rules.
