A relation fact records a link in source that the compiler has proved within the admitted domain. The query also reports the source sites and the scope it scanned.

A reference, caller, implementation, and type use are distinct facts. Their counts do not all count calls.

An anonymous body's owner is distinct from the named body that contains it. A static callback path does not prove that code ran.

[Program tracing](/reference/program-tracing) explains path evidence. [Callback fields](/reference/callback-observations) defines when a named edge can be claimed and which limits apply.
