Live read evidence names the workspace and source state that support the operation. Its identity and lifetime apply to that read.

The read epoch records admitted state signals. It does not replace committed-content admission or compiler identity revalidation.

Exact references can get fresh authority under their identity policy. Retained results and continuations need their original read state.

[Staleness](/reference/staleness) defines those policies. [Lifecycles](/reference/lifecycles) identifies the Host and request owners.
