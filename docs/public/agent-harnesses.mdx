## 1. Connect your agent

<Tabs>
  <Tab title="Codex">
    Replace an existing Kast connection with the bundled plugin:

    ```shell
    kast disconnect codex
    kast plugin codex
    ```

    Restart Codex to load the plugin. Select your Kotlin repository or worktree.
  </Tab>
  <Tab title="Copilot">
    ```shell
    kast connect copilot
    ```

    Restart Copilot to load Kast. Start Copilot from your Kotlin repository or worktree.
  </Tab>
  <Tab title="Pi">
    ```shell
    kast connect pi
    ```

    Restart Pi to load Kast. Start Pi from your Kotlin repository or worktree.
  </Tab>
</Tabs>

<a id="run-the-first-query" />

## 2. Request a declaration

Ask your agent:

> Use Kast to find a Kotlin function in this repository. Show its name and source location. Report a setup problem if you cannot.

A result from Kast shows that your agent can use the connection. Kast prepares the selected IntelliJ project when the query needs it.

You can continue in the same conversation:

> Read that function's source with Kast, then find its callers.

## 3. Compare the evidence

Use [the first-query exercise](/tutorials/first-query) to compare identity and caller evidence with known source.

See [Example questions](/search) for more tasks. If the tools do not appear, use [Troubleshoot Kast](/troubleshooting).
