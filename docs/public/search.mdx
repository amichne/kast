Use these prompts with your [connected agent](/agent-harnesses). Replace the example names with code from your project.

## Where does this value go?

> Use Kast to trace the result of submitOrder. Show the source connections through helpers, fields, and callbacks. Report where the evidence stops.

A value can move through several functions and take different names. Kast can trace those connections and distinguish another value of the same type.
Inspect each path's classification and the first unsupported transfer.
An admitted model alone does not establish that the same value reaches the destination.

[Explore a value journey](/explanation/value-journey).

## What depends on this function?

> Use Kast to find submitOrder. If several functions match, show their signatures so I can choose one. Then find its callers.

Use the returned locations to review the callers of your selected function.
Keep the search scope and completion status with that list. A partial list does not identify every affected caller.

## Which implementation matters?

> Use Kast to find implementations of CacheManager in this project. Show their source locations.

The list describes source code. It does not show which implementation a live application uses.

## What problems does IDEA report?

> Use Kast to inspect the diagnostics in this directory before we change it.

Kast returns the problems that IDEA reports for the selected code.
An empty diagnostic list does not replace a project build or its tests.

## Can we change this body?

> Use Kast to replace the selected retryLimit function's body with `{ return 3 }`. Keep its signature unchanged.

Kast can replace a supported function body or add a declaration to an existing file.
For a rename or a multi-file refactor, your agent needs its other edit tools.
Review the diff and run your project's tests after a change.

## What if Kast cannot finish?

Read the reason in the result. Ask your agent to narrow the question or resolve the problem.
An unfinished search does not prove that no matches exist.
If you narrow the scope, the new answer covers that smaller question.

[Troubleshoot Kast](/troubleshooting) to return to your task.

For exact steps, see [diagnostics](/how-to/inspect-diagnostics), [source changes](/reference/change), and [large results](/how-to/read-retained-evidence).
