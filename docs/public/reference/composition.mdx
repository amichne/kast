Composition compares canonical identities from admitted references or retained rows. Display names and opaque reference strings do not establish declaration equality.

## Set operations

| Step | Input field | Output rule | Evidence rule |
| --- | --- | --- | --- |
| `CONCAT` | `input` | Appends rows in order with duplicates. | Keeps evidence from each input. |
| `UNION` | `right` | Combines symbols by canonical identity. | Keeps input qualifications. |
| `INTERSECT` | `right` | Keeps symbols present in both inputs. | Combines evidence for the shared identity. |
| `DIFFERENCE` | `right` | Keeps left symbols absent from the right input. | Needs complete right coverage without failures or producer progress. |
| `DISTINCT_SYMBOLS` | None | Keeps the first row per canonical identity. | Applies at its exact pipeline position. |

The pipeline position controls scope of effect. A filter after composition acts on the combined stream.

`DISTINCT_SYMBOLS` keeps the first row for each identity at its supplied position. It does not erase the result's qualifications.

## Joins and row kinds

| Mode | Output | Necessary proof |
| --- | --- | --- |
| `INNER` | Binding rows with named left and right cells. | Canonical identity equality. |
| `SEMI` | Matching left symbol rows. | A matching right identity. |
| `ANTI` | Left symbol rows without a match. | Complete right coverage for absence. |

An inner join preserves both cells and their evidence. `PROJECT_BINDING` selects one named cell before a later symbol operation.

`BINDING_ROWS` presents inner-join output. Arbitrary-field joins and a general-purpose `MAP` have no supported contract.

## Absence and rejection

`DIFFERENCE` and `ANTI` need a complete right input without failures or unfinished producer progress. Missing matches in a prefix do not prove absence.

Both operations reject incomplete right coverage. A final presentation page cannot repair that producer limitation.

All composed rows keep their original state. A changed epoch or lost retained input prevents reuse before composition starts.
