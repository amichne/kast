`query_symbols` returns its canonical document in `result.structuredContent`, with `complete`, `qualified`, or `rejected` status and preserved evidence.

`check_diagnostics` has a separate `check_diagnosticsSemanticResult` schema. Invocation failures can lack a structured document; see the [MCP wrapper](/reference/models/mcp-tool-call-result) and [Results](/reference/responses).
