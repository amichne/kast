Kast lets your coding agent ask IntelliJ IDEA what Kotlin code means: which declaration a name refers to, where it is called, what implements it, and which results belong together.

New here? [Install Kast](/start), then [connect your agent](/agent-harnesses). You ask the question; the agent selects the tool and carries exact references between calls.

## Find the declaration you actually mean

> Use Kast to find the `parse` function in this module. Show each overload's signature and location before choosing one.

Names are useful starting points, not unique identities. Kast returns exact references that the agent can reuse instead of resolving the same name repeatedly.

## Trace a change through the code

> Find this interface's implementations. Select the relevant methods, then trace their callers up to two hops. Separate confirmed relationships from anything the query could not cover.

A relation query follows compiler-confirmed relationships. A bounded walk goes deeper. Ask for occurrences when individual call sites matter, rather than only a deduplicated list of declarations.

## Compare investigations without starting over

> Keep both query results. Find the declarations present in both, then show their references. Do not match them just because their names are the same.

Retained results can feed another query. The agent can combine sets, select matching symbols, or preserve paired rows from an identity join before applying another step. [Combine query results](/query-pipelines) walks through those shapes using Kast's own source.

## Make a bounded source change

> Find the exact function and inspect its source. Replace only its block body with this implementation, preserving the signature. Show the verified diff or explain why the change could not be verified.

Kast exposes bounded body replacement and declaration insertion. Neither is a promise that arbitrary refactoring or a whole-project build will succeed. Read [Change code](/change) before authorizing a write.

## Know what an answer covers

A result includes facts and their limits. A complete empty result and an unfinished empty result mean different things. Ask your agent to keep coverage and limitations in its answer, especially before claiming that nothing calls or implements something.

Kast [prepares IntelliJ in the background](/concepts/background-startup) when a query needs it. Trust, import, indexing, or other readiness blockers are reported rather than disguised as successful empty searches.

Start with [Find and trace code](/search). Use [Query forms](/reference/api) and [Results](/reference/responses) when you need the exact shape behind an example.
