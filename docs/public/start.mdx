Install Kast and connect it to the agent you already use for your Kotlin Gradle project. After setup, continue your work naturally.

## Before you start

<span id="before-you-install" />

You need:

- An Apple silicon Mac.
- A Kotlin Gradle project.
- IntelliJ IDEA `262.*` or `263.*` with its bundled Kotlin plugin and Java 25 JBR.
- The Codex, Copilot, or Pi CLI.
- Python 3.12 or 3.13 available as `python3` on `PATH`.

For upgrades or [optional MCP](/reference/integrations#optional-mcp), install uv 0.12.9 or later.

## 1. Install or update Kast

<span id="1-install-kast" />
<span id="1-select-the-development-build" />

Save your project work. Installation can end active Kast sessions.
For an initial installation, run:

```shell
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/amichne/kast/main/install.sh)" -- --developer-latest --skip-codex-plugin
```

This command needs no checkout or existing `kast` installation.
It selects the latest qualified development build and resets stale Kast state.
Step 2 adds the agent guidance.

Restart IDEA after installation to load the Kast Host.
If the shell cannot find `kast`, add the command directory from the installer output to `PATH`.

<Accordion title="If Kast is already installed">
  Update to the latest qualified development build:

  ```shell
  kast upgrade --channel main --restart-ide
  ```

  `--restart-ide` permits a normal IDEA restart when necessary. See [installation and updates](/reference/installation) for pins and recovery outcomes.
</Accordion>

## 2. Install agent guidance

<span id="choose-your-agent" />
<span id="1-connect-your-agent" />
<span id="2-restart-intellij-idea" />
<span id="2-restart-your-tools" />
<span id="3-connect-your-agent" />

Choose the tab for your existing agent.

<Tabs sync={false}>
  <Tab title="Codex">
    ```shell
    kast install codex
    ```
  </Tab>
  <Tab title="Copilot">
    ```shell
    kast install copilot
    ```
  </Tab>
  <Tab title="Pi">
    ```shell
    kast install pi
    ```
  </Tab>
</Tabs>

These commands install guidance for the native CLI.
The default setup needs no MCP registration.

Start a fresh agent session in the same Kotlin repository or worktree.
If an upgrade reports `HARNESS_REFRESH_REQUIRED`, repeat your agent's installation command before the fresh session.

## 3. Continue your work

<span id="3-ask-about-your-code" />
<span id="3-ask-your-agent" />
<span id="4-establish-readiness" />
<span id="what-your-first-result-establishes" />

Work on your project as usual. The installed guidance tells your agent how to use Kast for supported Kotlin work.

Kast can wait for Gradle import and indexing before supplying compiler evidence.
If it cannot finish, the result carries the cause and recovery evidence. Use [Help](/troubleshooting) to resolve the reported problem.

<span id="inspect-your-first-answer" />

[Agent capabilities](/search) describes the evidence available during your work.
[Understand the evidence](/explanation) explains completion and evidence limits.
