`check_diagnostics` returns IDEA diagnostics for the requested path. Read each diagnostic with its source location and the response's reported scope.

IDEA diagnostics do not establish a successful project build. After a source change, run your project's build and tests. See [change receipts](/change#read-the-receipt) for edit verification.
