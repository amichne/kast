# Product brief

## Description

Kast lets an agent query the Kotlin project admitted in IntelliJ IDEA and carry exact compiler references and coverage into follow-up work.

## Primary audience

Developers using an agent from a Kotlin Gradle repository or worktree. Assumption: the first visit is for installation or a first query.

## Jobs to be done

Install the matched IDEA plugin, connect a client, run a name-free query, and interpret its limits. Integrators need the installed MCP or tool RPC contract.

## Motivation

Kast provides compiler-backed identity and bounded semantic evidence that a text search cannot establish.
