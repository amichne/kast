This track teaches one path from source code to compiler evidence. Each exercise states its starting state and expected result.

1. [Install Kast](/start).
2. [Connect your agent](/agent-harnesses).
3. [Find a function and its caller](/tutorials/first-query).

The exercise uses a small file in your Kotlin Gradle project. You control the source and compare Kast's result with that file.

If you already know Kast, use [How-to guides](/how-to) for a specific task. Use [Reference](/reference) to look up syntax.
