For your first installation, [set up Kast](/start). Use this page to change an existing agent connection.

<span id="choose-your-agent" />

<span id="1-connect-your-agent" />

<Tabs sync={false}>
  <Tab title="Codex">
    If you skipped the installer's Codex plugin option, run:

    ```shell
    kast plugin codex
    ```

    Restart Codex in your Kotlin repository or worktree. Review and trust its Kast session context hook.
  </Tab>
  <Tab title="Copilot">
    If the optional RPC extension occupies the Kast slot, remove that connection first:

    ```shell
    kast disconnect copilot
    ```

    Install the bundled plugin:

    ```shell wrap
    copilot plugin install "$HOME/.local/share/kast/installation/share/kast/agent-tools/plugins/kast"
    ```

    Restart Copilot in your Kotlin repository or worktree.
  </Tab>
  <Tab title="Pi">
    Connect Pi:

    ```shell
    kast connect pi
    ```

    Restart Pi in your Kotlin repository or worktree.
  </Tab>
</Tabs>

If your shell cannot find `kast`, use the command path the installer printed. The installer does not change your shell profile.
