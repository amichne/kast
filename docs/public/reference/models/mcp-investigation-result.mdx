For a successful `health_check`, read readiness observations from the `complete` variant's `data`. A rejection reports an error. Semantic tools use separate operation documents.

Readiness describes workspace binding at the time of the call. A later query needs its own admission and coverage evidence. See [MCP contract](/reference/mcp-catalog) for discovery and result decoding.
