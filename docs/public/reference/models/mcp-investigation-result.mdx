The direct `health_check` result reports the workspace binding and whether it is ready. A complete reply keeps its findings in `data`. A rejected reply gives a specific error.

Readiness applies to the call's workspace state. It does not prove a later symbol identity, a link between symbols, or a complete query.

[MCP](/reference/mcp-catalog) defines the session and result wrapper. [Workspace preparation](/reference/lifecycles#workspace-preparation-lifecycle) describes what happens before a query can run.
