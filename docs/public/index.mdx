## Let your agent ask the project what a symbol means

Kast gives coding agents a semantic view of the Kotlin Gradle project open in IntelliJ IDEA. Queries return exact symbols, source locations, relationships, and coverage from that project.

## Try Kast

1. [Install Kast](/start).
2. Start your agent from the Kotlin repository or worktree you want Kast to inspect.
3. Ask:

> Use Kast to query declarations in this workspace. Return one exact symbol with its signature, source location, `ref`, and coverage. Explain what an empty or incomplete result proves.

A returned `ref` is Kast's exact symbol handle. Reuse it unchanged for a
source read or another query while Kast can validate its owning workspace and evidence. The result also says whether the requested
scope was fully covered.

## Give the model evidence it can reuse

A text match cannot establish which declaration a call refers to, whether a match is a call or a comment, or whether an empty search covered the requested scope.

### Identity stays exact

Kast returns a symbol reference established by the IDE's semantic model. Later reads reuse it instead of guessing from a name or path.

### Facts keep their limits

Coverage and qualifications travel with the result. Incomplete work stays distinct from a complete empty answer.

### Queries compose

Start from declarations or exact refs, then filter, expand relations, walk, combine sets, or join typed results in order.

## From a question to a grounded next step

The agent can find a declaration, carry its exact `ref` into a source read, and ask where it is used. Kast keeps scope, identity, and coverage visible across those steps.

Find a declaration without naming a project-specific class. Follow its exact reference into a source or relationship query. Interpret coverage and qualifications before making a claim. [Try the query guide](/search), then [see how Kast checks the evidence](/concepts/architecture).
