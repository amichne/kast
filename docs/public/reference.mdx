This track describes Kast's inputs, outputs, defaults, and rejection rules. The installed catalog governs the release that your client uses.

The schemas on `main` can describe a newer release. [Compatibility](/reference/compatibility) identifies the catalog for each client.

| --- | --- |

## Client contracts

| Client | Contract |
| --- | --- |
| Direct MCP | [Tool discovery, calls, and structured results](/reference/mcp-catalog). |
| Tool RPC | [Process invocation and the reply union](/reference/rpc-catalog). |
| Hosted App Server | [Client compatibility](/reference/compatibility) and the conversation's provider catalog. |

Direct MCP and Tool RPC expose `health_check`. Hosted App Server supplies `workspace_lifecycle` instead.

The four shared tools are `query_symbols`, `check_diagnostics`, `add_declaration`, and `replace_body`.
