Direct MCP puts the canonical `query_symbols` document in `result.structuredContent`. Its status is `complete`, `qualified`, or `rejected`.

This document keeps exact identities, coverage, proof limits, producer progress, and retained evidence. How much output fits on a page has its own row and byte limits.

A failed tool call can omit this document. `check_diagnostics` has its own schema: `check_diagnosticsSemanticResult`.

[Results](/reference/responses) defines the fields. [The MCP wrapper](/reference/models/mcp-tool-call-result) defines how a tool-call failure is reported.
