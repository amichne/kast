Kast connects your coding agent to IntelliJ IDEA. Your agent uses compiler evidence to identify Kotlin declarations and their connections.

Text search finds matching words. Kast distinguishes overloads, reports source relationships, and states the limits of each answer.

## What your agent can do

- Find a declaration by name, source location, or matching word.
- Read source and distinguish declarations with the same name.
- Find references, callers, implementations, and overrides.
- Inspect IDEA diagnostics for a file or directory.
- Add a declaration or replace a supported function body.

[Example questions](/search) show these tasks in an agent conversation. Codex, Copilot, and Pi use the same semantic owners through different adapters.

## Before your first query

Kast supports Kotlin Gradle repositories on Apple silicon macOS with IntelliJ IDEA `262.*`, its bundled Kotlin plugin, and Java 25 JBR.

[Install Kast](/start), then [connect your agent](/agent-harnesses). A query prepares the exact IDEA project and reports trust, import, or indexing blockers.

A completed answer applies to its declared source scope and compiler-static model. It does not prove runtime execution or a successful project build.

[What an answer proves](/reference/evidence-boundaries) explains these limits. Your project's build and tests establish behavior after a change.
