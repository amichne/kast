## Before you install

You need:

- An Apple silicon Mac.
- A Kotlin Gradle project.
- IntelliJ IDEA `262.*` with its bundled Kotlin plugin and Java 25 JBR.
- Codex CLI and Python 3.9 or later on `PATH`.

Run `codex --version` and `python3 --version` to examine those commands.
For Copilot or Pi, use the [agent guide](/agent-harnesses) after installation.

<Steps>
  <Step title="Install Kast">
    <span id="1-install-kast" />

    Run this command:

    ```shell wrap
    /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/amichne/kast/main/install.sh)"
    ```

    Accept the default Codex plugin installation.
  </Step>
  <Step title="Restart IDEA and Codex">
    <span id="2-restart-intellij-idea" />
    <span id="3-connect-your-agent" />

    Restart IDEA to load its Kast plugin. Restart Codex and select your Kotlin repository or worktree.
    Review and trust the Kast session context hook in Codex.
  </Step>
  <Step title="Ask your first question">
    <span id="3-ask-your-agent" />
    <span id="4-establish-readiness" />

    > Use Kast to find a Kotlin function in this workspace. Show its signature and source location.

    Kast prepares the project in IDEA. If trust or project import needs your attention, the result names the problem.
    Open the returned source location and compare the function with the answer.
  </Step>
</Steps>

Use [the first-query exercise](/tutorials/first-query) for a small example with a known caller.
If setup stops, use [Troubleshoot Kast](/troubleshooting).
