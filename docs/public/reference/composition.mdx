Composition compares canonical identities from admitted references or retained rows. A display name or opaque reference string alone cannot prove that two declarations are the same.

## Set operations

| Step | Input field | Output rule | Evidence rule |
| --- | --- | --- | --- |
| `CONCAT` | `input` | Appends rows in order with duplicates. | Keeps evidence from each input. |
| `UNION` | `right` | Combines symbols by canonical identity. | Keeps the stated limits of each input. |
| `INTERSECT` | `right` | Keeps symbols present in both inputs. | Combines evidence for the shared identity. |
| `DIFFERENCE` | `right` | Keeps left symbols absent from the right input. | The right scan has to be complete. It has no failures or producer work left. |
| `DISTINCT_SYMBOLS` | None | Keeps the first row per canonical identity. | Takes effect at that point in the pipeline. |

A step takes effect where you place it in the pipeline. A filter after composition acts on the combined stream.

`DISTINCT_SYMBOLS` keeps the first row for each identity at that point. It keeps the result's stated limits.

## Joins and row kinds

| Mode | Output | Necessary proof |
| --- | --- | --- |
| `INNER` | Binding rows with named left and right cells. | Canonical identity equality. |
| `SEMI` | Matching left symbol rows. | A matching right identity. |
| `ANTI` | Left symbol rows without a match. | Complete right coverage for absence. |

An inner join keeps both cells and their evidence. Before a later symbol step, use `PROJECT_BINDING` to select one named cell.

`BINDING_ROWS` presents inner-join output. Kast does not support arbitrary-field joins or a general-purpose `MAP`.

## Absence and rejection

`DIFFERENCE` and `ANTI` need a complete right input. It has no failures or producer work left. Missing matches in a prefix do not prove absence.

Both steps reject incomplete right coverage. The final output page cannot repair that producer limit.

All composed rows keep their original state. Kast rejects reuse before composition if the epoch changed or a retained input was lost.
